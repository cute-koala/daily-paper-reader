## 摘要
尽管在数据理解和决策方面具有强大能力，自主数据科学代理仍然严重依赖试错工作流程，这涉及昂贵的计算。这一瓶颈促使了能够在实际执行前预测数据科学操作效果的模型。在本文中，我们引入了数据科学世界模型的概念，该模型通过预测基于当前工作流状态和候选操作的环境状态转换来对数据科学执行环境进行建模。我们进一步提出了DSWorld，一个结合了结构化状态构建、成本感知路由、轻量级实际执行以及用于昂贵操作的基于LLM的模拟器的实用框架。为支持训练，我们构建了一个8K规模的转换轨迹数据集，并引入了反思性世界模型优化，这是一种用于改进转换预测的误差感知强化学习策略。实验表明，DSWorld将基于RL的代理训练加速约14倍，基于搜索的推理加速约3-6倍，同时保持竞争性能，并在转换预测任务上比最强LLM基线高出35.6%。代码可在https://anonymous.4open.science/r/DSWorld获取。

## Abstract
Despite strong capabilities in data understanding and decision-making, autonomous data science agents still heavily rely on trial-and-error workflows that involve expensive computation. This bottleneck motivates models that can anticipate the effects of data science operations before real execution. In this paper, we introduce the concept of Data Science World Model, which model the data science execution environment by predicting environment state transitions conditioned on current workflow states and candidate operations. We further propose DSWorld, a practical framework that combines structured state construction, cost-aware routing, lightweight real execution, and an LLM-based simulator for expensive operations. To support training, we construct an 8K-scale transition trajectory dataset and introduce Reflective World Model Optimization, an error-aware reinforcement learning strategy for improving transition prediction. Experiments show that DSWorld accelerates RL-based agent training by approximately $14\times$ and search-based inference by approximately $3$-$6\times$ while maintaining competitive performance, and outperforms the strongest LLM baseline by 35.6% on transition prediction tasks. The code is available at https://anonymous.4open.science/r/DSWorld.

## 1. 核心问题与整体含义（研究动机与背景）

- **痛点**：现有自主数据科学智能体（如 ML-Master、AIDE、AutoMLGen）通常依赖“试错”式工作流，执行大量昂贵计算（数据处理、模型训练、评估等）。例如，ML-Master 超过 86% 的执行时间用于模型训练，严重限制了系统效率与可扩展性。
- **目标**：开发一个**数据科学世界模型（Data Science World Model）**，能够基于当前工作流状态和候选操作，预测下一环境状态（数据集变化、执行反馈、错误、性能信号等），从而避免实际执行昂贵计算，加速智能体的训练和推理。
- **核心概念**：类比于物理世界模型（如视频生成），数据科学世界模型将数据科学执行环境视为“世界”，学习状态转移函数 $S_{t+1} = W(S_t, A_t)$。

## 2. 方法论：核心思想、关键技术细节

- **DSWorld 框架**由四个组件构成：
  - **状态构造器（State Constructor, SC）**：将原始执行环境（任务、数据集、日志、配置等）转化为结构化状态表示 $S_t = SC(E_t)$。
  - **路由器（Router, R）**：基于当前状态和动作嵌入（使用 Harrier OSS v1 0.6B 编码器 + 两层 MLP），判断操作是轻量级（直接执行）还是昂贵（需模拟），输出 $m_t \in \{\text{execute}, \text{simulate}\}$。
  - **编译器（Compiler, C）**：对轻量操作直接实际执行，返回准确下一状态 $\hat{S}_{t+1} = C(S_t, A_t)$。并设置超时，超时自动回退到模拟器。
  - **模拟器（Simulator, S）**：基于 Qwen3-8B 的 LLM，对昂贵操作预测下一状态 $\hat{S}_{t+1} = S(S_t, A_t)$，避免实际计算。

- **优化策略**（两阶段训练）：
  1. **监督微调（SFT）**：在 DSWorld-8K 数据集上训练，目标为最小化负对数似然 $L_{SFT} = -\log S_\theta(S'|S,A)$。
  2. **反思性世界模型优化（Reflective World Model Optimization）**：基于 GRPO 的强化学习。
     - 模拟器先预测下一状态 $\hat{S}'$，与实际状态 $S'$ 比较，生成反思反馈 $f$。
     - 条件于反馈，模拟器进行修正预测 $\hat{S}'_r$。
     - 每组 rollout 采集 $n$ 个原始和修正预测，计算组相对优势 $A_i = (R_i - \mu)/\sigma$，使用裁剪策略优化策略。

- **训练数据构建**：
  - **真实轨迹采集**：运行已有智能体在真实任务上，记录 $(S,A,S')$，并用 LLM 合成 CoT 推理路径。
  - **合成轨迹生成**：
    - 状态合成：从 MMTU (61,763 张真实表格) 随机选取数据集，用状态构造器构建。
    - 动作合成：基于 NumPy/Pandas 操作和错误库，条件采样操作、错误类型、执行状态，用 LLM 生成可执行动作。
    - 实际执行获取下一状态并验证，保留有效样本。
  - 最终数据集 DSWorld-8K：约 8,000 个（状态, 动作, 下一状态, CoT 轨迹）样本。
