## 摘要
在多智能体强化学习（MARL）中，智能体间的通信对于在部分可观测性下提升性能是有效的。基于表示学习的方法使分散式智能体能够学习基于自身观测的消息，但仅依赖当前观测，无法传递随时间累积的信息。我们提出Dreamer-CPC，一种基于模型的分散式MARL方法，它将基于集体预测编码（CPC）的消息学习集成到DreamerV3的世界模型中。每个智能体独立维护一个世界模型和一个消息模块，并从反映过去观测和动作历史的世界模型潜在状态中推断和交换消息。我们在两个环境中评估了Dreamer-CPC：Observer（非合作信息共享任务）和CatchApple（新引入的任务，其中任务相关观测暂时缺失）。在这两个环境中，Dreamer-CPC均优于IPPO-CPC（一种基于当前观测生成消息的现有CPC方法）以及无通信基线。特别是在CatchApple中，Dreamer-CPC实现的回合回报是IPPO-CPC的4到5倍，展示了在因观测缺失而导致其他方法失败时的有效协调能力。这些结果表明，当仅凭当前观测不足时，基于世界模型潜在动态的通信可以支持分散式决策。

## Abstract
In multi-agent reinforcement learning (MARL), inter-agent communication is effective for improving performance under partial observability. Representation learning-based approaches enable decentralized agents to learn messages grounded in their own observations, but they rely only on current observations and cannot convey information accumulated over time. We propose Dreamer-CPC, a decentralized model-based MARL method that integrates message learning based on Collective Predictive Coding (CPC) into the world model of DreamerV3. Each agent independently maintains a world model and a message module, and infers and exchanges messages from the latent states of the world model that reflect the history of past observations and actions. We evaluated Dreamer-CPC in two environments: Observer, a non-cooperative information-sharing task, and CatchApple, a newly introduced task in which task-relevant observations are temporarily missing. In both environments, Dreamer-CPC outperformed IPPO-CPC, an existing CPC-based method that generates messages from current observations, as well as no-communication baselines. In particular, in CatchApple, Dreamer-CPC achieved 4 to 5 times the episode return of IPPO-CPC, demonstrating effective coordination where other methods fail due to missing observations. These results suggest that communication grounded in the latent dynamics of world models can support decentralized decision-making when current observations alone are insufficient.

## 1. 核心问题与整体含义

- **研究动机**：在多智能体强化学习（MARL）的部分可观测环境下，智能体需要利用通信来弥补局部信息的不足。现有的基于表示学习的通信方法（如CPC）仅从当前观测中提取消息，无法传递随时间累积的历史信息，导致在观测临时缺失或需要预测未来状态时协调失败。
- **核心问题**：如何让分散式智能体在缺乏共享奖励的条件下，利用自身观测历史来生成和交换富含时间上下文的消息，从而在部分可观测性更强的场景中实现有效协调。
- **整体含义**：该工作将世界模型（World Model）与集体预测编码（CPC）相结合，使智能体能够从反映历史信息的潜在状态中学习通信，拓展了表示学习型通信的边界，在非合作和观测缺失任务中显著提升了性能，为构建类似于自然智能体的分散式决策系统提供了新思路。

## 2. 方法论

- **核心思想**：每个智能体独立维护一个基于RSSM（Recurrent State-Space Model）的世界模型和一个递归消息模块。消息不再从当前观测直接生成，而是从世界模型累积的潜在状态（包括确定性子状态 \(h_t^k\) 和随机潜在变量 \(z_t^k\) ）中推断，从而包含历史信息。消息在智能体间交换，并用于预测观测、奖励和继续标志。
- **关键技术细节**：
  - **RSSM扩展**：原始DreamerV3的RSSM被扩展为接收其他智能体的消息。公式(11)中，递归状态 \(h_t^k\) 的更新依赖于上一时刻的潜在状态、动作以及当前时刻的联合预测消息 \(\hat{m}_t\)；公式(12)中，观测重建 \(\hat{x}_t^k\) 条件于当前潜在状态和联合推断消息 \(m_t\)。其他预测（奖励、继续标志）不变。
  - **消息模块**：包含一个递归状态 \(\xi_t^k\)（通过GRU更新），消息先验 \(p_{\psi_k}(m_t^k|\xi_t^k)\) 和后验 \(q_{\psi_k}(m_t^k|\xi_t^k, h_t^k, z_t^k)\)。后验利用RSSM的潜在状态，使消息能反映过去和当前信息。
  - **分散式训练**：其他智能体的消息使用“停止梯度”（stop gradient），避免梯度跨智能体传播，从而实现完全分散的端到端学习。
  - **联合损失函数**：统一优化世界模型和消息模块，包括预测损失、两对KL散度（分别针对潜在状态和消息，均采用free bits和KL平衡技巧），权重设置为 \(\beta_{\text{pred}}=1, \beta_{\text{dyn}}=1, \beta_{\text{rep}}=0.1, \beta_{\text{m-dyn}}=1\times10^{-3}, \beta_{\text{m-rep}}=1\times10^{-4}\)。

## 3. 实验设计

- **环境与场景**：
  - **Observer**：非合作信息共享任务。Agent1（静止）观测奖励位置但不获得奖励；Agent2（可移动）观测自身位置但无法直接看到奖励，必须通过通信获知奖励位置。Agent2的回合回报作为指标。任务特点是每个时间步可通过聚合所有观测恢复完整状态。
  - **CatchApple**：新引入任务。物体下落，观测有时被遮挡（存在“隐藏行”）。Agent1观测物体轨迹但不移动；Agent2控制接盘，但只有物体到达最底层后才能直接观测到落点，因此必须提前预测位置。Agent2的回合回报作为指标。任务特点是存在无法通过聚合观测恢复完整状态的时间步。
- **基准方法与对照**：
  - IPPO-CPC（基于当前观测生成消息的CPC方法，含20×1和5×4两种消息配置）

  - DreamerV3无通信（no-comm）
  - DreamerV3观测共享（obs-shared，即直接共享原始观测）

- Dreamer-CPC在Observer和CatchApple中均显著优于IPPO-CPC和无通信基线，证明基于世界模型潜在状态的消息学习能有效传递历史信息。
