## 摘要
多智能体交互世界模型不仅应生成一致的观测，还应维护跨智能体持续存在并随视图演变的世界状态。现有的自回归视频扩散管道将观测历史作为条件上下文前向传播，这在多智能体和多视图设置中难以维持共享状态。我们提出WorldWeaver (W^2)，一种流式多智能体视频扩散模型，通过跨智能体世界状态寄存器增强展开过程：这些可学习令牌存储共享的世界信息、跟踪单个智能体状态，并在每个生成块后动态更新。我们通过涵盖单个智能体状态、全局状态视图（包括鸟瞰图）和场景文本的监督信号来夯实这些寄存器。我们进一步采用混合Transformer架构进行改进，该架构使用独立的权重进行世界状态建模和视觉帧建模。在双智能体Minecraft视频生成中的大量实验表明，显式世界状态建模提高了逻辑一致性和生成质量。

## Abstract
Multi-agent interactive world models should not only generate consistent observations, but also maintain world states that persist across agents and evolve across views. Existing autoregressive video diffusion pipelines carry forward observation history as conditioning context, which makes shared state difficult to maintain in multi-agent and multi-view settings. We present WorldWeaver (W^2), a streaming multi-agent video diffusion model that augments rollout with cross-agent world state registers: learnable tokens that store shared world information, track individual agent status, and are dynamically updated after each generated chunk. We ground these registers with supervision signals spanning individual agent status, global state views including bird's-eye views, and scene text. We further improve the architecture with a Mixture-of-Transformers design that uses separate weights for world state modeling and visual frame modeling. Extensive experiments in two-agent Minecraft video generation show that explicit world-state modeling improves logical consistency and generation quality.

#### 2. 论文提出的方法论
- **核心思想**：设计一组可学习的令牌（tokens）作为世界状态寄存器，它们跨智能体共享、随生成步骤动态更新，作为自回归扩散模型中的持久状态通路。寄存器具备两个关键性质：（1）跨智能体和展开步骤的持久性；（2）当新观测到达时能够动态更新。
- **关键技术细节**：
    - **世界状态寄存器（WSR）**：K个可学习令牌 ri ∈ R^{K×d}。在展开时，每个寄存器 ri 在生成第 i 帧后提交，用于条件下一步帧生成。序列排列为 [x0, r0, x1, r1, …]，因果注意力中寄存器查询仅关注局部窗口内的上下文帧和前一寄存器。
    - **监督信号**：对提交的寄存器使用三种辅助解码头进行监督：
        1. **智能体状态**（位置、速度、方向），L2损失。
        2. **鸟瞰图**，通过冻结的DINOv2特征余弦相似度损失。
        3. **场景文本**，通过冻结的Llama语言模型交叉熵损失。
    - **混合Transformer（MoT）架构**：寄存器令牌使用独立的权重分支（状态通路），视频帧令牌使用视觉分支，但共享联合注意力。这避免了帧生成与状态更新之间的参数冲突。
    - **三阶段训练策略**：
        - **阶段1：双向训练**。在多智能体同步片段上微调双向教师模型，学习跨智能体场景结构。
        - **阶段2：因果训练**。将教师转换为因果学生，引入因果注意力、滑动窗口和世界状态寄存器监督，同时优化流匹配损失和寄存器损失。
        - **阶段3：自强制（Self-Forcing）**。模拟推理展开，让学生在自己的生成帧和提交寄存器上优化，使用DMD分布匹配损失和寄存器损失，暴露帧和状态漂移。
- **算法流程**：推理时（Algorithm 1）维护帧KV缓存和寄存器KV缓存，每次去噪后提交新寄存器；自强制训练（Algorithm 2）在去噪中途截断，模拟展开。

#### 6. 主要结论与发现
- 显式世界状态寄存器建模显著提升了多智能体视频生成的逻辑一致性和视觉质量。
- 三种监督信号（智能体状态、鸟瞰图、场景文本）均有效，组合使用效果最佳。
- Mixture-of-Transformers架构在寄存器携带丰富语义时优于密集Transformer，避免了状态与视觉目标的竞争。
- 半监督设置下，少量标注数据配合大量未标注视频仍能提升模型性能，展示了在真实场景中应用的前景。
- 自强制阶段通过固定视觉Transformer、仅更新寄存器Transformer可稳定训练，提升VLM准确率。

#### 7. 优点
- **创新性**：首次在多智能体扩散模型中引入可学习的、动态更新的世界状态寄存器，显式建模共享状态。
