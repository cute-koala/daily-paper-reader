## 摘要
无人机反无人机（UAV Anti-UAV）跟踪是一项新兴的低空安全任务，旨在利用移动观察无人机上的机载摄像头定位敌对无人机。它与传统无人机跟踪和地面反无人机跟踪不同，因为相机平台和目标同时移动。这种双动态设置会导致视角快速变化、运动模糊、尺度变化以及视觉上相似的干扰物，使得可靠的外观匹配变得困难。在快速变化的条件下，固定的视觉表示往往不足，因为目标外观变得不可靠，特征分布可能偏离训练域。目标语言描述在帧间保持稳定，因此可以作为时间状态传播的语义锚点，而在线特征分布对齐可以减少特定视频的测试时间偏移。在本文中，我们提出了SATATrack，一种用于无人机反无人机跟踪的语义感知时间自适应框架。SATATrack引入了语义感知上下文传播（SACP），利用目标描述在骨干网络各阶段引导时间上下文传播，并在快速外观变化下保持目标身份。在训练期间使用辅助对比正则化器来抑制对语义相似背景区域的响应。在推理期间，时间感知分布对齐（TADA）在线对齐特征分布，而不更新模型参数，结合最近帧估计与训练时间统计数据以保持稳定性。SATATrack在UAV-Anti-UAV基准测试中达到了最先进的性能，同时在Anti-UAV和无人机目标跟踪任务中保持竞争力。代码将在https://github.com/XiaozhenQiao/SATATrack提供。

## Abstract
UAV Anti-UAV tracking is an emerging low-altitude security task for localizing an adversarial UAV using the onboard camera of a moving observer UAV. It differs from conventional UAV tracking and ground-based Anti-UAV tracking because both the camera platform and the target move simultaneously. This dual-dynamic setting induces rapid viewpoint changes, motion blur, scale variation, and visually similar distractors, making reliable appearance matching difficult. Under such rapidly changing conditions, fixed visual representations are often insufficient because target appearance becomes unreliable and feature distributions may deviate from the training domain. The target language description remains stable across frames and can therefore serve as a semantic anchor for temporal state propagation, while online feature-distribution alignment can reduce video-specific test-time shifts. In this paper, we propose \emph{SATATrack}, a Semantic-Aware Temporal Adaptation framework for UAV Anti-UAV tracking. SATATrack introduces Semantic-Aware Context Propagation (SACP), which uses the target description to guide temporal context propagation across backbone stages and preserve target identity under rapid appearance changes. An auxiliary contrastive regularizer is used during training to discourage responses to semantically similar background regions. During inference, Temporal-Aware Distribution Alignment (TADA) aligns feature distributions online without updating model parameters, combining recent-frame estimates with training-time statistics for stability. SATATrack achieves state-of-the-art performance on the UAV-Anti-UAV benchmark while remaining competitive in Anti-UAV and UAV object tracking tasks. The code will be available at https://github.com/XiaozhenQiao/SATATrack.

- **核心含义**：需要一种**语义锚点**（目标语言描述在帧间稳定）来指导时间状态传播，同时需要**不更新模型参数**的测试时分布对齐以应对视频特定的特征漂移。

## 2. 方法论：核心思想、关键技术细节

- **整体框架（SATATrack）**：由视觉编码器（Fast-iTPN）、文本编码器（CLIP）、语义感知上下文传播模块（SACP）、跟踪头部和测试时分布对齐模块（TADA）组成。模板与搜索帧经 patch embedding 后送入骨干，SACP 在骨干各阶段插入，利用语义嵌入调节状态空间更新，输出目标感知的时间上下文，最后通过跟踪头预测边界框。

### 核心模块一：语义感知上下文传播（SACP）

- **思想**：将目标语义注入选择性状态空间模型的**写门**（Δ）和**状态转移矩阵**（A），而非仅作为融合特征。这样语义直接控制哪些视觉观测可以写入时间记忆、以及目标一致上下文保留多久。
- **流程**（图 3 对应）：
  1. 输入上下文序列经过两个分支（更新分支 U 和调制分支 V）。
  2. 语义嵌入映射到 SSM 隐藏空间。
  3. 对每个 token 计算数据依赖步长 Δ，并通过语义门 `g = σ(MLP([u; s']))` 放大目标一致 token、抑制干扰物 → 得到调制后步长 `Δ̃`。
  4. 对转移矩阵 A 进行语义条件化：`Ã = −exp( a + W_A s + b_A )`，控制衰减率。
  5. 进行标准的离散状态空间更新：`h_t,k = Ã̄ h_{t-1,k} + B̄ u_t,k`。
  6. 结合调制分支输出最终上下文 token。
- **注入**：更新后的上下文通过 attention 注入视觉流，再写回传播分支。

### 辅助损失：语义判别对比学习（SDC）

- 作用：增强目标与语义相似的背景区域之间的判别性。
- 方法：对目标区域进行掩码平均池化得到目标特征，与语义嵌入映射到共享对比空间；挑选与语义最相似的 top-M 背景补丁作为硬负样本，计算 InfoNCE 损失。

### 核心模块二：时间感知分布对齐（TADA）

- 目标：在不更新模型参数的情况下，在线对齐 BN 统计数据。
- 算法流程（Algorithm 1）：
  1. 对特征图每个空间位置计算能量 `e_h,w = (1/C) Σ X²`，选取 top-ρ 高能量位置构成集合 Ωₜ。
  2. 仅在 Ωₜ 内计算当前帧统计量 μₜ、σ²ₜ。
  3. 通过漂移拒绝测试过滤离群帧，将合格统计量推入 FIFO 队列 Qμ、Qσ（大小 L）。
  4. 对队列取平均得到平滑估计 μ̄ₜ、σ̄²ₜ。
  5. 用置信度门控 `c_t = exp(−(|μ̄ₜ − μ_run|/(κ σ_run))²)` 得到混合权重 λ = λ₀·cₜ，其中 λ₀ = n/(n+N)。
  6. 插值得到适应后统计量：μ* = λ μ̄ₜ + (1−λ)μ_run，σ²* = λ σ̄²ₜ + (1−λ)σ²_run。
  7. 计算适应后输出 Y_tada 和原始 BN 输出 Y_run，进行凸混合：Y = (1−α)Y_run + α Y_tada。
- 应用在定位头的中心分支和尺寸分支的 BN 层。

## 6. 主要结论与发现

1. **SACP 带来最大提升**：在基线（35.84% AUC）基础上 +SACP 提升至 42.37% AUC，证明语义引导时间状态传播是核心组件。
2. **语义应控制记忆的写入与保留，而非仅作为融合特征**：全 SACP（同时调制 Δ 和 A）明显优于直接文本融合（44.07% vs 40.32% AUC），且移除 A 调制比移除 Δ 调制损失更大，说明控制保留时间尺度更重要。
3. **TADA 有效增强推理时鲁棒性**：全模型相比 w/o TADA 提升 2.33% AUC（46.40% vs 44.07%），且主要由 top-k 位置选取和双分支适应贡献。
4. **在 UAV-Anti-UAV 上达到 SOTA**：AUC 46.40%，OP75 38.63%，超过所有先前方法，且在所有属性上均最优。
5. **泛化能力良好**：在 UAV123 和 UAVDT 上也达到最佳或接近最佳的 AUC，未过度适配反 UAV 场景。

## 7. 优点

- **方法创新性**：首次将语义描述直接注入状态空间模型的选择性扫描，作为**时间记忆的控制器**而非简单融合，设计清晰（写门调制 + 衰减率调制）。

- **辅助损失设计合理**：SDC 挖掘语义相似的背景作为硬负样本，增强判别性。
- **实验严谨**：消融实验不仅拆分组件，还深入分析 SACP 内部设计变体；属性分析提供了语义抑制干扰物的直接证据；时间稳定性曲线可视化证明了误差累积控制。

## 8. 不足与局限

- **极端情况仍有失败**：在目标完全移出视野、极严重运动模糊、极度小目标（仅几个像素）时，性能下降明显，缺少长期重检测机制。
