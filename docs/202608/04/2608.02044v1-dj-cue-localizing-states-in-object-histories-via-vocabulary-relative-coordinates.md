## 摘要
跟踪通过视觉变化连接同一对象的观测，但仅凭跟踪本身无法确定对象是空的还是满的、完整的还是被切割的。我们提出身份条件下的状态时刻检索：给定一个被跟踪对象的历史和备选状态描述，定位每个描述状态成立的区间。绝对图像-文本相似度独立地给描述打分；因为每个可见帧都描绘同一目标，共享对象的兼容性可能掩盖识别目标区间所需的状态证据。备选描述提供了缺失的参照：一种状态的证据应与其它状态相比较。我们引入Déjà Cue，一个免训练框架，将这些备选描述转化为词汇相对坐标系。它从每个描述中减去状态平衡质心，校准帧分数，并在连续可见运行中使用冻结编码器扫描多个时长。在78个VOST历史上，保持时间扫描固定，仅改变查询参照，R@1在tIoU 0.5下从10.3%提高到20.5%，Top-1 tIoU从16.0%提高到21.5%。候选排名分析表明，词汇相对查询在相同候选集内将有用区间排名更高。因此，相关状态描述可以充当对象特定的查询时坐标系，用于读取冻结视觉表示。

## Abstract
Tracking links observations of the same object through visual change, yet cannot by itself determine when the object is empty or filled, intact or cut. We formulate identity-conditioned state-moment retrieval: given a tracked-object history and alternative state descriptions, localize an interval in which each described state holds. Absolute image-text similarity scores descriptions independently; because every visible frame depicts the same target, shared object compatibility can obscure the state evidence needed to identify the target interval. The alternatives provide the missing reference: evidence for one state should be measured against the others. We introduce Déjà Cue, a training-free framework that turns these alternatives into a vocabulary-relative coordinate system. It subtracts their state-balanced centroid from each description, calibrates frame scores, and scans multiple durations within contiguous visible runs using a frozen encoder. On 78 VOST histories, holding the temporal scan fixed and changing only the query reference nearly doubles R@1 at tIoU 0.5 from 10.3\% to 20.5\% and raises Top-1 tIoU from 16.0\% to 21.5\%. Candidate-rank analyses show that vocabulary-relative queries rank useful intervals higher within the same candidate set. Related state descriptions can therefore serve as an object-specific, query-time coordinate system for reading frozen visual representations.

## 2. 论文提出的方法论：Déjà Cue

**核心思想：**

Déjà Cue 是一个**免训练（training-free）**框架，利用**状态平衡质心（state-balanced centroid）**将每个查询描述转化为词汇相对坐标方向，然后在连续可见运行（observed runs）内进行鲁棒的时长无关扫描，以确定每个状态成立的时间区间。

**方法流程：**

**（1）词汇相对坐标构建**

- 对每个帧特征和文本描述进行 ℓ2 归一化；
- 在每个状态内部对描述向量取平均得到状态原型 μ_{zo,s}；
- 再对所有状态原型取平均得到状态平衡质心 c_o = (1/S_o) Σ μ_{zo,s}；
- 每个查询的残差向量为 e_{uo,q} = z̄_o,q − c_o，归一化后得到查询方向 u_o,q；
- 状态平衡的两层平均保证每个状态权重相等（1/S_o），不受释义数量影响——同一状态内重复描述不会改变质心。

**（2）关键数学性质**

- 若所有描述同时加上任意公共偏移 δ，残差不变（对公共平移具有不变性）；
- 投影是幂等的零和投影；
- 对二元状态词汇（如 pre/post），两个状态原型位于一条语义轴的两端，证据沿这条轴读取；对多状态词汇，每个状态相对全部备选者的重心进行比较；
- 在加入轨迹中心化视觉坐标（减去坐标维中位数）的双变体中，视觉与查询原点可以分别被替换，从而形成四个坐标变体用于消融：绝对基线、仅轨迹中心、仅词汇相对、双变体。

**（3）鲁棒校准与时间定位**

- **中位数–MAD（Median–MAD）标准化**：对每条查询的帧响应减去中位数并除以缩放的 MAD（1.4826 倍），该操作对正仿射变换具有不变性，消除查询特定的偏移与尺度；
- **运行内局部平滑（run-wise local smoothing）**：3 帧盒式滤波器在可见运行内平滑证据，边界处收缩但不跨越可见性缺口；
- **多尺度窗口扫描**：采用几何 1.5× 时长表（33 个候选长度），对每个可见运行内的每个起始位置枚举所有匹配时长；窗口得分 S(o,q,w) = (1/√ℓ) Σ e_{go,q,t}；
- 平方根归一化避免了线性时长偏好，同时保留了持续证据带来的 √L 增益；前缀和可实现 O(T log T) 时间/查询的复杂度。

## 6. 论文的主要结论与发现

1. **查询原点是检索改进的驱动力**：在匹配扫描下，仅将绝对坐标改为词汇相对坐标，R@1@tIoU0.5 从 10.3% 升至 20.5%（+10.3%，Holm–3 p=0.004），Top-1 tIoU 从 16.0% 升至 21.5%（+5.5%）；轨迹中心化对 R@1@0.5 仅带来 +1.6 个百分点的变化，且置信区间包含零；
2. **改进来源于更优的证据排序而非候选覆盖**：无论哪种坐标，共享候选集的 oracle Top-1 tIoU 都达到 93.5%，但词汇相对评分将 MRR@0.5 从 13.3 升至 23.3，R@10@0.5 从 19.2% 升至 28.5%，最优候选归一化排名提前 7.4 位；
3. **启发式效果在不同提示与时长偏好中保持**：四种 SigLIP 2 提示变体均产生正向配对区间；未归一化求和仍在两项指标上保持 +9.3/+6.4 的提升；
4. **语义分组与时间顺序都是必要的**：交换兄弟状态标签使 R@1@0.5 从 53.3% 降至 3.3%；进行 8 次非恒等圆移（保持特征多集与可见性不变）使结果从 43.8% 降至 14.1%；
5. **免训练坐标可以与监督解码器竞争**：在 7 条历史低数据环境中，Déjà Cue 的 R@1@0.3/R@1@0.5/Top-1 tIoU 分别达 45.2/33.3/35.9，超过最强适应解码器（Sim-DETR 为 44.0/30.2/28.7）；
6. **该几何可以推广到多状态词汇**：7 历史研究中的 coffee-martini 与 slice-banana 各自包含 3 个状态，但在保留三历史（内嵌、复发、渐进）上与绝对坐标相比表现下降（R@1@0.5：19.4% 对 38.9%），表明该几何的优势主要体现在端点主导状态上，在多状态拓扑上仍需更多研究；
7. **剩余差距主要来自证据排序与复发建模**：即使采用最优候选，oracle 仍未达到 100%，说明候选枚举并非唯一瓶颈。

---

## 7. 优点

- **问题表述新颖且清晰**：首次将"对象历史中的状态定位"形式化为身份条件下的状态时刻检索，将备选词汇提升为与对象本身同样重要的输入；
- **方法设计简洁、无需训练**：整个框架只涉及均值减法、归一化、中位数–MAD 校准、前缀和扫描，无需任何任务特定训练即可运行；
- **消融设计与配对比较严谨**：通过四种坐标变体（绝对/仅轨迹中心/仅词汇相对/双变体）共享除坐标原点外的所有组件，精确分离出查询原点的贡献；
- **统计推断规范**：使用 10,000 次 bootstrap 置信区间与 100,000 次符号翻转配对检验，并在族内采用 Holm 校正，最大程度上规避了多重比较的虚假发现风险；
- **候选排序分析揭示了机制**：固定候选集、采用 oracle 测量与 MRR/R@10 排序指标，将"检索改进来自更好的证据排序"这一论点与"来自更大搜索空间"清晰区分开来；
- **扰动实验相互印证**：语义置换将性能几乎压至零，时间重排显著降性能，从正反两侧支持了其解释；
- **公开可复现性良好**：提供了 GitHub 代码仓库，所有坐标变体共享相同的特征与管线；
- **对时长偏好的敏感性分析细致**（平方根 vs. 未归一化求和 vs. 算术均值，以及 1.25×/1.5×/2.0× 时长表、合成序列的 270 组设计），有力证明了该方法不依赖于单一的时长先验。

## 8. 不足与局限

- **对复发（recurrence）的处理不充分**：主基准使用单参考区间评价，13 条 pre / 20 条 post 历史存在多个语义有效出现，但只对指定事件附近区间计分，低估了模型的实际语义有效性；论文也承认多窗口解码与多参考评价是未来工作；
- **缺少"状态不存在"的判别机制**：论文假设词汇中的每个状态都实际存在，若某状态完全未发生，缺乏拒绝/空标准；
- **对掩码质量高度敏感**：输入依赖目标沿袭掩码，掩码漂移或跟踪器切换会破坏证据；论文仅用合成干扰物混合与中途身份切换做扰动测试，未覆盖真实像素级掩码漂移；
- **多状态与开放词汇覆盖有限**：主要结果集中于二元 pre/post 词汇；多状态仅由 3 条保留历史承载，在保留三历史上表现甚至不如绝对坐标，显示对不同状态拓扑的泛化能力尚未建立；
- **编码器单一**：全部实验都使用 SigLIP 2 base-patch16-224，未尝试 CLIP、EVA-CLIP 或其他视觉语言模型来检验坐标几何的可移植性；
- **7 历史评估功效不足**：4 条重构 + 3 条保留历史偏少，所有 8 项解码器配对比较均在 Holm 校正后失效，结果只能视为方向性证据；
- **标注主观性**：两个标注者对状态边界仅有 60.5% 的精确一致（κ=0.478），边界不确定性会改变指标幅度；尽管论文验证了符号的稳健性，但精确幅度仍受标注者选择影响；
- **轨迹中心化缺乏理论动机**：实验结果一致表明其区间包含零，提示这一视觉原点与状态判别任务对齐不足，论文也承认了这一点；
- **词汇扩展效果非单调**：当新描述被加入某一状态时，R@1 并不随加入数量单调变化，说明词汇组成与数量共同影响有效方向，该方法对"何时加入描述"无法提供稳定预测。
