## 摘要
在随机环境中，有效的基于模型的强化学习需要考虑到预测不确定性的规划。解析地传播完整的状态分布提供了一种原则性的方法，但传统上需要限制性的策略或奖励结构才能保持可处理性。因此，现代深度强化学习在很大程度上已经退回到随机采样（这会引入显著的目标方差）或确定性点估计（完全忽略预测协方差）。我们研究在没有这些约束的情况下，分布感知规划是否可能。利用二次动作价值参数化，我们首先将贝尔曼备份简化为仅对状态价值函数的期望；关键思想是预测转移分布与价值函数类之间的兼容性原理，在该原理下，这一期望在分布的矩上是解析的。我们用高斯转移模型与径向基价值函数配对实例化这一原理，产生一个闭式备份，同时传播预测均值和协方差。在经验上，我们的方法在连续控制中的随机观测下减少了目标方差，并产生了校准良好的预测不确定性，为使用学习到的分布模型进行规划提供了一个原则性框架。

## Abstract
Effective model-based reinforcement learning in stochastic environments requires planning that accounts for predictive uncertainty. Propagating full state distributions analytically offers a principled way to do this, but has traditionally required restrictive policy or reward structures to remain tractable. Consequently, modern deep reinforcement learning has largely retreated to either stochastic sampling, which introduces significant target variance, or deterministic point estimates that ignore predictive covariance entirely. We investigate whether distribution-aware planning is possible without these constraints. Using a quadratic action-value parameterization, we first reduce the Bellman backup to an expectation over the state-value function alone; the key idea is then a compatibility principle between the predictive transition distribution and the value function class, under which this expectation is analytic in the distribution's moments. We instantiate this principle with a Gaussian transition model paired with a radial-basis value function, yielding a closed-form backup that propagates both predictive mean and covariance. Empirically, our approach reduces target variance and yields well-calibrated predictive uncertainty under stochastic observations in continuous control, providing a principled framework for planning with learned distribution models.

### 1. 论文的核心问题与整体含义

论文针对基于模型的强化学习（MBRL）中处理预测不确定性的核心难题展开研究。在随机环境中进行规划时，价值估计必须考虑预测的不确定性，然而现有方法存在两条相互对立的路径，各自都有明显缺陷：

- **随机采样路径**：通过蒙特卡洛采样模拟想象轨迹来构造 Bellman 目标（如 PETS、MBPO、Dreamer 等），虽然可扩展性强，但采样方差直接注入价值目标，导致估计不稳定且对采样预算敏感。
- **确定性点估计路径**：将随机模型坍缩到均值或直接学习确定性模型，虽简化了计算，但完全丢弃了预测协方差，在价值函数非线性时会产生系统性偏差。

作者提出的核心问题是：**能否在不引入采样方差、也不丢弃协方差的前提下，解析地计算 Bellman 备份中的期望？** 全文围绕这个问题展开，提出了一种基于"矩闭合"（Moment Closure）的解析规划框架，使得在连续控制中既能传播预测均值也能传播预测协方差，同时保持计算的确定性和闭式可解性。

### 2. 论文提出的方法论

#### 核心思想

论文的核心洞察分为两个层次：

1. **解耦最大化与期望**：利用二次动作值参数化（NAF/BNAF 结构），将 Bellman 最优方程内部的 `max_a Q(s', a')` 消去，使备份退化为仅对状态值函数的期望 `E[V(s')]`。这一结构解耦了"贪心动作选择"与"期望计算"两个难题——贪心选择由二次 Q 函数的闭式解完成，而可解性要求全部落在价值表示上。

2. **矩兼容性原理**：提出一个设计原则——当预测转移分布与价值函数类配对时，如果 `E[V(s')]` 能够用分布矩的闭式表达式表示，则该配对是"矩兼容的"。这一原理不绑定任何单一函数形式，可以扩展到多项式价值函数、随机傅里叶特征等多种组合。

#### 关键技术细节

**（1）二次动作值参数化（BNAF）**

Q 函数分解为：

```
Q(s, a) = V(s) - ½(a - μ̃(s))ᵀP(s)(a - μ̃(s)) + ½(μ(s) - μ̃(s))ᵀP(s)(μ(s) - μ̃(s))
```

其中 `P(s) ≻ 0`，`μ(s) = Π_A(μ̃(s))` 是投影到可行动作集的贪心动作。满足：

```
argmax_a Q(s, a) = μ(s),   max_a Q(s, a) = V(s)
```

这使得 Bellman 备份简化为：`y = r + γE[V(s')]`。

**（2）随机动力学模型**

- 学习异方差高斯转移模型：`p_θ(s'|s,a) = N(μ_θ(s,a), Σ_θ(s,a))`，通过负对数似然训练。
- 使用 K 个集成模型捕获认知不确定性，通过**矩匹配**将混合高斯聚合成单一高斯：
  - 均值：`μ̄ = (1/K)Σ_k μ_{θk}`
  - 协方差：`Σ̄ = (1/K)Σ_k Σ_{θk} + (1/K)Σ_k Δμ_k Δμ_kᵀ`，其中第一项为平均偶然不确定性，第二项为集成分歧（认知不确定性）。

**（3）矩兼容的价值表示**

价值函数用高斯径向基函数（RBF）混合参数化：

```
V(s) = Σ_i w_i exp(-½(s - c_i)ᵀΛ_i(s - c_i))
```

其中中心 `c_i` 和精度矩阵 `Λ_i` 固定，仅权重 `w_i` 通过 TD 学习。在高斯预测分布 `s' ~ N(μ, Σ)` 下，期望有闭式解：

```
E[V(s')] = Σ_i w_i |I + ΣΛ_i|^{-1/2} exp(-½‖μ - c_i‖²_{A_i}),   A_i = Λ_i(I + ΣΛ_i)^{-1}
```

#### 算法流程（MoCA）

MoCA 算法在标准 off-policy 学习循环中整合了解析备份：

1. 维护双 critic（带目标网络，采用 clipped double estimation），每个 critic 由 BNAF 结构（共享主干 + 顶点头 + Cholesky 曲率头）和 RBF 价值头组成；
2. 训练 K 个高斯动力学集成模型（在 minibatch 的 bootstrap 重采样上）；
3. 对每个转移，先通过矩匹配得到预测高斯 `(μ̄, Σ̄)`，再用闭式公式解析计算 `E[V(s')]`，构造确定性 Bellman 目标；
4. 仅使用经验回放缓冲区中观测到的 `(s,a)` 对构造目标，避免 Dyna 风格合成滚动导致的模型利用问题；
5. 探索采用目标策略加高斯噪声 + 小概率随机动作的组合。

### 7. 优点

- **理论贡献清晰**：提出"矩兼容性"这一设计原则，不以特定函数形式为限，为未来扩展提供了框架性指导；
- **新颖的问题解耦**：将"贪心动作选择"与"期望计算"的可解性分离，利用二次 Q 结构移除内层最大化，令不确定性传播只依赖价值表示，同时保持策略无约束；

### 8. 不足与局限

- **价值表示的维度灾难**：RBF 混合是紧致状态域上的通用逼近器，但维持逼近质量所需的基函数数量随维度增长迅速，存在表示层面的维度灾难；

### 小结

MoCA 论文提出了一种在随机环境中解析传播不确定性的规划框架——通过 BNAF 二次 Q 参数化解耦最大化与期望，通过高斯转移 + RBF 价值函数的矩兼容配对实现闭式 Bellman 备份。实验证明其在低维连续控制任务上优于采样和确定性等价基线，不确定性校准良好。然而，其价值表示的维度扩展性、实验覆盖范围以及与主流 MBRL 方法的对比仍有不足，需要在未来工作中进一步验证和探索。
