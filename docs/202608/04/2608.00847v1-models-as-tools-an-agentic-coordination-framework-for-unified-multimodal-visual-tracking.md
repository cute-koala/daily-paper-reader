## 摘要
当前大多数视觉跟踪器采用基于匹配的架构，并仅在跟踪数据集上训练，其性能提升高度依赖输入上下文长度，现已达到瓶颈。尽管高性能跟踪日益依赖基础模型，现有方法将其整体化使用，要么将基础模型适配为跟踪器，要么将分割基础模型修改为跟踪流程，未能发挥互补优势。基于匹配的跟踪器擅长实例级对应，但缺乏语义判别和细粒度前景感知；而分割基础模型能产生精确掩码，却在实例判别和多模态扩展上存在困难。两种范式也都缺乏长期跟踪的纠错能力。为解决这些问题，我们提出ACTrack，一种在事件触发机制下将异构模型视为可调用工具的智能体协同框架。ACTrack协调基于跟踪器的实例匹配工具用于目标判别、SAM3运动工具用于生成掩码派生的运动先验、SAM3感知工具用于检测干扰物和实例冲突线索，以及仅在持续冲突时激活的VLM重提示工具以缓解错误累积。我们设计了完整的工具调用触发机制和工具间协同机制，使不同模型工具的互补优势得以充分整合。实验表明，ACTrack在八个RGB基准上大幅超越最强和最大的跟踪器。此外，参数高效适配策略实现跨工具的参数共享与复用，仅用30%可训练参数即可实现统一多模态跟踪，并在LasHeR、VisEvent、TNL2K和DepthTrack等多模态基准上大幅领先现有方法。

## Abstract
Most current visual trackers adopt a matching-based architecture trained exclusively on tracking datasets, whose performance gains depend heavily on the length of the input context, and have now reached a bottleneck. While high-performance tracking increasingly relies on foundation models, existing methods use them monolithically, adapting a foundation model into a tracker or modify a segmentation foundation model into a tracking pipeline, which fails to exploit complementary strengths. Matching-based trackers excel at instance-level correspondence but lack semantic discrimination and fine-grained foreground perception, whereas segmentation foundation models produce precise masks yet struggle with instance discrimination and multimodal extension. Both paradigms also lack error-correction capabilities for long-term tracking. To address these issues, we propose ACTrack, an agentic coordination framework that treats heterogeneous models as invocable tools under an event-triggered mechanism. ACTrack coordinates a Tracker-based Instance Matching Tool for target discrimination, a SAM3 Motion Tool for mask-derived motion priors, a SAM3 Perception Tool for detecting distractors and instance-conflict cues, and a VLM Reprompt Tool activated only under persistent conflict to mitigate error accumulation. We design a complete tool-invocation trigger mechanism and an inter-tool coordination mechanism, enabling the complementary strengths of different model tools to be fully integrated. Experiments show that ACTrack substantially surpasses the strongest and the largest trackers on eight RGB benchmarks. Furthermore, a parameter-efficient adaptation strategy enables parameter sharing and reuse across tools, achieving unified multimodal tracking with only 30\% trainable parameters while substantially outperforming prior methods on multimodal benchmarks such as LasHeR, VisEvent, TNL2K, and DepthTrack.

- **匹配式跟踪范式面临瓶颈**：目前主流视觉跟踪器采用基于匹配的单流Transformer架构，仅在视觉跟踪数据上训练。其性能提升高度依赖输入上下文长度和模型规模，已逼近极限，难以满足鲁棒跟踪所需的语义判别、细粒度前景感知、目标消失恢复、相似干扰物拒斥与多模态适配等多元能力。
- **基础模型被“整体化”使用的局限**：虽已有工作将基础模型用于跟踪，但做法大多是把基础模型改造成匹配式跟踪器，或将分割基础模型整体修改为跟踪流程。这种方式强制单一模型承载所有能力，忽略不同模型在不同子问题上各有所长、各有缺陷的事实，互补优势得不到发挥。
- **两种范式各自的不足**：
  - 匹配式跟踪器擅长实例级跨帧对应，但容易漂移到相似物体上，缺乏语义判别和细粒度前景感知。
  - SAM3等分割基础模型擅长掩码级前景感知与运动先验，但可能服从语义对象的自然边界而非标注的特定实例（如从车厢扩大到整列火车），在目标消失后难以重新锁定，且记忆被错误结果污染后易致误差累积。
- **核心研究问题**：能否不将能力压缩进单一跟踪器，而是**将不同模型当作可调用工具协同起来**，让互补能力互相校验、纠错？这构成了"模型即工具"的agentic协调框架——ACTrack。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将视觉跟踪视作**智能体工具协调问题**而非单一模型匹配问题：以事件触发机制协调四种异构工具，每个工具只负责自己最擅长的子问题，同时被其他工具监控与校验。
- 通过**共享目标状态Ωt**和**闭环反馈**让各工具协同决策，而不是用固定规则融合输出。

### 2.2 四种工具的职责分工

| 工具 | 基础模型 | 职责 |
|---|---|---|
| 实例匹配工具（Instance Matching Tool） | 现成的匹配式跟踪器（如MCITrack，可替换） | 提供默认的框级定位，忠实保持初始目标实例身份 |
| 运动工具（Motion Tool） | 带Kalman滤波的SAM3 | 传播目标掩码得到“运动框”，为实例匹配工具提供搜索区域先验（重锚定） |
| 感知工具（Perception Tool） | SAM3图像分支 | 检测有效搜索区域内的相似实例，将两个工具的输出框归属到具体实例，产生二元冲突信号Ct |
| 重提示工具（Reprompt Tool） | VLM（Seed 2.0 Pro） | 仅在冲突持续K帧后触发，仲裁哪个工具更可靠，必要时更新SAM3的提示以重启掩码传播 |

### 2.3 关键技术细节与算法流程

- **事件触发式协同的闭环流程**（逐帧执行）：
  1. **运动工具**先在当前帧传播SAM3记忆，输出掩码并转化为运动框 b_m^t；若无效则回退到上一帧接受框 b̄_{t-1}，跳过感知阶段。
  2. 以运动框为中心、按扩张系数ρ扩展得到有效搜索区域 R_t 。
  3. **实例匹配工具**在该搜索区域内进行判别性匹配，输出跟踪器框 b_r^t 并更新内部状态 H。
  4. **感知工具**在 R_t 中检测目标实例，利用基于框中心和掩码包含关系的分配逻辑（Algorithm 1），判断 b_r^t 和 b_m^t 是否归属于同一物理对象，得出冲突信号 C_t。
  5. **默认决策策略**：无冲突时接受跟踪器框 b_r^t；有冲突时暂时接受运动框 b_m^t，以避免干扰物污染跟踪器状态。
  6. **持续冲突触发VLM**：若同一冲突连续K帧存在，调用VLM对“实例匹配工具 vs 运动工具”进行三方判决（Matching / Motion / Uncertain）。Matching则将 b_r^t 注入SAM3作为新框提示并以下一帧重启传播；Motion则保持运动框；Uncertain则不强制覆盖任一工具。
  7. 最终接受的框被提交回两个工具的状态，供下一帧使用。

- **Kalman滤波辅助掩码选择**（运动工具内部）：对SAM3掩码解码器产生的多个候选掩码，用恒定速度Kalman滤波预测框，按“掩码IoU分数 + 运动先验加权”的线性融合重新排序（如 W_m=0.15），最终生效的掩码在进入SAM3记忆前即被筛选，防止干扰物污染视频记忆；当目标不可见（objectness低于0.5）时清空KF状态。

- **感知工具分配算法（Algorithm 1，文字说明）**：将两个工具的框中心映射到搜索区域裁剪图的掩码网格，优先按“中心是否落在掩码内”选择最优实例，若掩码无法判定则回退到检测框包含关系；无匹配则返回空，仅在两个输入都匹配到非空实例且属于不同实例时才置冲突为1。

- **ACTrack-EM 多模态参数高效扩展**：
  - 将实例匹配工具的职责扩展为统一多模态跟踪器 D_mm，从冻结的SAM3图像编码器出发做参数高效微调，而运动、感知、重提示工具仍仅运行在RGB流上，从而将**模态适配与工具协同解耦**。
  - 关键技术：模态感知统一patch embedding（RGB用冻结的SAM3嵌入，辅助模态用各自初始化的专家，残差融合）、动态辅助模板（高置信度时按 ⌊n/5⌋ 帧间隔FIFO更新）、多路径流专属LoRA（初始模板流、动态模板流、搜索流分别使用各自的低秩适配路径）、分块因果时序注意力（后块可见前块，早期参考块不被后期搜索块更新，NLP前缀token置于初始模板前）。

## 6. 论文的主要结论与发现

- **"模型即工具"的智能体协同显著优于单一模型的规模扩展**：ACTrack在几乎所有RGB基准上打破之前SOTA，LaSOT AUC首次突破80（ACTrack-B为80.1，ACTrack-L为81.4），VastTrack上较之前最强方法AUC提升超过20个点（69.0 vs 44.2）。
- **工具协同的价值定位鲜明**：单独使用SAM3（含Kalman增强）只能达到约76.3 AUC，实例匹配工具单独使用为75.3 AUC，二者结合后达78.9，再引入感知与重提示工具后提升至80.1，说明跨工具冲突检测与稀疏语义仲裁带来了实质性增益。
- **多模态统一方面**：ACTrack-EM仅用30%可训练参数在LasHeR、VisEvent、TNL2K、DepthTrack上均取得最佳成绩（如VisEvent AUC 77.8，较此前最好方法提升超10个点；DepthTrack F-score 74.9），显示参数高效微调加工具协调的范式在统一多模态追踪上有很强的可扩展性。
- **重要设计权衡**：VLM仅需平均每序列约0.3–2.9次调用，即取得显著收益，说明稀疏语义仲裁是高效且有效的；而运动工具的强配置并不自动等于协同框架内的最优配置，表明协调机制的重要性高于某个工具单独的性能。

## 7. 优点

- **范式创新性强**：不需要设计新的跟踪网络，而是建立工具化/智能体式协调策略，思路新颖，与主流“更大更强的单模型跟踪器”路线互补，对基础模型在跟踪中的应用提供了新的视角。
- **模块化与可替换性设计良好**：实例匹配工具接口抽象清晰（初始化、匹配、状态同步），任何匹配式跟踪器皆可接入；泛化实验显示ODTrack-L接入ACTrack后AUC从74.0提升到78.1，MCITrack-L使用后从76.6提升到81.4，验证了框架的可迁移性。
- **事件触发机制带来效率优势**：无需让VLM或分割模型处理每一帧，日常定位交给高效视觉工具，高成本语义推理仅在持续冲突时启用，兼顾了精度与推理开销。
- **参数高效的多模态设计**：通过LoRA等多路径适配，把异构模态任务统一到一个冻结的SAM3视觉编码器内，参数效率显著优于大型统一跟踪器，且将模态适配与工具协调解耦，思路清晰。
- **实验体系完整**：覆盖长时/短时、低分辨率/高速运动、各种遮挡与干扰场景，以及五种模态的基准；消融研究细致、充分，能清楚归因每个组件所带来的增益。

## 8. 不足与局限

- **对SAM3与VLM的外部依赖**：感知与运动工具依赖SAM3的掩码质量与检测能力；若SAM3在某种目标类别（如非语义对象、极端变形）上系统性失效，感知与冲突信号的有效性会大幅降低。VLM的判决能力也未做系统敏感性分析（如不同VLM的差异、误判率影响）。
- **额外的计算与内存开销**：虽然推理速度优于SPMTrack-G，但相比单模型跟踪器（如MCITrack/LoRAT）增加了SAM3传播、SAM3图像分支检测、Kalman滤波等模块的固定计算与显存开销；VLM调用的延迟（约2.1秒/次）在实时性要求高的应用场景中可能成为瓶颈。
- **触发机制的延迟隐含失效风险**：冲突持续K帧才触发VLM，在这一窗口内默认策略暂时信任运动框；若SAM3已因记忆污染持续漂移，或目标在窗口中快速移动/消失后重现，延迟仲裁可能错过关键时机。论文未分析K取值在不同场景下的失败案例。
- **长期跟踪的误差累积未根治**：VLM仅在二元冲突下介入，但对“两个工具同时漂移到同一错误对象”的隐性联合失败缺乏检测手段，理论上仍存在不可纠偏的误差累积风险。
- **多模态扩展的适用范围有限**：ACTrack-EM的多模态能力集中在实例匹配工具内部，深度/热红外/事件等模态仅通过早期融合与LoRA路径参与训练，并未利用各模态在SAM3模态的扩展可能性；RGB- Language设置下的语言信息也仅作为NLP前缀token，语义仲裁仍依赖VLM，而事件等模态与语言联合的协同未深入探索。
- **部分报告与结论的证实完整性**：定性展示（Fig. 6、Fig. 7）只选取了少量代表性序列，未给出失败案例的分析；训练时长、数据预处理细节（如GOT-10k one-shot协议规避的具体原因）也未展开充分讨论。此外，所有实验均在作者设定下进行，缺少第三方复现或跨代码库验证。
