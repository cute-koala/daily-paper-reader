## 摘要
接触丰富的操作仍然具有挑战性，因为成功的控制依赖于通常仅从视觉中难以观察到的物理交互线索。最近基于触觉的世界动作模型联合建模未来的视觉观测和触觉信号以指导动作生成，但如何构造这些未来信息以使其被动作专家有效使用仍未得到充分探索。直接通过学习到的世界动作模型研究这一问题很困难，因为端到端行为纠缠了物理上无效的视觉未来、不可靠的预测、不准确或跨模态不一致的触觉预测，以及难以解读的未来到动作接口。为了使该接口可独立研究，我们引入了预言机视觉-触觉预视（OVTF），这是一个受控框架，提供来自模拟中验证的成功轨迹的配对RGB和触觉未来。通过固定未来提供者，OVTF隔离了接口并提出了一个更清晰的问题：如果未来是成功的且物理上可执行的，哪种表示能让动作专家吸收其益处？在OVTF中，我们提出了不对称相位局部未来记忆（AFM），其中视觉记忆读取未来视觉，每个触觉记忆联合关注自身的触觉流和相位对齐的未来视觉，并阻断跨触觉访问。我们将AFM与模态隔离未来记忆（IFM）进行比较，后者移除视觉到触觉的访问并独立处理每种未来模态。在UniVTAC仿真基准的七项任务上，AFM的平均成功率为32.0%，而IFM为23.7%，UniVTAC-ACT为14.9%。这一受控比较表明，选择性的相位对齐视觉-触觉路由提供了比完全模态隔离更具可操作性的未来到动作桥梁。

## Abstract
Contact-rich manipulation remains challenging because successful control depends on physical interaction cues that are often weakly observable from vision alone. Recent tactile world action models jointly model future visual observations and tactile signals to guide action generation, but how such futures should be structured for effective use by the action expert remains underexplored. Directly studying this question with learned world action models is difficult because end-to-end behavior entangles physically invalid visual futures, unreliable predictions, inaccurate or cross-modally inconsistent tactile forecasts, and an unreadable future-to-action interface. To make this interface independently studyable, we introduce Oracle Visuo-Tactile Foresight (OVTF), a controlled framework that supplies paired RGB and tactile futures from successful trajectories verified in simulation. By fixing the future provider, OVTF isolates the interface and asks a cleaner question: if the future is successful and physically executable, what representation allows the action expert to absorb its benefit? Within OVTF, we propose Asymmetric Phase-Local Future Memory (AFM), in which visual memory reads future vision, each tactile memory jointly attends to its own tactile stream and phase-aligned future vision, and cross-tactile access is blocked. We compare AFM with Modality-Isolated Future Memory (IFM), which removes visual-to-tactile access and processes each future modality independently. Across seven tasks on the UniVTAC simulation benchmark, AFM achieves 32.0% average success, compared with 23.7% for IFM and 14.9% for UniVTAC-ACT. This controlled comparison shows that selective phase-aligned visual-tactile routing provides a more actionable future-to-action bridge than complete modality isolation.

# 论文详细总结

## 1. 论文核心问题与整体含义（研究动机和背景）

接触丰富的机器人操作（contact-rich manipulation）本质依赖物理交互线索（接触时刻、形变、局部动力学），而这些线索往往难以从纯视觉观察中充分获得。近年来，触觉世界动作模型（Tactile World Action Models, WAMs）通过联合建模未来视觉观测与触觉信号来指导动作生成，试图弥补这一信息缺口。

然而，论文指出一个被现有研究忽略的关键问题：**未来信息不仅要预测准确，还必须通过一个动作专家（action expert）可以有效消费的接口来传递**。直接采用端到端学习的方式研究这个问题存在四大混淆因素：

- **物理无效的视觉未来**：视觉上连贯的后续帧可能违反接触力学，或描述机器人根本无法执行的轨迹。
- **未来分支信任不足**：预测不稳定或不准时，动作分支会习得忽略未来信息。
- **不准确或跨模态不一致的触觉预测**：预测触觉需要准确计时、形变和局部交互动力学，且与预测视频对齐极为困难。
- **糟糕的未来到动作接口**：即使未来正确，其编码形式也可能让动作分支无法有效读取。

基于此，论文提出了一个更干净的"解纠缠"研究问题：**如果未来是成功的且物理可执行的，什么样的表示能让动作专家真正吸收其益处？**

## 2. 方法论：核心思想、关键技术细节与公式

### 2.1 Oracle Visuo-Tactile Foresight（OVTF）框架

核心思想是**将"未来提供者"与"未来到动作接口"分离**：

- 未来提供者不再使用学习预测器，而是从**模拟验证成功的演示轨迹**中采样配对的 RGB 和左右触觉流的未来帧。
- Oracle 仅提供参考轨迹的视觉/触觉图像，**不提供未来动作、qpos、物体位姿或成功标签等额外特权信息**。

**相位定义（Phase Definition）**：对于动作窗口参考索引 $\tau_{ref}$，从 $\tau_{ref}$ 到终止帧 $T-1$ 之间均匀采样最多 100 帧，第 $i$ 帧的归一化剩余-水平相位为：

$$\phi_i = \frac{\tau_i - \tau_{ref}}{\max(1, T-1-\tau_{ref})}, \quad \phi_i \in [0,1]$$

rollout 时参考索引按 $\tau_{ref} = \min(\lfloor p/2 \rfloor, T-1)$ 确定。

### 2.2 未来编码与门控局部时间残差

- 未来视觉帧与触觉帧分别经**可训练的 ResNet-18**（以 UniVTAC-ACT* 编码器权重初始化）编码，输出三个序列 $H, L, R \in \mathbb{R}^{N \times 512}$。
- 序列经过**门控局部时间残差**增强：

$$X'_m = X_m + \tanh(g_m) \cdot \text{Conv}_{\text{DW}}(\text{LN}(X_m))$$

其中 Conv1d 为深度可分离卷积（kernel size 5, padding 2, 512 组），三个门控 $g_m$ **初始化为零**从而在初始时不引入残差干扰。

### 2.3 Asymmetric Phase-Local Future Memory（AFM）

AFM 包含 **12 个可学习的 512 维槽位**（4 个视觉、4 个左触觉、4 个右触觉），对应固定相位锚点 $C = \{0.125, 0.375, 0.625, 0.875\}$。注意力机制引入**高斯软相位先验**：

$$\text{score}^h_{k,i} = \frac{(q^h_k)^\top k^h_i}{\sqrt{64}} - \frac{(\phi_i - c_k)^2}{2 \times 0.18^2}$$

- 高斯项是软约束而非硬时间窗口；内容注意力仍可在所有有效源位置上选择。
- **路由模式**：$H \leftarrow H$，$L \leftarrow (L, H)$，$R \leftarrow (R, H)$，即视觉可被触觉读取，但左右触觉之间互相阻断；每个触觉槽位在拼接的自身触觉流与视觉序列上执行**单次联合注意力**（而非先读触觉再读视觉的级联）。
- 对比的 IFM 路由为 $H \leftarrow H$，$L \leftarrow L$，$R \leftarrow R$，仅去除视觉→触觉的可读边。

### 2.4 ACT 集成与训练目标

- 当前视觉/触觉观测由**冻结的 UniVTAC-ACT\* 编码器**处理；qpos 经冻结状态投影后输入策略。
- 未来槽位乘以零初始化的 tanh 门控；ACT 编码器记忆组织为 $[z_0 + s_1, q, s_2, \ldots, s_{12}, M_{\text{current}}]$。
- 解码器使用 50 个动作查询，输出 50×8 的归一化动作块，重叠块用 $\exp(-0.01 \times \text{age})$ 加权聚合。
- 唯一优化目标为**掩码动作 L1 损失**：

$$\mathcal{L}_{\text{action}} = \text{mean}(|\hat{a} - a| \odot \mathbb{1}_{\text{not-pad}})$$

槽位去相关为**非回传**的诊断项。训练时禁用 CVAE，潜变量 z 恒为零。

## 6. 论文主要结论与发现

1. **AFM Oracle 显著优于所有对比条件**：平均成功率 32.0%，相较 IFM（23.7%）提升 **8.3 个百分点**，相较 UniVTAC-ACT\* 基线提升 **17.1 个百分点**。
2. **选择性相位对齐的视觉→触觉路由更具可操作性**：即便三种模态记忆在进入 ACT 编码器后仍可再次交互，显式在接口处执行非对称融合依然带来增益——表明下游自注意力无法完全恢复隔离接口丢失的信息组织。
3. **模型确实在使用测试时未来内容**：Oracle 检查点在 Forced-Zero 下从 32.0% 降到 19.4%，说明成功并非来自额外参数。
4. **无未来输入时策略仍保持竞争力**：Zero-Train 达 20.0%，Forced-Zero 为 19.4%，均高于 14.9% 的基线——AFM 兼容的策略路径本身就有益。
5. **任务差异显著**：Put Shelf（54%）和 Pull Out Key（54%）是未来信息增益最大的任务；Insert Tube 的策略增益主要来自训练制度而非测试时未来（Oracle 与 Forced-Zero 打平，均 42%）；Insert Hole 是唯一 IFM 更高的任务，但所有条件均贴近成功率地板。

## 7. 优点

1. **问题构造精巧（解纠缠思想）**：OVTF 用固定未来提供者将"预测质量"与"接口可操作性"解耦，直接暴露了端到端 WAM 评估无法分离的接口问题——这是方法设计上最突出的亮点。
2. **控制变量极其干净**：AFM 与 IFM 共享未来源、相位锚点、记忆预算、数据、优化设置，唯一差异是视觉↔触觉的可读边；Forced-Zero 和 Zero-Train 为"是否使用未来信息"提供了双重确认方案。
3. **接口层面的洞见**：证明了即使在后续 transformer 可再次交叉注意力的情况下，接口处的显式组织依然重要——这对世界动作模型的架构设计有直接指导意义。
4. **诚实评估**：论文在任务级讨论中如实报告了未来信息增益不均甚至缺失（如 Insert Hole）的现象，没有为了整体指标美化结果。

## 8. 不足与局限

1. **仅仿真验证，无真实机器人实验**：所有结论建立在 UniVTAC 模拟平台上，真实世界中存在的传感器噪声、域迁移、图像分布漂移均未涉及，需谨慎推广至物理系统。
2. **Oracle 设定具有理想化假设**：成功轨迹配对且环境可重置这一前提在真实应用中未必成立——实际场景中无法保证"已知成功的未来"存在，因此 OVTF 的结论是接口层面的诊断性结论，而非可直接部署的算法。
3. **评估规模偏小**：每条件每任务仅 50 次 rollout，面对如 Lift Bottle（0%-16%）、Insert Hole（2%-8%）这类低成功率任务，置信区间较宽，AFM 与 IFM 间的差异可能不足以达到严格统计显著性。
4. **未报告训练时长与推理开销**：缺少对 RTX 4090 D 上单任务训练的实际耗时和 rollout 推理延迟的数据，实际部署成本不明。
5. **单基准依赖**：仅在 UniVTAC 一个平台上测试，缺少跨平台（不同仿真器或真实系统）的可迁移性证据。
6. **AFM 设计的特殊性问题**：每个触觉槽位执行"单次联合注意力"而非级联读取，这一设计选择的依据和替代方案（如先触觉后视觉、交叉注意力层数不同）的消融未充分展开。
