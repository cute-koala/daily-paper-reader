## 摘要
高光谱目标跟踪利用丰富的光谱信息，在复杂场景中为目标判别提供独特优势。然而，现有方法通常将高光谱图像视为RGB图像的多通道扩展，并以固定的波段顺序进行特征融合。这种方法导致模型依赖特定传感器配置，同时忽略了波段之间的流形关系，难以泛化到异构传感器。此外，波段的判别贡献会随目标属性和场景变化而动态改变，进一步限制了静态融合策略的表征能力。为此，我们提出了流形引导光谱提示网络（MSP-Net）。该网络首先通过图驱动的流形路由重建波段关系并形成自适应光谱分组，然后将分组后的光谱统计信息与模板外观联合集成，构建与目标相关的动态条件提示，从而增强目标特征同时抑制背景干扰。此外，随着跟踪的进行，光谱条件基于中间目标表征持续演化，使目标提示能够实时适应外观和场景变化。同时，利用可靠的历史状态约束目标定位和尺度波动，显著提高跨传感器跟踪的时间稳定性。在HOT2020和HOT2023上的实验表明，MSP-Net的AUC和精确度分别超过0.80和0.96，在异构传感器、目标变形和复杂背景条件下表现出卓越的鲁棒性。代码将发布在https://github.com/GGML668897/MSP-Net。

## Abstract
Hyperspectral object tracking leverages abundant spectral information to provide unique advantages for target discrimination in complex scenes. However, existing methods typically treat hyperspectral images as multi-channel extensions of RGB images, performing feature fusion in fixed band order. This approach leads to models dependent on specific sensor configurations while neglecting manifold relationships between bands, making generalization to heterogeneous sensors difficult. Moreover, the discriminative contribution of bands dynamically changes with target attributes and scene variations, further limiting the representational capacity of static fusion strategies. To address this, we propose the Manifold-Guided Spectral Prompt Network (MSP-Net). This network first reconstructs band relationships and forms adaptive spectral grouping through graph-driven manifold routing, then jointly integrates grouped spectral statistics with template appearance to construct target-related dynamic conditional prompts, enhancing target features while suppressing background interference. Furthermore, as tracking progresses, spectral conditions continuously evolve based on intermediate target representations, enabling target prompts to adapt in real-time to appearance and scene changes. Meanwhile, reliable historical states are used to constrain target localization and scale fluctuations, significantly improving temporal stability in cross-sensor tracking. Experiments on HOT2020 and HOT2023 demonstrate that MSP-Net achieves AUC and Precision exceeding 0.80 and 0.96, respectively, exhibiting exceptional robustness under heterogeneous sensors, target deformation, and complex background conditions. The code will be released at https://github.com/GGML668897/MSP-Net.

  - **静态融合策略**：波段的判别贡献会随目标属性和场景变化而动态变化，静态的波段融合方式限制了模型的表征能力。
- **整体含义**：本文提出了 MSP-Net（Manifold-Guided Spectral Prompt Network），将高光谱跟踪从“固定光谱压缩”范式转向“流形感知 + 动态提示演化”范式，以解决光谱信息丢失、特征滞后和跟踪漂移三大问题。

### 2. 提出的方法论：核心思想、关键技术细节

**核心思想**：联合建模波段间的流形结构、目标条件化信息与时序状态，实现高光谱跟踪中“光谱分组自适应 + 提示动态演化 + 定位自适应稳定”的统一框架。

**网络由四个核心组件构成**：

**（1）GMSR（Graph-Driven Manifold Spectral Routing）模块——流形感知的自适应光谱分组**
- 将每个光谱波段视为图中的一个节点，通过自适应平均池化获得波段节点特征；
- 使用动态高斯核函数计算波段间的特征相似度，构造邻接矩阵，刻画波段间的流形结构：
  - \(A_{i,j} = \exp(-\|V_i - V_j\|_2^2 / (2\zeta(\sigma)^2 + \epsilon))\)
- 对邻接矩阵进行对称归一化（\(D^{-1/2}AD^{-1/2}\)）以稳定梯度传播；
- 通过图卷积网络（GCN）在流形空间内传播和聚合节点信息，获得更新的流形节点特征；
- 路由策略：训练阶段使用 Gumbel-Softmax 硬分配，推理阶段切换为 Softmax 软分配，以得到更平滑稳定的分组；
- 按分组进行加权聚合得到各组代表性特征，并投影生成 MoE（Mixture-of-Experts）权重，用于后续加权融合和提示生成。

**（2）DSCPM（Dual-Stream Spectral-Conditioned Prompt Modulation）模块——双流光谱条件提示调制**
- 对每个光谱分组提取多维统计信息（均值 + 标准差），构成分组光谱条件向量，编码流形的低频全局上下文和高频光谱波动；
- 对模板特征提取均值 + 最大响应，构成模板条件向量，编码目标的几何和纹理特征；
- 将分组条件、模板条件与 MoE 权重拼接，得到 97 维解耦双流条件向量；
- 条件向量经 Prompt Generator 映射为动态提示向量 P，以输入图像 tokens 为 Query、提示向量为 Key/Value 进行跨注意力调制；
- 引入余弦相似度门控（CosGate）：计算输入 tokens 与提示中心的余弦相似度，经 Sigmoid 生成空间掩码，选择性增强目标相关区域、抑制背景干扰；
- 最终输出：\(X_{out} = X_{in} + \alpha (M \odot X_{attn})\)。

**（3）DSCE（Decoupled Spectral-Condition Evolution）策略——解耦光谱条件演化**
- 目标：解决长时跟踪中首帧光谱先验与当前目标状态不一致导致的提示退化问题；
- 在骨干网络第 l 层，从联合 tokens 中切分出最新模板 tokens Z^(l)，提取当前帧目标的最新表征；
- 在预设的更新层（Ω = {3, 6, 9}）更新条件向量 \(C_{cond}^{(l)}\)，形成“参数无关的在线提示校准闭环”；
- **训练阶段**：条件演化机制保持静止（固定使用初始条件），确保骨干网络稳定收敛；
- **推理阶段**：动态激活条件演化，定期刷新提示，无需引入额外参数或在线微调。

**（4）TMMA（Temporal Morphology Memory-Adaptive Post-processing）模块——时间形态记忆自适应后处理**
- 通过“空间跳跃锁定”判断当前预测是否因相似干扰而发生异常位置突变（\(I_{jump}\)）；
- 仅对高置信度、无突变帧的目标形态（长宽比、面积）存入滑窗记忆库（K=8）；
- 计算形态统计量（长宽比方差 \(V_r\)、面积最大最小波动率 \(F_a\)），自适应调节尺度惩罚因子 \(\eta_{size}\)：
  - 目标持续明显形变时 \(\eta_{size} = 1.00\)（放宽限制）；
  - 否则保持 \(\eta_{base} = 0.99\)（抑制背景漂移）；
- 在保持对真实形变的适应能力与抑制相似干扰引起的漂移之间取得平衡。

6. MSP-Net 在推理速度（34.71 FPS）与精度之间取得了良好平衡，具备实时应用潜力。

### 7. 优点

- **思想创新**：首次将高光谱波段分组从固定/权重范式提升为“流形自适应路由”范式，兼顾物理结构感知与数据自适应性；
- **机制协同设计**：GMSR（空间/光谱表征）→ DSCE（时间演化）→ DSCPM（条件调制）→ TMMA（后处理稳定化）形成完整闭环，各组件互补明确；

- **跨域性能不均衡**：在 HOT2024 的 VIS 和 RedNIR 模态上性能明显落后于部分对比方法（如 AUC 仅 0.4819/0.5044），说明方法对光谱维度缩减后的模态信息丢失敏感，复杂光谱路由可能干扰细粒度空间对齐；
- **未做到全面最优**：在 IMEC25 上 AUC（0.7381）低于 ProFit（0.7540）；在 HOT2023 VIS 模态的 DP@20 也略低于 ProFit，并非所有指标全面领先；
- **零样本泛化受限**：论文自身承认，在未见过的背景、目标材料及传感器光谱响应差异下，流形拓扑可能发生显著变化，动态图构建可靠性下降，未来需改进对未知材料和极端环境的零样本泛化能力；
- **训练/测试设置的不对称性**：IMEC25 为单独训练和评估，无法完全反映方法的零样本跨域能力；
- **计算复杂度非最低**：FLOPs（73.01G）高于 Trans-DAT（30.3G）和 HOT-MoE（58.37G），在资源受限的边缘设备上部署可能存在压力；
- **后处理依赖**：TMMA 的调节效果依赖置信度阈值和记忆库参数（如 K=8、λ=0.5 等），这些超参数在不同场景下的普适性有待进一步验证；
- **训练时长未报告**：未说明 30 个 epoch 的具体训练时间，难以评估训练效率。
