## 摘要
大规模部署现代视频跟踪器受限于基于RGB目标检测器的计算成本。为此，我们提出了MVTrack，一种直接对H.264比特流进行操作的超快移动目标跟踪器。MVTrack将轻量级运动矢量场检测器MVDet与极简运动学关联模块MVLink相结合。在VIRAT数据集上，MVTrack在性能上超越YOLO26n，同时参数减少60倍，FLOPs减少40倍，CPU延迟降低8.6倍。这些结果表明，仅凭压缩视频数据即可实现准确且可扩展的监控跟踪，从而无需进行像素重建。

## Abstract
Deploying modern video trackers at scale is bottlenecked by the computational cost of RGB-based object detectors. To this end, we present MVTrack, an ultrafast tracker for moving objects that operates directly on H.264 bitstreams. MVTrack combines MVDet, a lightweight detector for motion vector fields, with MVLink, a minimalist kinematic association module. On VIRAT, MVTrack outperforms YOLO26n while using 60$\times$ fewer parameters, requiring 40$\times$ fewer FLOPs, and reducing CPU latency by 8.6$\times$. These results demonstrate that compressed video data alone can enable accurate and scalable surveillance tracking, thereby bypassing the need for pixel reconstruction.

- **研究动机**：现代视频监控规模巨大，但基于RGB的检测器在解码像素帧后计算开销极高，难以在边缘CPU设备上大规模实时部署。传统系统即使利用运动矢量加速中间帧推理，仍周期性依赖RGB网络恢复语义信息，形成“慢-快”混合范式。
- **核心观察**：对于监控场景中的移动目标跟踪，主要信号是运动而非外观。压缩码流中的运动矢量（MVs）本身就是目标位置与移动信息的廉价表示，静态内容位移接近零，无需重建像素即可完成跟踪。
- **核心主张**：提出“始终快速”（always-fast）范式，完全抛弃RGB通路，仅以H.264码流中的运动矢量和宏块分区信息作为感知信号，即可实现高效、可扩展、隐私保护的目标跟踪，为大规模监控分析提供新的低成本路径。

## 2. 论文提出的方法论

- **总体框架**：MVTrack由两部分组成：
  - **MVDet**：轻量级、无锚框（anchor-free）的检测器，输入为每个16×16 patch构造的3通道张量（水平运动矢量 dx、垂直运动矢量 dy、宏块分区模式 q），检测移动目标中心、尺寸和偏移。
  - **MVLink**：基于ByteTrack的运动学关联模块，专门处理目标静止时运动矢量消失导致的轨迹中断问题。
- **关键设计细节**：
  - **输入表示**：将H.264宏块运动矢量聚合到16×16 patch，归一化并裁剪；宏块分区模式通过可学习嵌入映射为连续向量并与MVs拼接。
  - **Temporal Gate（时间门控）**：改进ConvGRU，用单门控、EMA风格的递归更新机制，仅需0.5K参数、4.2 MFLOPs，有效抑制瞬态噪声并积累运动证据。
  - **网络结构**：编码器-解码器结构，仅一次池化下采样，瓶颈处使用三个空洞卷积扩大感受野，解码器上采样并跳连。三个预测头输出中心热图、尺寸图、偏移图。
  - **标签与损失**：修改版CenterNet热图标签，采用各向异性高斯，3×3回归区域；损失函数包含焦点损失、掩膜ℓ1损失和CIoU损失。
  - **MVLink**：将未匹配轨迹分类为静止（Stopped）或丢失（Lost），利用尺度归一化速度/加速度估计（公式(3)），保持静止轨迹的位置窗口，避免轨迹漂移，减少身份切换。

- **关联模块设计巧妙**：针对运动域特有静止问题设计MVLink，从运动学特征区分静止与丢失，简单有效。

## 8. 不足与局限

- **数据集单一**：仅在VIRAT-DIVA-V1上验证，场景类型和对象类别有限（行人、车辆），缺乏对密集人群、恶劣天气、夜间等复杂环境的测试。

- **空间分辨率受限**：16×16 patch的粒度限制了小目标定位精度，且每个单元格只能回归一个目标，重叠目标可能合并。
