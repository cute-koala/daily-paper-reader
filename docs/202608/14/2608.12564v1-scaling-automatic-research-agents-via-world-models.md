## 摘要
自动化实证研究是人工智能的一个长期方向。最近的自动研究（AutoResearch）代理使这一目标触手可及，因为现代LLM表现出独立实现解决方案并从执行结果中学习的能力。在这些成果背后，后训练（尤其是RL）起着核心作用。在本文中，我们发现了为这些代理扩展RL时的根本张力：每个AutoResearch轨迹的两个组成部分（代理生成和环境执行）以非常不同的方式扩展，因为所有生成通过批处理共享计算，而每次执行占用其专用沙箱和真实机器时间。因此，环境执行主导了训练成本，并随着轨迹增长成为瓶颈。为了解决这种张力，我们提出了World Model RL（WMRL），用世界模型代替环境执行，以消除这一瓶颈。此外，世界模型可能不完美，因为其奖励会被偏差和噪声污染。因此，我们进一步为WMRL配备了两个缓解措施：在线去偏和逆方差去噪，分别抵消偏差和抑制噪声。理论上，我们证明了WMRL的两种缓解措施都严格提高了收敛保证。实证上，WMRL在各种任务和不同代理规模下将训练加速了3-4倍，同时超过了标准RL基线的性能。此外，我们后训练的4B和9B代理在保留基准上优于48B和120B的更大规模开放权重代理。除了AutoResearch，WMRL还迁移到后训练具身VLA策略，这表明了我们方法的通用性。

## Abstract
Automating empirical research is a long-standing direction of AI. Recent automatic research (AutoResearch) agents bring this goal within reach, as modern LLMs show the capability to independently implement solutions and learn from the execution outcomes. Behind these gains, post-training (especially RL) plays a central role. In this paper, we identify a fundamental tension when scaling RL for these agents: the two components of every AutoResearch trajectory (agent generation and environment execution) scale in very different manners, since all generation shares compute through batching, while each execution occupies its exclusive sandbox and real machine time. As a result, the environment execution dominates the training cost and becomes the bottleneck as trajectories grow. To resolve this tension, we propose World Model RL (WMRL), which replaces environment execution with a world model to remove this bottleneck. Additionally, the world model can be imperfect, as its rewards are corrupted by bias and noise. Therefore, we further equip WMRL with two mitigations, Online Debiasing and Inverse-Variance Denoising, which offset the bias and suppress the noise respectively. Theoretically, we prove that both mitigations of WMRL strictly improve the convergence guarantee. Empirically, WMRL accelerates training by 3-4x on various tasks at different agent scales, while exceeding the performance of standard RL baselines. Moreover, our post-trained 4B and 9B agents outperform much larger open-weight agents of 48B and 120B on held-out benchmarks. Beyond AutoResearch, WMRL also transfers to post-training embodied VLA policies, which demonstrates the generalizability of our method.

## 2. 方法论

### 2.1 基础框架：GRPO 与奖励替换
- 采用组相对策略优化（GRPO）：每组采样 n≥2 条独立轨迹，执行后得到分数 r(τᵢ)，组内归一化为优势 Aᵢ，形成策略梯度估计：
  - ĝ = (1/n) Σ Aᵢ sᵢ，其中 sᵢ = ∇θ log πθ(τᵢ)。
- WMRL 将真实执行替换为世界模型预测得分 r̂(τ)，构成带偏噪声的奖励模型：
  - **r̂(τ) = r(τ) + b(τ) + ξ(τ)**，其中 b 为系统偏差（|b| ≤ B），ξ 为零均值噪声（标准差 ≤ σ）。
- 世界模型采用与代理相同的骨干网络，通过 prompt 式模拟（不微调），输入任务上下文与解决方案，输出执行结果的预测，批处理成本与生成相当，从而消除执行瓶颈。

### 2.2 锚定信号（Anchor Signal）
- 引入小幅真实执行流：每步约 10% 的组（anchor groups）同时由世界模型与真实环境评分，得到分数对 P = {(r̂ⱼ, rⱼ)}，为两种修正机制提供数据支撑。

### 2.3 机制一：在线去偏（Online Debiasing）
- 在分数对上拟合**保序回归（isotonic regression）**映射 f̂ = argmin Σ (f(r̂ⱼ) − rⱼ)²，将世界模型输出重新校准到真实分数尺度。
- 映射随新 anchor 数据不断更新（每 64 对重拟合一次），以跟踪训练过程中的漂移。

### 2.4 机制二：逆方差去噪（Inverse-Variance Denoising）
- 融合两条梯度流（真实执行锚组 g_E 与世界模型组 g_WM），按**逆方差加权**使融合方差低于任何单一流：
  - ĝ = (V_E⁻¹ g_E + V_WM⁻¹ g_WM) / (V_E⁻¹|G_E| + V_WM⁻¹|G_WM|)。
- 方差比 ρ = V_WM/V_E = 1 + cσ²，其中 c 通过预热阶段的残差 η̂²_cal 标定，σ² 由校准分数与真实分数的均方残差 η̂² 在线估计；权重自适应——当世界模型质量恶化时，锚组权重自动上升，WMRL 退化为标准 GRPO，避免被损坏信号带偏。

### 2.5 理论保证
- **定理 3（纯世界模型 RL 的收敛）**：偏差项 O(M²B²) 与方差项 O(γV_WM) 构成不可消除的误差地板，训练无法通过增加步数消除。
- **定理 4（WMRL 的收敛）**：偏差项变为收缩项 O(M²B² / (1+T/T₀))，随训练趋于零；方差项降为调和形式 O(γV_WM / (1+V_WM/V_E))，严格优于单一流。
- 两项修正各自消除一个误差项，且融合权重对估计误差二阶不敏感，理论保证严格优于纯世界模型训练。

## 6. 主要结论与发现

1. **执行瓶颈可消除**：WMRL 以世界模型替代真实执行，使执行侧成本以与生成侧相同的方式摊还，训练加速 3–4 倍。
2. **廉价信号不损害性能**：WMRL 在每项基准上都超过同规模真实环境 GRPO：4B 提升 0.9–2.8 分，9B 提升 1.6–4.7 分。
3. **小模型可超越大模型**：后训练的 4B 代理（MLE 28.8、DS 16.4）超过 Kimi-48B-A3B（MLE 17.3、DS 8.1）；9B 代理（MLE 32.8、DS 21.6）超过 Nemotron-120B-A12B（MLE 31.7、DS 20.5）。
4. **两种修正缺一不可**：去偏单独贡献 2.2–2.8 分，去噪单独贡献 0.9–1.7 分，两者结合贡献 2.9–4.8 分，互补而非冗余，与理论中"一者去偏差项、一者去方差项"的预测一致。
5. **跨领域泛化成立**：VLA 上 WMRL 将总体成功率从 GRPO 的 38.3% 提升至 41.2%，在未见过的初始状态上提升幅度最大。

## 8. 局限性

- **世界模型构建开销未完全透明**：论文详细报告了训练阶段 GPU 成本，但世界模型本身的构建与验证开销（如何选定 prompt 形式、如何确认其作为评分器的可靠性）未纳入成本核算；若将世界模型的开发调试成本计入，加速优势会有所稀释。
- **手工切分测试集引入人为因素**：作者公开承认 MLE-Dojo 测试集是手工划分而非沿用官方划分，理由是原始 MLE-Bench 测试集存在死任务与 medal 指标缺陷；这一决策合理且坦诚，但任何手工划分都可能隐含对特定类别分布的偏好，削弱了与外部已有结果直接对比的公正性。
- **理论假设与实际偏差之间的缝隙**：定理 4 依赖锚点数量足够、偏差项有界、世界模型噪声近似零均值等假设；在真实数据中，世界模型的偏差 b(τ) 可能是输入依赖且非有界的，保序回归估计 f̂ 的误差也可能与假设不符，理论结论只能视为理想情形下的上限保证。
- **VLA 验证广度有限**：具身实验仅在 LIBERO-Long 一个任务族、1B 一个策略规模上验证；未能展示在不同具身环境、不同动作空间或真实物理世界中的表现，跨领域推广性仍需更多证据。
- **训练细节缺失**：未报告具体训练步数、批大小、锚组更新频率之外的超参数、多次随机种子的稳定性等；统计稳健性信息不完整，难以判断报告分数是否为最优种子下的结果。
- **执行侧"瓶颈"的定义局限于模拟环境**：论文所消除的执行瓶颈是沙箱化代码执行与 GPU 训练；但现实中许多 AutoResearch 场景的执行成本还包括物理实验时间、人工验证或 API 调用，世界模型对这些成本的替代效果尚未讨论。

- **理论框架的拓展**：将偏差有界、噪声零均值假设推广到更一般的随机过程；考虑世界模型与策略相互影响的动态博弈，建立联合收敛理论。
- **统一 AutoResearch 全生命周期**：将世界模型不仅用于训练阶段的奖励替代，也延伸到研究想法筛选、实验设计、结果解读等环节，构建端到端的"科研模拟器"。

## 10. 总结评价

WMRL 是一篇问题意识极强、工程设计闭环、理论实证相互印证的高质量工作。它没有简单地将"世界模型"用作某种玄学加速器，而是精确拆解了 AutoResearch RL 中"生成可摊还、执行不可摊还"的结构性矛盾，并用两个数学上可解释的修正机制（保序回归去偏 + 逆方差融合去噪）把廉价但有偏的世界模型信号校准为安全可用的训练信号。

其最值得称道之处在于**对"免费信号"代价的诚实回答**：世界模型并非免费午餐，它带来偏差与噪声；但论文证明——只要保留一小股真实执行流作为锚，偏差可收缩、方差可调和，最终性能反而优于全真实 RL。这一"用小成本锚定大世界模型"的思想不局限于科研代理，对任何存在昂贵评估器的 RL 场景（机器人操作、分子模拟、推荐系统等）都有启发意义。

论文的主要短板在于训练细节披露不足与手工构建测试集带来的可比性损失；此外，世界模型本身的开发成本被置于叙事之外，使得"3–4× 加速"更接近运行时间而非全流程成本。但整体而言，这项工作在"可扩展 AutoResearch 后训练"方向上迈出了坚实一步，理论深度与实验完备性均达到顶尖会议水准，值得作为该方向的标杆性参考文献。
