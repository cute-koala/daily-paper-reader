## 摘要
通用机器人策略旨在将多模态观察和语言任务指令映射到跨多种任务的动作。然而，现有方法通常将未来表示为固定的短视频-动作块。这种短期未来捕获用于动作执行的局部场景演化，但并未明确描述指定任务应如何从当前阶段进展到下一阶段的阶段级未来。因此，我们区分了机器人操作中两个互补的未来：用于捕获局部场景演化的短期物理未来和用于表示任务进展的阶段级语义未来。我们引入了JEPA-WAM，它通过Stage-JEPA（一种基于目标条件的联合嵌入预测架构（JEPA）预测器）增强了基于Motus的世界动作模型（WAM）。给定当前观察和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机环境中的50个RoboTwin 2.0任务上，JEPA-WAM实现了90.25%的总体成功率，并将成功轨迹中的平均执行步数相对于最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：通用机器人策略（generalist robot policies）通常将未来表示为固定的短视频-动作块（short video-action chunk），这类“短期物理未来”能捕获局部场景演化，但无法显式描述“任务应如何从当前阶段进展到下一阶段”这一**阶段级语义未来**（stage-level semantic future）。
- **现有方法的不足**：
  - 视觉-语言-动作模型（VLA）直接做 observation-to-action 映射，不显式建模环境应如何随任务推进而变化；
  - 世界动作模型（WAM）虽联合预测未来视频和动作，但用密集时间块表示未来，将下一任务相关状态或关系变化隐含在密集展开中，缺乏显式的任务进度目标。
- **核心洞察**：机器人操作需要区分两种互补的未来——**短期物理未来**（局部视频-动作演化）与**阶段级语义未来**（任务进展的下一目标状态）。JEPA 类架构天然适合做后者：在表示空间中预测目标状态潜表示，而不是逐像素重建，从而对低级外观不敏感。
- **整体含义**：该工作为“预测任务进展”提供了一种新的建模思路——将阶段级潜目标注入 WAM，作为内部进度条件来引导局部视觉和动作生成。

## 2. 论文提出的方法论

**核心思想**：JEPA-WAM = Motus 基础 WAM + Stage-JEPA 分支。Stage-JEPA 从当前观测和任务指令中预测“下一任务阶段”的潜表示，并通过门控接口注入 WAM 的视频流，作为视频预测和动作生成的内部条件。

**两阶段训练流程**：

- **Stage I：训练 JEPA 预测器**
  - **阶段对自动构造**：无需人工阶段标签。用冻结的 V-JEPA2 编码器对每隔 8 帧的候选中心编码 64 帧片段，得到 clip 级与 token 级表示；用局部窗口内的表示变化分数（式 5-6）和 temporal NMS（半径 r=3，最多 K=5 个关键帧）自动推断阶段边界；每个当前帧 t 与下一边界 b_{i+1} 构成密集训练对（式 8）。
  - **目标条件阶段预测**：Stage-JEPA 用冻结 V-JEPA2 编码器 + 可训练的 V-JEPA2 predictor 初始化 + 指令跨注意力适配器。输入当前 64 帧切片和下一阶段 64 帧切片，分别编码，预测器输出 token 级预测，pool 并归一化后用余弦损失对齐：
    - L_stage = 1/B Σ [1 − (ẑ_target)^T z_target]（式 9）
- **Stage II：训练阶段条件 WAM**
  - 冻结 Stage-JEPA，只训练 WAM 和条件接口，避免细节损失干扰语义目标。
  - WAM 用 Motus（Mixture-of-Transformers：视频专家、动作专家、视觉语言理解专家），视频专家基于 Wan2.2 初始化，理解专家用冻结 Qwen3-VL，使用 Tri-modal Joint Attention 交换信息。
  - **门控注入**：将 Stage-JEPA 输出的 token 均值池化后经 MLP 映射到视频 token 维度，得条件向量 h_t；全局标量门 α = 0.2σ(β)（β 可训练，初始为 0.02），注入方式为 X̃_vt = X_vt + αh_t（式 10-12）。
  - **总损失**：L = L_video + L_action + L_reg，其中 L_reg = λ_g α² + λ_ρ(ρ − ρ₀)²，ρ = ‖αh_t‖/‖X_vt‖ 控制注入幅度（式 13-14）。
- **闭循环推理**：维护因果 64 帧观察缓冲，预测阶段潜 → 注入 WAM → 生成有限视界视频未来和动作块 → 执行并重规划。阶段边界只存在于训练时，推理时不依赖目标切片或未来帧。

## 6. 论文的主要结论与发现

- JEPA-WAM 在 50 个 RoboTwin 2.0 任务上的 **总体成功率为 90.25%**（clean 91.42%，randomized 89.08%），在 clean 下 5/7 个语义类别、在 randomized 下 6/7 个类别超过 Motus。
- **执行效率提升**：平均 episode 长度从 156.28 降至 132.80（整体降低 15.02%）；仅统计成功轨迹时，从 79.57 降至 74.82 步（**降低 5.97%**），说明阶段引导能减少冗余纠正动作。
- 消融实验表明：JEPA 阶段条件通路和“注入未来潜到视频 token”都是关键设计；门控正则提供额外稳定约束；Stage-I 的具体配对训练带来进一步但较小的增益。
- 阶段级语义未来是短期世界-动作预测的有效补充，尤其对交接、目标放置、装箱等需要显式状态/关系变化的任务收益最明显。
- 真实世界 LIFT2 实验中 JEPA-WAM 平均任务进度分 48.00，高于 π0.5 的 41.50，初步验证了方法的可迁移性。

## 7. 优点

- **问题定义清晰且具有启发性**：明确提出“短期物理未来”与“阶段级语义未来”的区分，为机器人未来建模提供了新视角。
- **免人工阶段标注**：利用冻结 V-JEPA2 特征变化 + temporal NMS 自动推断阶段边界，训练监督可扩展。
- **表示空间预测而非像素预测**：用 JEPA 潜表示作为进度目标，避免了像素级预测对表观细节的过度关注。
- **两阶段训练解耦**：先学语义目标，再冻结之学习局部实现，防止细节损失侵蚀语义表示。
- **轻量注入设计**：全局标量门 + 正则约束（α 和 ρ）让阶段条件以可控幅度注入视频流，不破坏 WAM 原生表示。
- **实验体系较完整**：大范围模拟、多类别语义分解、消融、效率分析、真实世界验证均有覆盖，附录提供完整 task-level 结果。

## 8. 不足与局限

- **部分类别提升有限或略降**：Acquisition & lifting 类别 JEPA-WAM 略低于 Motus（clean 92.60 vs 94.20）；Articulated/device interaction 类别同样略低（90.71 vs 93.57），说明对依赖精确接触/机构约束的任务，间接阶段信号不够充分。
- **阶段边界自动推断的可靠性**：附录诊断显示平均阶段长度 44.74 帧，81.72% 的阶段间隔短于 64 帧 V-JEPA2 输入窗口，导致中心切片频繁跨阶段或与目标切片重叠——这种离线监督与推理时纯因果预测之间存在分布偏差风险。
- **Stage-I 收益有限**：消融显示不做 Stage-I 训练仍能达到接近性能，说明很大程度上依赖 V-JEPA2 预训练先验，任务特定阶段目标的增量贡献需进一步验证和强化。
- **真实世界验证偏弱**：仅 2 个任务、单基线对比、20 次/任务的样本量，统计效力有限。
- **推理开销**：64 帧 V-JEPA2 输入 + 潜预测 + 视频扩散生成带来较高延迟，论文也承认未来需要降低 WAM 推理延迟以提高闭环控制频率，这限制了高频控制场景的实时性。
- **评估偏差风险**：模拟评估的基线数值来自外部论文而非统一重训，可能受训练数据、超参、随机种子等影响；任务成功指标未报告逐任务方差。
