## 摘要
复杂视频目标分割需要在严重遮挡、消失和重现的情况下进行稳健的目标传播。尽管SAM3提供了强大的可提示掩码传播，但统一的推理路径对于视觉证据不足的微小目标和依赖显式属性来识别身份的语义主导目标仍然不可靠。为此，我们提出了VOS-Agent，一个协作框架，保留SAM3作为共享的密集分割模块，并根据目标特征有条件地激活专门的智能体。目标感知与路由智能体将每个序列分配给常规、微小或语义主导路线。微小目标由视觉跟踪智能体通过置信度感知的框提示支持，而语义主导目标则由基于MLLM的语义智能体通过描述引导的定位和候选验证来处理。在MOSEv2测试集上，VOS-Agent在官方$\mathcal{J}\&\dot{\mathcal{F}}$指标上达到69.82%，在ECCV 2026第八届LSVOS挑战赛的MOSEv2赛道中排名第一。

## Abstract
Complex video object segmentation requires robust target propagation under severe occlusion, disappearance and reappearance. Although SAM3 provides strong promptable mask propagation, a uniform inference path remains unreliable for tiny targets with insufficient visual evidence and semantic-dominated targets whose identities depend on explicit attributes. To this end, we present VOS-Agent, a collaborative framework that retains SAM3 as the shared dense segmentation module and conditionally activates specialized agents according to target characteristics. A Target Perception and Routing Agent assigns each sequence to a regular, tiny, or semantic-dominated route. Tiny targets are supported by a Visual Tracking Agent through confidence-aware box prompts, while semantic-dominated targets are handled by an MLLM-based Semantic Agent through description-guided localization and candidate verification. On the MOSEv2 test set, VOS-Agent achieves 69.82% on the official $\mathcal{J}\&\dot{\mathcal{F}}$ metric and ranks first in the MOSEv2 Track of the 8th LSVOS Challenge at ECCV 2026.

- **研究背景**：半监督视频目标分割（VOS）旨在根据首帧掩码，在后续帧中持续分割同一目标。传统方法（如XMem、Cutie、SAM2、SAM3）在常规基准上表现优异，但在复杂场景（MOSEv2）中仍面临严峻挑战，包括严重遮挡、目标消失与重现、微小目标、拥挤场景、相似干扰物、恶劣天气与光照等。
- **核心问题**：作者指出，尽管最强的SAM3模型具备强大的可提示掩码传播能力，但其**统一的推理路径**在两类目标上不可靠：
  - **微小目标**：仅占据极少像素，缺乏足够视觉证据，难以维持稳定长程对应，容易受背景干扰和累积定位误差影响。

- **核心含义**：这两种失败模式本质源于SAM3仅依赖提示条件视觉特征和时序记忆进行传播，当目标表示欠分辨或视觉模糊时，缺乏足够证据确定位置或保持实例身份。因此，需要针对不同目标特性引入专门化的推理路径，而不是采用单一推理流程。

### 2. 论文提出的方法论

- **总体框架**：VOS-Agent 是一个协作式多智能体框架，由四个组件构成：
  - **Target Perception and Routing Agent（目标感知与路由智能体）**
  - **SAM3 Segmentation Agent（SAM3分割智能体）**
  - **Visual Tracking Agent（视觉跟踪智能体）**
  - **MLLM-based Semantic Agent（基于多模态大模型的语义智能体）**
- **核心思想**：将目标分类为常规、微小、语义主导三类，并路由到不同处理路径。SAM3作为共享的密集分割模块，负责生成像素级掩码；专用智能体在目标定位和身份推理层面提供辅助提示，无需微调SAM3。
- **关键技术细节**：
  - **路由判定**：
    - 空间尺度：计算目标初始掩码面积与图像面积之比 `r_area = A(M1)/A(I1)`，若 `r_area < τ_area` 则判定为微小目标。
    - 语义独特性：对非微小目标，使用MLLM分析参考裁剪和上下文，判断是否需要显式语义属性区分干扰实例，输出 `s_sem ∈ {0,1}`。
    - 最终路由：`r_area < τ_area` → tiny；否则若 `s_sem=1` → semantic；否则 → regular。
  - **SAM3分割智能体**：承担掩码传播和时序记忆构建，常规目标直接传播；对于微小或语义目标，接受来自辅助智能体的边界框提示，并据此精化当前掩码、更新条件状态。
  - **视觉跟踪智能体（以SUTrack实现）**：
    - 用首帧目标裁剪作为静态模板，并在线维护动态模板。
    - 在上一帧结果周围裁剪搜索区域，递归估计目标框和置信度。
    - 与SAM3的原生掩码框计算IoU作为一致性度量。
    - 仅当两预测不一致（IoU < τ_iou）且跟踪置信度足够高（≥ τ_conf）时，才接受跟踪框作为提示，以纠正SAM3传播。
  - **语义智能体（以Qwen3.5-397B-A17B实现）**：
    - 首先生成目标的可判别性描述（如文本、标志、颜色等）。
    - 在每帧执行语言引导定位，得到候选框。
    - 计算与SAM3原生掩码框的IoU，若不一致，则从首帧目标与当前帧两个候选框（SAM3框与语义定位框）中提取裁剪，让MLLM判定哪个候选与原始目标及描述更一致。
    - 仅当语义候选被判定为更符合时，才将语义边界框作为提示输入SAM3。
- **公式与算法流程**：通过 IoU 计算、阈值比较、条件判断（`η`标志）控制辅助提示的激活，确保只在必要时干预。
