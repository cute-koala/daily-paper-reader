## 摘要
鲁棒的机器人控制受益于显式建模状态转换，但视频生成世界动作模型（WAM）引入了显著的部署成本。现有的潜在WAM避免了显式的未来生成，但往往压缩预测表示或将预测建模与用于动作生成的表示分离。我们提出了JEPA-WAM，一个构建在预训练V-JEPA空间中的潜在WAM，通过共享预测器将潜在状态转换预测与连续动作生成耦合。JEPA-WAM预测一个空间结构的联合当前-未来目标，该目标捕获当前与未来观测之间共享任务的视觉时序结构，同时保留稠密的补丁级对应关系。通过共享预测器，状态转换监督直接塑造骨干网络，从中提取专用表示用于动作预测。同样的设计也可以实例化到预训练的VLA策略中，同时保留其原有的感知和动作通路。在LIBERO-Plus上，JEPA-WAM达到了79.2%，是无需大规模机器人策略预训练的最佳结果，而其预训练的π0.5实例化达到了86.3%，取得了总体最佳性能。在RoboTwin 2.0和真实世界双臂操作上的实验进一步证明了在视觉和空间偏移下的强大泛化能力。

## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：视觉-语言-动作（VLA）策略在多种操作任务中表现优异，但其动作预测目标仅隐式建模状态转换，在分布偏移下鲁棒性受限。
- **生成式 WAM 的瓶颈**：视频生成式世界动作模型（WAM）通过显式预测未来帧来建模状态转换，但迭代式未来预测带来高昂的部署成本。
- **现有潜在 WAM 的两大缺陷**：
  - 预测目标选择不当：要么复用为视频生成优化的中间特征（不显式表达状态变化），要么将未来观测压缩为少量 latent token（丢失细粒度空间结构）。
  - 预测与动作生成的集成方式欠佳：或是将预测表示仅作为动作模块的额外上下文（引入冗余信息），或是引入独立 latent 动力学模块（对动作生成所依赖的表示影响微弱）。
- **论文定位**：提出 JEPA-WAM，一种在预训练 V-JEPA 空间中构建的潜在 WAM，**不显式生成未来帧**，而是通过共享预测器将潜在转移预测与连续动作生成耦合，以低部署成本实现强 OOD 泛化。

## 2. 方法论

- **核心思想**：构建在预训练 V-JEPA 2.1 表示空间中的潜在世界动作模型，预测一个**空间结构化的"当前-未来联合目标"**，通过**共享预测器**将转移监督直接施加到用于动作生成的同一骨干网络上。

- **关键技术细节**：

  1. **当前视觉表示 $Z_t$**：多视角观测经冻结 V-JEPA 编码器独立编码，按固定相机顺序拼接，得到 patch 级（token 级）稠密表示，保留空间结构。
  2. **联合当前-未来目标 $Y_{t,t+\delta}$**：将当前帧与 $\delta$ 步后的未来帧在时间维堆叠后由冻结 V-JEPA 联合编码。由于 V-JEPA 的时间 tubelet 大小为 2，两帧输入产生与单帧相同的空间 token 网格。该目标强调两个时间端点之间的**时序关系**（哪些区域稳定/变化、物体与空间关系如何演化），而非重构单一的绝对未来状态。
  3. **共享预测器 $F_\theta$**：实例化为 Qwen2.5-0.5B，同时处理视觉投影、任务指令和专用动作占位符（action placeholders），输出：
     - $Q^{wm}_t$（视觉 token 位置的隐状态）：用于预测联合当前-未来目标；
     - $C_t$（动作占位符对应的专用表示）：用于条件化动作生成。
  4. **潜在转移预测**：轻量预测头 $G_\phi$ 将 $Q^{wm}_t$ 映射回 V-JEPA 空间，获得 $\hat{Y}_{t,t+\delta}$，与目标 $Y_{t,t+\delta}$ 计算 **patch 级平均余弦距离损失** $\mathcal{L}_{wm}$。
  5. **动作生成**：基于 StarVLA 的 DiT 动作专家，采用条件流匹配（velocity prediction，RoboTwin 用 x-prediction），优化损失 $\mathcal{L}_{act}$。
  6. **联合训练目标**：$\mathcal{L} = \mathcal{L}_{act} + \lambda_{wm}\mathcal{L}_{wm}$，使用 LoRA 适配器训练，部署时移除转移预测分支。
  7. **向预训练 VLA 迁移**：以 π0.5 为例，引入 learnable future tokens，其输出隐状态经 reshape 为粗网格、轻量投影与空间上采样到目标分辨率，与 V-JEPA 联合目标做 patch 级对齐，且不改变原策略感知与动作通路。

- **公式核心**（文字说明）：
  - 视觉-语言初始化遵循 Prismatic 单阶段微调设定，V-JEPA 冻结，仅微调投影器与 Qwen 骨干。
  - 机器人策略训练中，V-JEPA、视觉投影器与 Qwen 基座权重冻结，优化 Qwen LoRA、转移预测头与动作专家。

## 3. 实验设计

- **Benchmark 与数据集**：

- **对比方法**：
  - 无机器人策略预训练：Diffusion Policy、ACT、DP3、ResVLA、Fast-WAM、RoVLA、VLA-Adapter 等。
  - 有机器人策略预训练：π0、π0.5、VLA-JEPA、Motus、PokeVLA、ABot-M0、Cosmos-Policy、Being-H0.7、RDT-1B 等。
  - 关键对比是相同骨干下加/不加 JEPA 目标的 π0.5 + JEPA Obj. vs π0.5。

- **消融分析**（LIBERO-Plus 上）：
  - 视觉表示：V-JEPA vs DINOv2+SigLIP（无转移预测）
  - 预测目标：联合当前-未来 vs 仅未来 vs 端点差分
  - 空间结构：patch 级直接对齐 vs iREPA 风格卷积变换
  - 监督层位：最终层 vs 中间层（Lower-16）
  - 动作条件化：专用占位符 vs 全部隐状态（Full-hidden）

- **冻结探针分析**：受控时间间隔解码、未见时间间隔泛化、去除端点位移后的轨迹结构恢复、端点位移控制、空间诊断（patch 级表示变化与 RGB 变化的相关性）。

## 6. 主要结论与发现

- 在 **LIBERO-Plus** 上，JEPA-WAM 达到 **79.2%**，是**无大规模机器人策略预训练的最佳结果**；预训练 π0.5 加入同一转移监督后平均成功率从 84.5% 提升至 **86.3%**，取得**总体最佳**。
- 在标准 LIBERO 上，JEPA-WAM 平均成功率 **96.7%**，与强基线（含预训练方法）保持相当；π0.5 + JEPA Obj. 达 97.8% 为最优。
- 在 **RoboTwin 2.0** 上，JEPA-WAM 在 Clean 与 Random 下分别达 79.9% 与 36.9%，优于所有无预训练方法；π0.5 + JEPA Obj. 将 Clean 从 75.4% 提升至 **84.6%**。
- 在**真实世界双臂操作**中，JEPA-WAM（ID 59.8% / OOD 54.2%）显著优于 π0（51.8% / 22.5%）；π0.5 + JEPA Obj. 将 ID 从 77.5% 提升至 **90.3%**，OOD 从 72.5% 提升至 **84.7%**。
- **设计验证**：V-JEPA 表示空间本身有利于 OOD；联合当前-未来目标优于仅未来与端点差分；patch 级空间监督优于卷积对齐；最终层监督优于中间层；专用动作占位符优于全隐状态条件化。
- **效率**：部署时仅执行当前观测编码 + 预测器 + 动作专家，RoboTwin 推理延迟 85 ms（11.76 Hz），快于 ABot-M0（125 ms）。

## 7. 优点

- **共享预测器设计新颖**：将转移预测与动作生成耦合同一骨干，使世界模型监督直接塑造动作所需表示，而非分离的辅助模块。
- **联合当前-未来目标有洞察**：通过联合编码而非端点相减，保留更丰富的时序关系（探针实验证明其超越一阶端点差分）。
- **patch 级稠密监督**：保留空间结构，避免全局池化或压缩造成的细节丢失。
- **迁移灵活**：不改变预训练 VLA 的原有通路，通过 future tokens 使预训练策略（π0.5）同样受益。
- **部署高效**：训练阶段才有目标分支与预测头，推理与基线策略成本几乎相同，无逐帧迭代生成。
- **实验规范**：ID 与 OOD 对比清晰、消融系统、探针分析深入、真实 rollout 记录详尽。

## 8. 不足与局限

- **语言无关的转移目标**：联合当前-未来目标捕获的是任务共享的视觉时序结构，不依赖语言指令。当同一观测在不同指令下对应显著不同的转换时，该监督的表达力受限。论文在 Limitations 中也承认这一点，并将语言条件化/多模态转移目标列为未来工作。
- **真实世界 OOD 覆盖有限**：仅涉及背景与初始物体配置变化，未覆盖光照突变、相机移位、物体外观变化等更广泛的视觉干扰。
- **RoboTwin Random 的增益有限**：π0.5 + JEPA Obj. 在 Random 上仅与 π0.5 持平，说明转移监督对该基准随机化场景的额外增益有限。
- **训练成本**：需要进行 VLM 初始化（LLaVA v1.5 微调）后再进行 60K 步策略训练，总体训练管线开销不算低；虽然部署成本低，但"训练成本"与"部署成本"的权衡未详细讨论。
- **未与更多潜在 WAM 方法对比**：如表 2 所示，Cosmos-Policy、Being-H0.7 等均为代表性方法，但 JEPA-WAM 未与这些方法在"无预训练"条件下做同类对比（它们大多依赖预训练），可比较性有待加强。
- **算力细节缺失**：GPU 型号、具体训练时长未报告，复现成本难以精确评估。
