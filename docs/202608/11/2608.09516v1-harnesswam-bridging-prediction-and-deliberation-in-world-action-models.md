## 摘要
世界动作模型（WAMs）联合学习环境动力学与机器人动作，将物理演化的先验引入具身控制。然而，有限时域的预测和动作生成不足以应对复杂的具身任务，这些任务需要全局规划、跨阶段状态维护、执行验证和失败恢复。我们将这种不匹配称为WAMs的预测-深思鸿沟。为解决这一鸿沟，我们提出HarnessWAM，一个针对WAMs的智能体框架。HarnessWAM采用基于视觉语言模型的任务管理器来维护基于证据的场景信念和结构化的任务图。能力条件化的可执行空间投影进一步将开放式的语义计划约束为满足任务依赖、具身状态约束以及底层WAM能力边界的原子技能序列。在执行过程中，HarnessWAM通过事件驱动的双时间尺度反馈循环运行：一个轻量级的进度估计器持续提供高频执行证据，而任务管理器在显著里程碑处进行深思，联合考虑当前观察、任务状态和交互历史，以决定是推进任务、获取额外观察、修订计划还是启动局部恢复。这一机制使机器人能够在子任务失败后恢复其状态，并在不丢弃先前获取的场景知识的情况下继续执行。HarnessWAM在RoboMemArena上实现了59.6%和69.9%的最先进的全任务和子任务成功率，并在RoboCerebra Ideal上实现了23.7%的SR。这些结果表明，模型外部的结构化状态维护和闭环智能体决策能够有效地将WAMs的局部控制能力扩展为可规划、可验证和可恢复的具身任务执行。

## Abstract
World Action Models (WAMs) jointly learn environmental dynamics and robot actions, introducing priors over physical evolution into embodied control. However, finite-horizon prediction and action generation are insufficient for complex embodied tasks that require global planning, cross-stage state maintenance, execution verification, and failure recovery. We refer to this mismatch as the prediction-deliberation gap of WAMs. To address this gap, we propose HarnessWAM, an agentic framework for WAMs. HarnessWAM employs a vision-language-model-based Task Manager to maintain an evidence-grounded scene belief and a structured task graph. A capability-conditioned executable-space projection further constrains open-ended semantic plans into sequences of atomic skills that satisfy task dependencies, embodiment-state constraints, and the capability boundary of the underlying WAM. During execution, HarnessWAM operates through an event-driven, dual-timescale feedback loop: a lightweight progress estimator continuously provides high-frequency execution evidence, while the Task Manager deliberates at salient milestones by jointly considering the current observation, task state, and interaction history to determine whether to advance the task, acquire additional observations, revise the plan, or initiate local recovery. This mechanism enables the robot to recover its state after a subtask failure and resume execution without discarding previously acquired scene knowledge. HarnessWAM achieves state-of-the-art full-task and subtask success rates of 59.6% and 69.9% on RoboMemArena, and an SR of 23.7% on RoboCerebra Ideal. These results demonstrate that model-external structured state maintenance and closed-loop agentic decision making can effectively extend the local control capabilities of WAMs into embodied task execution that is plannable, verifiable, and recoverable.

- **核心问题**：论文将这一不匹配定义为 **预测–深思鸿沟（prediction–deliberation gap）** ——WAMs擅长局部预测与控制，但缺乏持续的全局级任务状态维护、语义验证和失败后决策的能力。具体表现为：

  - 缺乏执行验证机制，难以判断子任务是否真正完成；
  - 缺乏失败恢复策略，局部技能失败可能导致整条任务链中断。
- **整体含义**：要提升WAMs在复杂任务上的可靠性，不仅需要改进模型内在的预测与动作能力，还需要构建模型外部的结构化状态维护与闭环决策机制，将局部控制能力"编排"为可规划、可验证、可恢复的完整任务执行。

## 2. 方法论

- **核心思想**：提出 HarnessWAM —— 一个模型外部（model-external）的智能体编排框架，在不改变底层WAM架构的前提下，通过外部运行时组织WAM的局部预测与动作，使其具备任务级的状态估计和闭环节点决策能力。
- **关键技术组件**：

  - **证据接地的场景信念（Evidence-grounded scene belief）**
    - 场景事实表示为：`f = (s, p, o, v, η, c, E)`，其中 `η ∈ {observed, inferred, unknown}` 区分直接观察、推断事实和未解决状态；`E` 保存支撑的视觉证据。
    - 区分"未观察到"与"观察到为假"，遮挡不会使已有场景事实失效。
    - 任务记忆 `Mk = (M_task, M_evidence)` 保存已完成/失败节点、重试次数、变量绑定、修订历史和视觉证据。

  - **结构化任务图（Structured task graph）**
    - 任务表示为有向图 `Gk = (Vk, Ek, Xk, βk)`，其中 `Xk` 为未解析符号变量，`βk` 为从变量到场景实体的部分绑定。
    - 节点包含 `(op, args, pre, eff, term, rec)` 六要素，覆盖操作、参数、前置条件、预期效果、终止条件和恢复策略。
    - 图中同时包含**运动节点**（引发物理动作）和**认知节点**（获取观察、验证状态、绑定变量、更新记忆）。
    - 当实体无法从初始观察中识别时，保留符号变量而非做出无依据的猜测，待证据充足后再绑定。

  - **能力条件化可执行空间投影（Capability-conditioned executable-space projection）**
    - 定义可扩展的参数化操作本体：`P⋆ = Pmotion ∪ Pgrasp ∪ Pcontact ∪ P_articulation ∪ P_assembly ∪ Ptool`。
    - 对具体WAM，可执行基元集合 `PW = {p ∈ P⋆ | p has a validated realization under Wθ}`。
    - 投影 `Gexec = Π_{L(PW) ∩ F(zk)}(Gvlm)` 由确定性计划编译器实现，检查参数类型、依赖关系、前置条件-效果一致性、单臂持物状态、图无环性等约束。
    - 若无法投影则返回 ⊥，报告违反的约束供任务管理器重新规划。
    - 历史不变性约束：只允许修订未执行的图后缀 `Gk+1|V_executed = Gk|V_executed`。

  - **事件驱动的双时间尺度控制（Event-driven dual-timescale control）**
    - **快时间尺度**：WAM持续生成动作块，一个轻量级进度估计器 `Fϕ` 从近期双视角RGB帧输出连续进度 `pt ∈ [0,1]`、阶段完成概率 `ct ∈ [0,1]` 和离散进度区间分布 `πbin_t`。
    - **慢时间尺度**：任务管理器只在显著里程碑事件触发时被调用，联合考虑当前观察、进度轨迹、场景信念、任务图、证据记忆和执行状态，输出：
      `yk = (νk, dk, ΔBk, Δβk, ρk)`，其中 `νk ∈ {success, failure, uncertain}` 为效果标签，`dk ∈ {continue, advance, observe, replan, recover, terminate}` 为执行决策。
    - 进度估计本身**永不直接推进任务图**，子任务边界必须由任务管理器基于视觉结果与结构化状态判定。

  - **具身状态恢复（Embodiment-state recovery）**
    - 每个运动节点开始时记录臂关节状态 `q0k` 和夹爪状态 `u0k`，并分配执行预算。
    - 当 `dk = recover` 时，通过多步关节控制将机械臂和夹爪恢复到节点初始状态，同时保留环境状态、场景信念和任务记忆。
    - 恢复后清空局部WAM状态，可重试当前节点或替换未执行图后缀。

  - **整体算法流程**（Algorithm 1）：初始化 → VLM规划 → 投影编译 → 循环选择就绪节点 → 执行WAM技能 + 进度估计 → 事件触发深思 → 执行决策（推进/观察/重规划/恢复/终止）→ 最终验证。

## 3. 实验设计

- **Benchmark 1：RoboMemArena**
  - 26个长时程操作任务，平均轨迹长度1,076环境步，68.9%的子任务依赖历史信息。
  - 四个任务族：多物体转移（4个）、遮挡（11个）、计数（7个）、顺序执行（4个）。
  - 指标：全任务成功率 `SR_task`（所有阶段谓词全真的比例）和子任务成功率 `SR_sub`（阶段谓词宏平均）。
  - 对比方法：
    - 已发表基线：π0.5、HiF-VLA、MemoryVLA、MemER、PrediMem；
    - 同WAM诊断基线：WAM + Whole Task（直接全局指令）、WAM + Static Plan（一次性静态分解，无记忆更新和重新规划）。

- **Benchmark 2：RoboCerebra Ideal**
  - 长时程组合操作与高层推理基准，Ideal子集（静态、完全可观察）。
  - 指标：SR = 关键物体状态转换的平均完成率。
  - 对比方法：π0.5、OpenVLA、GPT-4o Planner + OpenVLA、HPE Framework。

- **实现细节**：
  - 底层WAM：LingBot-VA（架构不变，按各基准独立微调）；
  - 任务管理器：Qwen3-VL-32B-Instruct，无任务特定微调，仅使用多视角RGB输入；
  - 进度估计器：SigLIP2-base编码器 + 4层因果Transformer，输入最近5个时间步双视角RGB + 技能指令，训练目标包含连续回归、区间分类、排序、端点锚定、完成预测和单调性约束。

- **评价协议**：每个任务20次rollout，匹配初始状态、随机种子、观测接口和任务级预算；任务转换和终止由执行证据动态决定，不使用预定的切换时间。

## 6. 主要结论与发现

- **性能总结**：
  - RoboMemArena：全任务成功率59.6%，子任务成功率69.9%，超过PrediMem 21.1和14.7个百分点；
  - RoboCerebra Ideal：SR 23.70%，超过GPT-4o Planner + OpenVLA 1.78点、HPE Framework 2.60点。
- **关键成分分析**：
  - 可执行空间投影贡献最大：移除后全任务成功率从59.6%降至18.5%；
  - 进度条件事件控制次之：移除后下降21.3个百分点；
  - 结构化任务状态不可或缺：遮挡任务族中尤为明显；
  - 仅靠进度估计的"高局部完成率"不等于端到端成功——顺序执行族中，仅用进度切换将子任务成功率提升至97.9%但全任务成功率从86.3%降至72.5%；
  - 词汇规范化只能将计划可执行性从13.8%提升至42.3%，而完整投影可提升至72.9%。
- **核心论断**：模型外部结构化状态维护 + 闭环智能体决策可以有效弥合预测–深思鸿沟，将WAMs的局部控制扩展为可规划、可验证、可恢复的完整具身任务执行。

## 7. 优点

- **问题定义清晰且具有原创性**：明确诊断了WAMs的预测–深思鸿沟，并将可靠执行形式化为模型外部的状态估计与闭环决策过程。
- **模块化设计优雅**：任务管理、可执行投影、进度估计、恢复机制各司其职，架构边界分明，且无需修改底层WAM，具有良好的兼容性。
- **"证据接地"的状态维护思想**：区分观察与推断、维护支撑证据引用，解决了部分可观察环境下"遮挡后状态不可逆地丢失"的痛点。
- **能力条件化投影**：在开放语义空间（VLM）与受限执行空间（WAM技能库）之间建立了确定性检查桥梁，防止了语义可行但物理不可执行的计划。
- **双时间尺度控制合理**：避免逐帧调用VLM带来的计算开销，同时通过语义事件保证任务边界判定的可靠性，进度估计"建议但不决策"的资源分配原则避免了语义误判。
- **消融设计严谨**：同WAM对照有效剥离了模型能力与编排能力的贡献，计划级诊断将任务级性能差异追溯到具体的机制环节，归因链条完整。
- **在部分可观察、记忆依赖的基准上达到了最优性能**，验证了方法的实用性。

## 8. 不足与局限

- **未报告算力与效率数据**：缺少GPU资源、训练时长、推理延迟等信息，难以评估部署成本和实时性。
- **真实世界验证缺失**：所有实验均在仿真基准上完成，未涉及真实机器人环境中的噪声、标定误差、动力学不确定性等挑战。
- **底层WAM单一**：仅使用LingBot-VA一种WAM，未验证框架对多种WAM（如Fast-WAM、DreamZero等）的普适性。
- **RoboCerebra评估维度有限**：只报告了Ideal子集的单一SR指标，未报告全任务成功率和更极端的子集（如多阶段、需想象力的场景）。
- **统计严谨性不足**：每任务仅20次rollout，未报告方差、置信区间或显著性检验。
- **VLM任务管理器依赖**：32B模型在事件触发时仍需以高延迟进行多模态推理，在长时间任务中事件频繁时可能成为瓶颈。
- **策略链的可靠性未与"失败即不做任何事"的下界对比**——未展示在最坏情况下框架不会造成比单纯WAM更差的负效果。
- **恢复机制的能力上限**：只支持恢复机械臂和夹爪的位姿，不支持环境状态的逆操作；在某些不可逆物理变化（如物体掉落损坏）下恢复无济于事。
- **任务图与本体论的手工设计**：操作本体（P⋆）和约束集合需人工定义，其完备性直接影响系统的泛化边界，论文未涉及这一设计过程的自动化。
