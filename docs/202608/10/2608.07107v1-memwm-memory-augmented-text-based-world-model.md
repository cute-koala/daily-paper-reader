## 摘要
世界模型越来越多地被用于通过预测环境状态如何响应智能体行为来支持智能体的规划。然而，流畅的下一状态预测仍可能遗漏任务关键事实、破坏产品属性或应用错误的转换规则。为了解决这类系统性预测错误，我们引入了MemWM，一种记忆增强的基于文本的世界模型。MemWM使用世界记忆（world memory），一个精心整理的转换规则、状态缓存和难以预测的事实的记忆库，来条件化下一状态的想象。我们通过结构化状态保真度（SSF）评估事实状态的保留，该指标通过基准特定的事实和字段对预测状态进行评分。与SFT相比，记忆增强训练将SSF提升了高达206.3%。在完整规划设置中，我们保持策略模型冻结，并提供策略侧世界技能：检索到的任务级技能和逐步纠正性指导以进行动作选择。在ALFWorld、WebShop和ScienceWorld上，与SFT训练的世界模型智能体相比，记忆增强智能体提高了下游成功率，相对增益高达65.4%。敏感性分析进一步表明，在不同的记忆和动作预算设置下，检索到的记忆提高了任务成功率和效率。

## Abstract
World models are increasingly used to support planning in agents by predicting how environment states evolve in response to agent actions. Yet fluent next-state predictions can still omit task-critical facts, corrupt product attributes, or apply incorrect transition rules. To address such systematic prediction errors, we introduce MemWM, a memory-augmented text-based world model. MemWM uses world memory, a curated memory bank of transition rules, state caches, and hard-to-predict facts, to condition next-state imagination. We evaluate factual state preservation with Structured State Fidelity (SSF), which scores predicted states through benchmark-specific facts and fields. Compared with SFT, memory-augmented training improves SSF by up to 206.3%. In the full planning setting, we keep the policy model frozen and provide policy-side world skill: retrieved task-level skills and step-wise corrective guidance for action selection. Across ALFWorld, WebShop, and ScienceWorld, memory-augmented agents improve downstream success over an SFT-trained world-model agent, with up to a 65.4% relative gain. Sensitivity analyses further show that retrieved memory improves task success and efficiency under different memory and action-budget settings.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：文本世界模型在预测下一状态时，虽然能生成流畅、局部合理的文本，但系统性存在三类错误：**遗漏任务关键事实**（如物体位置绑定）、**破坏属性**（如产品ID、价格、选项）、**应用错误的转换规则**（如状态翻转）。
- **为何重要**：这些表面看似不严重的错误，会在前瞻规划（lookahead planning）中逐步累积放大，最终导致智能体做出无效或错误的决策。
- **现有评估指标的缺陷**：
  - **精确匹配（EM）过严**：无害的改写、格式变化或事实重排会被判零分。
  - **词级F1过松**：交换对象、位置、状态、产品ID或价格后，预测仍可能保留大部分共享词元，得到高分。
- **根本矛盾**：现有指标无法区分"表面相似但事实错误"与"表面不同但事实正确"，导致世界模型的可靠性被高估。
- **研究问题**：如何让文本世界模型利用经验衍生的记忆，避免系统性的事实、规则和状态转换错误，同时保持想象状态对行为关键世界事实的忠实？

## 2. 方法论：MemWM

### 2.1 核心思想：双通道记忆架构

MemWM 将记忆分为两个独立通道，分别服务"后果预测"和"动作选择"：

- **世界记忆（World Memory）**：供世界模型使用，存储转移规则、状态缓存和难预测事实；通过检索在预测时注入提示词，条件化下一状态的想象。
- **世界技能（World Skill）**：供冻结的策略模型使用，包含任务级技能和逐步骤的纠正性指导，用于增强动作选择质量。

### 2.2 关键公式

世界模型预测：

$$\hat{s}_{t+1} = f_\theta(c_t, a_t) \quad \text{（无记忆）}$$

记忆增强后：

$$\hat{s}_{t+1} = f_\theta(c_t, a_t, \mathcal{R}_{wm}(q^{wm}_t, \mathcal{M}^{wm}_t))$$

其中 `R_wm` 从世界记忆中检索与当前上下文和候选动作相关的紧凑条目。

### 2.3 结构化状态保真度（SSF）

SSF 是论文提出的新评估指标，核心思想是**通过领域特定的结构化事实比较预测与金标状态**：

$$\text{SSF}_d(\hat{s}_{t+1}, s_{t+1}) = \sum_{c \in C_d} w_c \cdot \text{sim}_c(\hat{z}_c, z_c)$$

- 对 ALFWorld 和 ScienceWorld：用抽取器将状态投影为规范化事实集，计算**事实级F1**。
- 对 WebShop：用规则解析器提取页面结构化字段（产品ID、价格、选项等），计算**加权字段相似度**。
- 数值字段用相对误差、类别字段用精确匹配、集合字段用集合F1。

### 2.4 记忆构建与检索

- **世界记忆构建**：
  - 从硬负样本预测失败、历史轨迹和循环转换模式中提取。
  - ALFWorld：按目标签名、动作模式、对象类型等分桶，总结为正向提示和负向错误模式。
  - ScienceWorld：残差事实记忆 + 训练世界事实缓存（配方、温度、房间事实等）。
  - WebShop：持久化站点缓存（搜索结果页、产品详情页、选项条件状态）。
- **检索机制**：基于领域特定的结构化线索进行轻量级匹配；可见轨迹始终优先于检索记忆。
- **冲突处理**：若检索记忆与轨迹冲突，以轨迹为准。

### 2.5 规划流程

1. 任务开始时检索任务级技能，形成高层求解先验。
2. 每个决策步骤检索纠正性指导，提出候选动作。
3. 对每个候选动作检索世界记忆，生成想象的下一状态。
4. 用规划规则对候选轨迹评分，选出最高分动作执行。
5. 执行后更新历史与记忆证据。

## 6. 主要结论与发现

- **记忆增强训练一致提升结构化状态保真度**：在全部9个模型–基准组合（Table 1）中，Mem-Aug RL均取得最优SSF；相比SFT最高提升206.3%（Qwen2.5-7B在ALFWorld上从0.286提升至0.876）。
- **检索记忆在推理时确实起作用**：增加记忆dropout会降低SSF，证明记忆是预测的实际依据，而非无效上下文（图4、图6）。
- **不训练策略也能提升智能体性能**：冻结策略模型下，MemWM在ALFWorld和WebShop上超越SFT世界模型智能体；MemWM+Skill在ALFWorld Qwen3-8B上达72.7%成功率（SFT WM为51.4%），相对提升约41%；在ALFWorld整体上相对增益最高65.4%。
- **增益不是预算假象**：在1/3/5个候选动作的不同预算下，记忆增强均提升成功率，且成功轨迹步数未增加（效率同等或更好）。
- **消融证明各组件互补**：在ALFWorld Qwen2.5-7B设置中，记忆增强训练（0.5439）与推理时相关检索（0.5385）各自独立贡献，组合达0.5696；随机/无关记忆反而降至0.47/0.44，证明相关性和记忆内容质量是关键。
- **WebShop上记忆memory增益最大**：这是产品标识、价格等事实最密集、最容易被污染的领域，记忆增强在Llama3.2-1B上SSF提升+0.175。

## 7. 优点

- **指标设计精细**：SSF针对不同领域设计不同的事实抽取方案（ALFWorld/ScienceWorld用事实集F1，WebShop用字段加权），且通过控制扰动测试、盲注释者验证、权重敏感性、跨域迁移等多重手段验证指标可靠性。
- **抽取器的防修复设计**：ScienceWorld混合解析器明确避免LLM抽取器"过度补全"腐败预测的问题（纯LLM抽取器在扰动测试中最大得分为1.000，混合解析器降为0.250），体现方法论的严谨性。
- **双通道记忆的清晰解耦**：世界记忆服务后果预测、世界技能服务动作选择，职责分离、模块化清晰，便于消融和可扩展性。
- **冻结策略模型的方案**：证明无需策略训练即可提升智能体性能，提供了一条计算上更经济的增强路线。
- **消融极其细致**：12种变体区分了"记忆训练"vs"检索使用"vs"技能指导"的各自贡献，还排除了提示长度和任意上下文干扰。
- **跨领域设计原则验证**：在CookingWorld上验证SSF设计配方可迁移，同时诚实指出每个新领域仍需显式schema和解析器。

## 8. 不足与局限

- **领域特定工程成本高**：SSF和记忆构建都要求为每个新环境手工设计schema、解析器、记忆分桶和检索规则，缺乏通用性和零样本适用性；从ScienceWorld到CookingWorld的迁移也需要重新实例化解析器。
- **记忆库构建依赖离线经验**：世界记忆主要来自训练轨迹硬负样本，需要高质量轨迹和失败数据作为输入；记忆更新的在线学习机制描述较简单，未充分探讨如何随环境变化自动演进。
- **算力信息不完整**：未报告GPU型号、训练时长和总计算量，影响成本评估和复现的精确性。
- **部分baseline引用第三方数据**：CoT/ReAct/RAP/ITP基线直接引用他人研究结果，环境版本、解码配置和评估预算的一致性无法完全确认，对比的严格性略有折扣。
- **ScienceWorld的未seen任务增益有限**：在Qwen3-8B上，MemWM+Skill对ScienceWorld Unseen的成功率（21.85%）相对WM（20.63%）仅提升约1.2个百分点，泛化能力边界不够清晰。
