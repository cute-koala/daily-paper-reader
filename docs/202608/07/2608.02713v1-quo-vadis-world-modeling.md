## 摘要
持续改进的智能体需要超越静态监督的动态交互反馈，然而直接与现实环境交互成本高昂、速度缓慢、存在安全隐患且难以并行化。世界建模提供了一种自然的中间代理，使智能体在采取真实行动之前能够查询成本更低、更可控的反馈。经典世界模型主要通过未来物理状态预测来实例化这一代理，这种形式对于需要超越原始状态转换的可操作反馈的智能体而言虽有用但较为狭窄。在本工作中，我们提出智能体中心交互式世界代理的概念，将基本范式从物理状态转换转变为智能体可用信息转换，例如执行结果、检索到的经验或技能以及验证信号，从而拓宽世界建模的范围，为持续改进的智能体提供多方面反馈。为系统性地映射这一设计空间，我们根据反馈模态将世界代理分为六种功能形式：动力学代理、空间代理、执行代理、记忆/经验代理、技能代理以及奖励/验证代理，它们共同刻画了世界建模服务于智能体改进的主要方式。我们进一步分析了这些代理如何在三个递进层级上赋能智能体：L.1 推理时引导，代理输出丰富上下文信息以支持更优决策；L.2 训练时优化，代理输出产生奖励、批评或合成轨迹用于策略学习；L.3 智能体-代理共同演化，真实环境证据持续更新代理与智能体以实现共同演化。最终，本工作将世界建模重塑为智能体中心范式，为构建赋能智能体更好规划、更快学习、持续演化的世界代理制定了路线图。

## Abstract
Continually improving agents require dynamic interaction feedback beyond static supervision, yet direct real-environment interaction is costly, slow, unsafe, and hard to parallelize. World modeling offers a natural intermediate proxy that allows agents to query lower-cost, more controllable feedback before committing to real actions. Classical world models instantiate this proxy primarily through future physical-state prediction, a formulation useful yet narrow for agents that require actionable feedback beyond raw state transitions. In this work, we conceptualize Agent-Centric Interactive World Proxies, shifting the fundamental paradigm from physical state transitions to agent-usable information transitions, such as execution outcomes, retrieved experiences or skills, and verification signals, broadening the scope of world modeling to provide versatile feedback for continually improving agents. To systematically map this design space, we organize world proxies into six functional forms based on their feedback modalities: dynamics, spatial, execution, memory/experience, skill, and reward/verification proxies, which together characterize the primary ways world modeling serves agent improvement. We further analyze how these proxies empower agents across three progressive levels: L.1 Inference-Time Guidance, where proxy outputs enrich in-context information for superior decisions; L.2 Training-Time Optimization, where proxy outputs yield rewards, critiques, or synthetic rollouts for policy learning; and L.3 Agent-Proxy Co-Evolution, where real-environment evidence continuously updates both the proxy and the agent for co-evolution. Ultimately, this work recasts world modeling into an agent-centric paradigm, establishing a roadmap for building world proxies that empower agents to plan better, learn faster, and evolve continually.

## 2. 论文提出的方法论

### 核心思想
- **从世界模型到世界代理（World Proxy）**：世界代理是环境接地（environment-grounded）的中间机制，建模或预测**信息转换（information transition）**，而非仅仅预测物理状态。它支持智能体发起的查询、行动或干预，返回智能体可直接使用的反馈（未来状态、执行结果、检索到的经验/技能、奖励/验证信号等）。
- **三个拓展轴**（区别于经典世界模型）：
  - 物理时间步 → 交互步（agent interaction step ℓ）；
  - 状态转换 → 信息转换（information transition）；
  - 外部给定条件 → 智能体发起的交互（agent-initiated interaction）。
- **好的世界代理应满足**：环境接地性（groundedness）、可控性（controllability）、反馈有用性（feedback usefulness）、成本与可扩展性（cost & scalability）、前瞻能力（forward-looking）。

### 形式化定义

### 六种功能代理（Section 4）
| 代理类型 | 智能体输入 | 输出 |
|---|---|---|
| 动力学代理（Dynamics） | 状态 + 动作/未来查询 | 未来状态、轨迹、预测奖励 |
| 空间代理（Spatial） | 场景 + 视角/位姿查询 | 新视角观测、渲染视图 |
| 执行代理（Execution） | 代码/命令/点击/API调用 | 执行结果、状态变化、stdout/stderr |

| 技能代理（Skill） | 目标/上下文 + 技能查询 | 技能建议、行为先验 |
| 奖励/验证代理（Reward/Verification） | 计划/轨迹/答案/行动 | 奖励、批评、偏好、验证结果 |

### 三个赋能层级（Section 3）
- **L.1 推理时引导（Inference-Time Guidance）**：世界代理作为上下文增强器，通过检索、模拟、验证向智能体提供额外信息，加入当前上下文以改进决策；不改动智能体参数。
  - 形式化：$s^{agent+}_\ell = s^{agent}_\ell \oplus \hat{s}^{guide}_{\ell+1}$
- **L.2 训练时优化（Training-Time Optimization）**：世界代理作为奖励模型、验证器、批评者或模拟器，为智能体策略优化提供训练信号（奖励、批评、偏好、合成轨迹），可转化为 SFT、DPO、PPO、GRPO 等训练目标。
  - 形式化：$agent^+ = Train(agent, \hat{s}^{opt}_{\ell+1})$
- **L.3 智能体-代理共同演化（Agent-Proxy Co-Evolution）**：真实环境证据持续更新世界代理，代理的知识再蒸馏回智能体，实现二者闭环共演化。
  - 形式化：$(agent^+, \mathcal{WP}^+) = CoEvolve(agent, \mathcal{WP}, \hat{s}^{proxy}_{\ell+1}, s^{env}_{\ell+1})$

### 算法流程说明
- **L1 流程**：Agent Query → Proxy Retrieval/Simulation/Verification → Guidance → Augmented Context → Agent Decision
- **L2 流程**：Agent Rollout → Proxy Verification/Simulation → Reward/Critique/Preference → Training Objective → Agent Policy Optimization
- **L3 流程**：Agent Rollout → Proxy Prediction/Verification → Real-Environment Evidence → Disagreement/Error Diagnosis → Update Proxy + Distill to Agent → Co-Evolution

## 6. 论文的主要结论与发现

- **范式转移**：世界建模的核心目标应从"预测世界"转向"服务智能体"——最有价值的未来世界模型，应以其使查询它的智能体变得多好来衡量，而非其生成的画面有多逼真。
- **概念框架**：提出智能体中心世界代理，形式化定义为环境接地的信息转换模型，涵盖六种功能形式（动力学、空间、执行、记忆、技能、奖励/验证）与三个赋能层级（推理时引导、训练时优化、共同演化）。
- **迭代闭环**：世界代理应与智能体形成闭环——智能体发起查询、代理返回反馈、智能体据此改进，持续迭代。
- **开放挑战**（论文提出四个未来方向）：
  1. **保真度与想象的边界**：生成模型可能"看起来正确但物理上错误"，长程 rollout 误差累积，需要校准的不确定性而非更逼真的像素；
  2. **何时信任代理**：智能体需要在线判断是依赖代理反馈还是回到真实环境，目前缺乏好的判断机制；
  3. **奖励黑客与安全**：当代理成为奖励/验证器（L2），智能体可能利用代理盲点，安全风险随之增加；
  4. **评估信息增益**：需要代理中心的 benchmark 来度量反馈是否真正帮助智能体改进，而非在隔离状态下评估代理的保真度。
