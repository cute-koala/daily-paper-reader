## 摘要
图像目标视觉导航是具身智能体的基本能力。现有的导航策略能高效预测航点轨迹，但缺乏视觉预见性；而导航世界模型可以预测未来的观察结果，但通常需要昂贵的规划展开。我们提出了UniNav，一种统一的世界-动作模型，通过单一扩散过程生成未来的视觉观察和连续的航点轨迹。给定历史帧和目标图像，UniNav在单个Transformer中联合去噪视觉和航点token，在共享框架中统一未来预测和动作生成。为了改善空间基础，我们引入了几何感知的相机token。我们还在带有轨迹标签的导航数据和纯视频数据上训练，使模型能够从多样化的视频中受益而无需航点标注。基于这一统一框架，我们引入了两个变体：UniNav-Full联合预测可解释的未来观察及其相应轨迹，而UniNav-Fast在推理时移除未来图像token以实现高效轨迹预测。在导航基准上的实验表明，UniNav在所有数据集上的ATE均优于最强基线。通过单步推理，UniNav-Fast的延迟为0.1秒，且没有显著精度下降。代码将发布。

## Abstract
Image-goal visual navigation is a fundamental capability for embodied agents. Existing navigation policies efficiently predict waypoint trajectories but lack visual foresight, while navigation world models can anticipate future observations but often require costly planning rollouts. We present UniNav, a unified world-action model that generates future visual observations and continuous waypoint trajectories through a single diffusion process. Given history frames and a goal image, UniNav jointly denoises visual and waypoint tokens within a single transformer, unifying future prediction and action generation in a shared framework. To improve spatial grounding, we incorporate geometry-aware camera tokens. We also train on both trajectory-labeled navigation data and video-only data, enabling the model to benefit from diverse videos without waypoint annotations. Based on this unified framework, we introduce two variants: UniNav-Full jointly predicts interpretable future observations and their corresponding trajectories, while UniNav-Fast removes future-image tokens at inference for efficient trajectory prediction. Experiments on navigation benchmarks show that UniNav outperforms the strongest baseline in ATE across all datasets. With one-step inference, UniNav-Fast achieves a latency of 0.1s without a substantial accuracy drop. Code will be released.

- **研究问题**：图像目标视觉导航（Image-goal Visual Navigation）中，如何让智能体同时具备对未来视觉的预见能力与高效、可执行的航点轨迹预测能力。

  - **策略模型（Policy-only）**：如GNM、ViNT、NoMaD，能高效地从观测直接预测航点轨迹，但缺乏视觉前瞻，不显式建模未来观测，可解释性与环境推理能力受限。
  - **导航世界模型（Navigation World Models）**：如NWM，能预测未来观测，但采用“先生成-再评估”的规划范式，每个候选轨迹都需要独立展开，计算成本高昂，难以支持实时闭环导航。
- **核心洞察**：人类导航自然伴随视觉预见——在走向目标前能想象未来视角下的场景变化。这种预见为动作选择提供可解释基础。因此需要一种统一模型，同时完成未来观测预测与动作生成，兼顾可解释性与实时性。

## 2. 方法论

### 2.1 核心思想

UniNav提出**统一世界-动作扩散模型**：在单个Transformer中，通过一个统一的flow-matching（流匹配）扩散过程，**联合去噪**未来视觉latent、连续航点轨迹token以及几何感知相机token，从而在一个共享框架内统一未来预测与动作生成。

### 2.2 关键技术细节

**（1）多样化的Token表示**

| Token类型 | 来源 | 作用 |
|---|---|---|
| 视觉Token | 冻结的视频VAE对历史帧、目标图、未来帧编码 | 提供视觉上下文（历史+目标），未来帧作为去噪目标 |
| 航点Token | 每步航点经MLP投影到Transformer隐空间 | 表示K步局部航点轨迹，作为预测目标 |
| 相机Token | 冻结的几何基础模型DA3提取未来视图的几何特征 | 提供3D结构与相机姿态的几何监督 |
| 寄存器Token | 可学习的全局token | 促进异构token间的信息交换 |

**（2）统一Token序列**：`[h_cam | h_pred | h_traj | h_hist | h_goal | h_reg]`，所有token由同一去噪Transformer处理。

**（3）统一Flow-Matching目标**：

- 对每个模态 $m \in \{vid, traj, cam\}$，噪声化状态定义为：
  $$z_m = (1-\sigma_m)x_m + \sigma_m\epsilon_m, \quad u_m = \epsilon_m - x_m$$
- 总损失：$\mathcal{L} = \lambda_{vid}m_{vid}\mathcal{L}_{vid} + \lambda_{traj}m_{traj}\mathcal{L}_{traj} + \lambda_{cam}m_{cam}\mathcal{L}_{cam}$
- 轨迹损失使用SmoothL1，视频和相机损失使用L2。

**（4）混合训练策略**：对轨迹标注的导航数据启用三个损失；对纯视频数据仅启用视频和相机损失（$m_{traj}=0$），从而利用无标注视频数据提供额外的视觉与几何监督。

**（5）两种推理变体**：
- **UniNav-Full**：联合去噪未来视频latent、航点轨迹和相机token，生成可解释的未来观测+可执行轨迹。
- **UniNav-Fast**：训练时使用非对称注意力掩码，使航点去噪不依赖未来视频token；推理时直接移除未来图像token，避免视频解码，显著降低延迟。
