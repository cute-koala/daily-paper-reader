## 摘要
现有的自动驾驶世界模型通常执行未来视频、占用状态、BEV表示或智能体运动的密集预测。我们认为规划无需重建完整的未来世界，而只需关注影响未来自我（ego）动作的场景特征。基于这一观点，我们提出Auto-JEPA，一种面向动作的潜在世界模型，通过联合嵌入预测学习连续的未来驾驶意图。给定视觉观测、自我运动历史和导航命令，Auto-JEPA预测一个与未来自我轨迹潜在表示对齐的意图嵌入。预测的意图从固定轨迹记忆中检索可执行的轨迹，然后由场景条件下的候选选择模块进行排序。Auto-JEPA保持视觉编码器冻结，不需要显式感知标注，也不使用学习的轨迹生成器。仅通过优化轨迹表示、意图预测和候选选择等任务特定模块，Auto-JEPA在NAVSIM v1上达到91.3 PDMS，在NAVSIM v2上达到89.1 EPDMS。语义遮挡实验表明，遮挡动态智能体区域导致的平均意图变化是等面积随机遮挡的2.97倍。此外，遮挡影响未来驾驶的车辆会显著改变预测意图和所选轨迹，而遮挡不影响驾驶的车辆时两者基本不变。这些结果表明，未来意图预测促使模型关注与规划相关的视觉特征，并在无需密集未来世界建模的情况下支持高质量规划。

## Abstract
Existing autonomous-driving world models typically perform dense prediction of future videos, occupancy states, BEV representations, or agent motion. We argue that planning need not reconstruct the complete future world, but only focus on scene features that affect future ego action. Based on this perspective, we propose Auto-JEPA, an action-oriented latent world model that learns continuous future driving intent through joint-embedding prediction. Given visual observations, egomotion history, and navigation commands, Auto-JEPA predicts an intent embedding aligned with the latent representation of the future ego trajectory. The predicted intent retrieves executable trajectories from a fixed trajectory memory, which are then ranked by a scene-conditioned candidate selection module. Auto-JEPA keeps the visual encoder frozen, requires no explicit perception annotations, and uses no learned trajectory generator. By optimizing only task-specific modules for trajectory representation, intent prediction, and candidate selection, Auto-JEPA achieves 91.3 PDMS on NAVSIM v1 and 89.1 EPDMS on NAVSIM v2. Semantic occlusion experiments show that masking dynamic-agent regions induces an average intent change 2.97x that of equal-area random masking. Moreover, occluding vehicles that affect future driving substantially changes the predicted intent and selected trajectory, whereas both remain essentially unchanged when non-influential vehicles are occluded. These results show that future-intent prediction encourages the model to focus on planning-relevant visual features and supports high-quality planning without dense future-world modeling.

## 2. 论文提出的方法论

### 2.1 核心思想

Auto-JEPA 采用**联合嵌入预测学习（Joint-Embedding Predictive Learning）** 框架：从当前视觉观测、自车运动历史和导航命令出发，预测一个与未来自车轨迹潜在表示对齐的"意图嵌入"，然后以该嵌入为查询键，从固定轨迹记忆库中检索可执行轨迹。

### 2.2 整体架构（三阶段）

#### 阶段一：轨迹潜在空间预训练（Trajectory Latent-Space Pretraining）

- 将一条未来轨迹表示为 8 个二维航路点：`Y ∈ R^(8×2)`,覆盖 4 秒规划时域（每 0.5 秒一个点）。
- 训练一个轨迹自编码器：编码器 `E_traj` 将轨迹映射为 8 个 1024 维潜在 token（`Z+ = E_traj(Y) ∈ R^(8×1024)`），轻量解码器 `D_traj` 重建轨迹。
- 重建损失由四个监督项组成：
  ```
  L_traj = L_xy + λ_e·L_end + λ_v·L_vel + λ_a·L_acc
  ```
  分别监督：航路点坐标、终点、速度、加速度。
- 预训练结束后：**丢弃解码器**，**冻结轨迹编码器**，用于后续意图预测的监督信号和轨迹记忆库的构建。

#### 阶段二：视觉意图预测（Visual Intent Prediction）

- 模型输入为 `X = (I, H, C)`：
  - `I`：四帧前视相机图像（256×256）
  - `H ∈ R^(4×2)`：四个历史自车位置
  - `C ∈ R^4`：导航命令
- **冻结的 V-JEPA 2 视觉编码器**提取视觉 token `F_v`；历史编码器 `E_hist` 和命令编码器 `E_cmd` 分别编码运动历史和导航命令。
- 一个 24 层 Transformer 预测器（hidden=1024, heads=16, 8 个可学习的未来查询 token）融合以上上下文，输出 8 个未来的潜在 token：`Ẑ = P_θ(F_v, F_h, F_c) ∈ R^(8×1024)`。
- 联合嵌入训练目标包含三项，总损失为：
  ```
  L_intent = 0.1·L_feat + 2.0·L_cos + L_NCE
  ```
  - **特征对齐损失 `L_feat`**：对预测与目标潜在进行归一化后计算 Smooth L1 损失。
  - **Token 级余弦对齐损失 `L_cos`**：按 8 个时间位置逐一计算余弦距离，保持时序对应关系。
  - **批级 InfoNCE 损失 `L_NCE`**：以当前场景的目标潜在为正样本，以其他场景的目标潜在为负样本，增强区分度（temperature τ=0.07，分布式训练时跨 GPU 收集负样本）。

#### 阶段三：非参数轨迹检索 + 场景排序 + 可行性门控（推理阶段）

- **轨迹记忆库构建**：仅使用 NAVSIM 训练集中的真实驾驶轨迹（N=110,335 条），每条轨迹用冻结的轨迹编码器编码为 `(Z_n, Y_n)` 对。
- **Top-K 检索**：将预测意图 Ẑ 和记忆库中所有轨迹 latent 展平并 L2 归一化，按扁平余弦相似度排序，检索前 300（K=300）条候选轨迹。
- **场景条件评分器（Scene-Conditioned Scorer）**：以场景特征、自车上下文和候选轨迹为输入，预测质量分数。初始化自 CLOVER 轨迹评分器，在 Auto-JEPA 自身的检索候选分布上重新优化，使用碰撞、可行驶区域、TTC、舒适度、自车进度等监督信号。
- **可行驶区域可行性门控（DAC Gate）**：独立训练二分类器，预测候选轨迹违反可行驶区域约束的概率。若 `p_DAC ≤ 0.2` 则保留候选，否则屏蔽。若全部被屏蔽，则回退到无门控的评分排序。
- **最终选择**：在通过门控的候选中执行带掩码的 argmax：
  ```
  k* = argmax_{k: m_k=1} s_k,   Y* = Y_k*
  ```

## 6. 论文的主要结论与发现

1. **未来意图预测可以替代稠密未来建模**：Auto-JEPA 在完全不做未来视频/占据场重建的情况下，以 91.3 PDMS（v1）和 89.1 EPDMS（v2）达到单相机 SOTA 水平，有力验证了"规划不需要重建完整世界"的核心假设。

2. **模型自发聚焦规划相关特征**：
   - 全验证集上，遮挡动态智能体区域的平均意图变化（1 - cosine similarity = 0.080）是等面积随机遮挡（0.027）的 **2.97 倍**，71.1% 的场景中动态智能体遮挡引起更大响应。
   - 遮挡影响未来驾驶的车辆会显著改变预测意图和所选轨迹，而遮挡不影响驾驶的车辆时几乎无变化——**尽管模型从未接收目标框或交互标签**，该选择性关注能力从未来轨迹潜在表示监督中涌现。

3. **模块解耦有效**：意图预测（决定"何种运动合适"）、轨迹记忆（提供显式几何）、场景评分（评估场景级驾驶质量）、可行驶区域门控（约束可行性）四项职责分离，协同工作优于任何单一模块。

4. **非参数检索切实可行**：固定记忆库 + 余弦检索 + 场景排序，可以在不训练任何生成器的前提下完成高质量规划。

5. **客观的局限性讨论**：论文在补充材料中明确讨论了记忆覆盖范围、评分器校准等失败模式，并给出改进方向，态度客观。

## 8. 不足与局限

### 8.1 方法本身的局限
- **记忆覆盖度受限**：规划性能受限于固定轨迹记忆库的覆盖范围。若检索到的 300 条候选中不存在可行机动，评分器和门控都无法合成新轨迹。K=200→300 的性能饱和（+0.2）表明仅扩大候选池收益有限。
- **不提供场景级预测**：Auto-JEPA 预测的是"场景对自车未来动作的含义"，而非周围智能体的未来状态。这不足以支持交互式仿真、反事实环境生成等需要完整场景演化的应用。
- **单目输入**：仅使用单前视相机，未利用环视相机或 LiDAR 的几何信息，可能在更复杂场景中存在感知信息不足。
- **视觉编码器不可微**：冻结的 V-JEPA 2 意味着视觉特征无法针对驾驶任务端到端调优，存在感知与规划之间的表征鸿沟。

### 8.2 实验覆盖不足
- **无多 seed / 多次运行报告**：所有结果来自一次评估，缺少均值-方差报告，无法量化训练随机性带来的波动。
- **缺少 NAVSIM v1 与 v2 之外的泛化验证**：未在 CARLA、nuScenes 等其他驾驶基准上验证方法的通用性。
- **未评估模型对不同天气/光照等视觉扰动的鲁棒性**；语义遮挡实验只覆盖了空间遮蔽这一种扰动形式。
- **未报告推理延迟（延迟）**:自动驾驶对实时性有严格要求，但论文未给出推理耗时数据。

### 8.3 潜在偏差风险（续）

- **非反应式基准的固有局限**：NAVSIM 使用固定的交通参与者轨迹，不随自车行为改变而反应。这意味着评估只能反映"在给定他人轨迹下的合理决策"，无法检验模型在真实交互博弈（如对方让行/不让行）中的闭环表现。对于依赖"预测意图"做规划的方法而言，这种非反应式评估可能高估其在动态交互场景中的适用性，因为真实世界的其他智能体并非固定脚本。
- **评分器存在分布内训练偏差**：场景评分器是在 Auto-JEPA 自身的检索候选分布上重新适配的，而非在全部可能轨迹空间上训练。如果部署时的检索分布发生偏移（如换用更大的记忆库或不同的视觉编码器），评分器的校准性可能下降。
- **对预训练视觉编码器质量的依赖**：V-JEPA 2 的冻结特征质量直接决定了意图预测的输入上限。论文未消融不同视觉主干（如 DINOv2、CLIP 等）对最终性能的影响，因此"方法的贡献"与"主干的选择"在一定程度上相互纠缠。
- **指标本身的倾向性**：PDMS/EPDMS 由公式加权合成，对舒适度、进度等量的权重设定带有主观性；Auto-JEPA 的高 C（舒适度=100.0）与 EP（进度=87.1）的良好组合可能恰好契合该指标偏好，其真实驾驶质量需要在更多元评估维度下进一步验证。

## 9. 综合评价与阅读建议

### 9.1 总体定位

Auto-JEPA 是"最小化世界模型"在自动驾驶规划中的一次成功实践。它将传统世界模型"预测完整未来"的目标，收敛为"预测与自车决策相关的潜在意图"，在保持端到端传感器到轨迹接口的同时，显著压缩了建模空间，并以 91.3 PDMS（v1）/ 89.1 EPDMS（v2）的单相机成绩验证了该范式的竞争力。

### 9.2 在文献中的位置

- 与 **LAW / DrivingGPT / WoTE / Epona** 等显式预测未来场景的世界模型不同，Auto-JEPA 属于**隐式、面向决策的世界模型**分支，思想上游接近 JEPA 家族的潜在空间预测理念。
- 与 **Hydra-MDP / DiffusionDrive** 等候选轨迹生成范式不同，Auto-JEPA 证明了**非参数记忆检索 + 轻量评分**的路线可以替代学习式轨迹生成器，简化了训练与推理管线。
- 与 **CLOVER** 等"生成器–评分器"框架相比，Auto-JEPA 的检索式生成天然具备真实驾驶数据的几何合理性，且不需要训练生成模块。

### 9.3 适合的读者与场景

- **推荐阅读人群**：关注世界模型范式、端到端规划、表征学习与决策结合的研究者；希望在有限算力（2×A100）下复现 SOTA 规划方法的工程师。
- **值得借鉴的方法论**：语义遮挡配对实验的设计思路（遮挡动态智能体 vs 等面积随机遮挡）具有较高的示范价值，可作为"证明模型关注了什么"的通用验证范式。
- **需谨慎对待的部分**：非反应式基准上的指标绝对数值不宜直接外推为真实道路表现；记忆库覆盖度与评分器校准问题在真实部署前仍需解决。

### 9.4 一句话总结

> Auto-JEPA 用"只预测对规划有用的未来"这一简洁主张，在保留端到端接口的同时实现了单相机 SOTA 规划性能，并为"极端简约世界模型"提供了令人信服的实证支撑——其局限在于记忆覆盖度的天花板与非反应式评估的适用边界。
