## 摘要
轻量级跟踪器已用注意力取代互相关，而在低功耗边缘硬件上，它们为此付出代价，因为注意力中受内存约束的 softmax、归一化和重塑算子所耗时间远超其算术量所暗示的水平。我们在统一的数值验证协议下，于边缘神经处理单元（NPU）和 Arm CPU 上对高效跟踪器进行基准测试，发现相关跟踪器速度更快，但除非采用 ViT 主干，否则精度落后，而这又把注意力带了回来。我们重新审视相关性缺少什么。模板—搜索交互有两个作用：使搜索特征以目标为条件，并在空间上将其与目标匹配。注意力两者都做，而相关性只做匹配，且是在未了解目标的情况下提取的特征上进行匹配。我们提出 TaCo（Target-aligned Correlation，目标对齐相关），通过让模板仅作为每段视频计算一次的操作数进入逐帧网络，从而在不使用注意力的情况下补上缺失的条件化。目标描述符在主干内逐通道缩放和平移搜索特征，而与目标框对齐的核（每个核的权重由模板预测）通过一次矩阵乘法与其进行相关。在主干固定时，我们的相关性仍然不可或缺，同时带来的 NPU 开销可忽略不计，相比我们测试的基于注意力的交互提供了更好的速度—精度权衡。TaCo-T 在 Rockchip RV1126B NPU 上以 184 FPS 达到 62.3% LaSOT AUC，在 Raspberry Pi 5 CPU 上达到 96 FPS，分别为 HiT-Tiny 和 AsymTrack-T NPU 速度的 3.0 倍和 3.5 倍，且精度更高。TaCo-B 在 NPU 上以 50 FPS 达到 65.6%，速度超过 HiT-Base、AsymTrack-B 和 LightFC-vit 的两倍，且精度更高。代码和模型见 https://github.com/TsingWei/TaCo-Tracker。

## Abstract
Lightweight trackers have replaced cross-correlation with attention, and on low-power edge hardware they pay for it, since memory-bound softmax, normalization and reshaping operators of attention cost far more time than their arithmetic suggests. Benchmarking efficient trackers on an edge Neural Processing Unit (NPU) and an Arm CPU under one numerically validated protocol, we find that correlation trackers are the fast ones, but they lag in accuracy unless they adopt a ViT backbone, which brings attention back. We revisit what correlation lacks. Template--search interaction serves two roles: conditioning the search features on the target and matching them against it spatially. Attention does both, whereas correlation only matches, and does so on features extracted without knowledge of the target. We present TaCo (Target-aligned Correlation), which supplies the missing conditioning without attention by letting the template enter the per-frame network only as operands computed once per video. A descriptor of the target scales and shifts the search features channel by channel inside the backbone, and kernels aligned with the target box, each with a weight predicted from the template, correlate with them in one matrix product. With the backbone fixed, our correlation remains essential while incurring negligible NPU overhead, offering a better speed-accuracy trade-off than the attention-based interactions we tested. TaCo-T achieves 62.3% LaSOT AUC at 184 FPS on the Rockchip RV1126B NPU and 96 FPS on a Raspberry Pi 5 CPU, 3.0x and 3.5x the NPU speed of HiT-Tiny and AsymTrack-T at higher accuracy. TaCo-B reaches 65.6% at 50 FPS on the NPU, more than twice the speed of HiT-Base, AsymTrack-B and LightFC-vit, again at higher accuracy. Code and models are available at https://github.com/TsingWei/TaCo-Tracker.

## 一、核心问题与研究背景

- **研究动机**：轻量级视觉跟踪器近年普遍用注意力（attention）替代显式互相关（cross-correlation）来融合模板与搜索特征。但在低功耗边缘硬件上，注意力中的 softmax、LayerNorm、Transpose/Split/Reshape 等**内存受限算子**的实际耗时远超其 MACs 所暗示的水平。
- **关键观察（算子级 profiling）**：在 Rockchip RV1126B NPU 上，ViT-Tiny 跟踪器（1.63 GMACs）耗时 33.63 ms，而 MAC 预算相当的卷积式 TaCo-T（1.49 GMACs）仅 6.19 ms；差距主要来自 fused attention、LayerNorm、layout ops 与 pointwise 算子，而非卷积/线性层。
- **基准测试发现**：在统一的数值验证协议下，相关（correlation）跟踪器在边缘设备上确实更快，但精度落后；若靠 ViT 主干补救精度，又会把注意力带回来，重新引入高延迟。
- **问题重述**：模板—搜索交互承担两个角色——(1) **条件化**：让搜索特征"知道"目标；(2) **空间匹配**：把搜索位置与目标对齐比较。注意力两者兼做但代价高；互相关只做匹配，且是在"没见过目标"的特征上匹配。论文追问：能否在不使用注意力的前提下补上缺失的条件化？
- **整体含义**：为边缘 NPU/CPU 上的实时跟踪提供一条"显式相关 + 缓存式目标条件化"的路线，挑战"低 MACs = 低延迟"与"注意力必然更优"的既有假设。

## 二、方法论

### 2.1 核心设计原则

论文把三种交互形式并列比较：

- 相关：`R = K_z · X`（只匹配，X 未被目标条件化）
- 注意力：`X ← X + V_z · softmax(K'_z^T Q_X / √d)`（匹配 + 条件化，但每帧执行 softmax/归一化/布局算子）
- 调制（FiLM）：`X ← (1 + γ_z) ⊙ X + β_z`（只条件化，不做空间匹配）

由此提出**统一设计规则**：模板派生参数（θ_z）每段视频只计算一次，逐帧仅以**通道级乘加**和**一次矩阵乘法**的操作数形式进入网络，全程不使用 softmax、token 归一化与注意力重塑。

整体形式化为两阶段：

- 一次性阶段：`θ_z = g(z, b)`（z 为首帧模板，b 为目标框）
- 逐帧阶段：`(Ŝ, Ô, B̂) = f(x; θ_z)`

主干为双流共享 CNN（保留 stride 4/8/16 的 s1–s3，去掉 stride-32），模板流不接触搜索区域，仅搜索流被调制。

### 2.2 目标引导调制（Target-guided Modulation）

- 从模板特征 f_z 中按"单元格落在框内的面积比例"加权池化，得到描述符 d。
- 在 s3 的每个 block 之前设置调制位点，由共享 MLP + 每站点独立线性层预测 γ_l、β_l：`h_l ← (1 + γ_l(d)) ⊙ h_l + β_l(d)`。
- 逐站点层零初始化，使训练从普通双流跟踪器起步；每帧每个位点仅一次逐元素乘加。
- TaCo-T / TaCo-S / TaCo-B 分别有 4 / 13 / 25 个调制位点（随 s3 深度而定）。

### 2.3 目标对齐相关（Target-aligned Correlation）

- **核构造**：用 RoIAlign 在目标框对齐网格上采 4×4 目标核（P=4），再对整块模板做 4×4 平均池化得 16 个上下文核（Q=4），共 N_k = 32 个核，按 C^(−1/2) 缩放。相比 LightFC 的固定 8×8 网格，避免目标/背景混合与量化错位；上下文核用平均池化而非最大池化，避免单峰主导并减半核数。
- **相关运算**：`R = K X ∈ R^(N_k×HW)`，每帧一次矩阵乘法，后接 BatchNorm。
- **轻量核加权（Lite Kernel Weighting）**：替代 LightFC 每帧运行的 squeeze-and-excitation。由每个核特征 k_i 及其箱内覆盖率 a_i 经共享 MLP 预测增益 w_i 与偏置 b_i，`R_i ← w_i R_i + b_i`（末层初始化为 w=1, b=0），全部在模板分支一次算好。
- 响应经 1×1 卷积降到 64 通道后与 X 拼接；**丢弃** LightFC 的后相关融合层（深度卷积 + 倒残差），因为 X 已目标感知。

### 2.4 头部与损失

- 128 通道中心头（center head），输出得分图 Ŝ、亚格偏移 Ô、框尺寸 B̂；采用 RepConv 块，训练时多分支、部署时折叠为单个 3×3 卷积。
- 前两层 RepConv 在三个输出分支间共享，末层各自独立。
- 损失：`L = L_focal + 2·L_GIoU + 5·L_1`。

### 2.5 部署侧要点

- 推理时缓存调制参数、相关核与核权重；每帧以 Hann 窗加权得分图并解码峰值框；模板/搜索裁剪因子为 2 / 4。
- 相关输入按 2 的幂缩放以避免响应溢出，补偿系数折入后续归一化。

## 六、主要结论与发现

- **显式相关在边缘上"几乎免费且不可或缺"**：去掉相关损失 2.48 LaSOT / 1.18 VastTrack AUC，却只省 0.20 ms（NPU）与 0.68 ms（Arm）。
- **注意力替换相关代价高且泛化更差**：cross/joint attention 损失 2.9–3.5 LaSOT、6.6–7.1 VastTrack AUC，NPU 延迟升至 1.4–1.7 倍、Arm 升至 2.3–2.8 倍；VastTrack 上的损失约为 LaSOT 的两倍，说明学习式注意力读出在广类别上泛化弱于相关的内置 2D 对应性。
- **调制补上条件化且开销极低**：贡献 0.59 LaSOT / 0.77 VastTrack AUC，仅占帧时 <2.3%；放在 s3 之前（而非 s1/s2）在精度—延迟上最优。
- **目标对齐核 + 轻量核加权有效**：目标对齐 +0.73 LaSOT，核加权 +0.62；但目标对齐需配合 LKW 才生效（配 SE 反而从 61.50 降到 60.83）；去掉后相关融合层反而取得最高 AUC（61.55）与最低延迟。
- **跨主干可迁移**：HiT-Tiny +6.1 AUC 且延迟降 2.68 ms；LightFC +1.5 AUC 且延迟略降；AsymTrack-T 精度持平但 NPU 延迟降 34%。
- **数值鲁棒性差异**：31 个模型中 4/4 相关基线、3/3 TaCo 图在双设备通过 FP16 检查；24 个注意力变体中 19/24（RV1126B）与 16/24（Pi 5）通过，9 个至少在一台设备失败，失败点集中在 softmax 或 token 选择。
- **最终性能**：TaCo-T 在 RV1126B 上 183.6 FPS / 62.3% LaSOT AUC（Arm 96.3 FPS），为 HiT-Tiny 的 3.0×、AsymTrack-T 的 3.5×；TaCo-B 50.4 FPS / 65.6% AUC，约为 HiT-Base、AsymTrack-B、LightFC-vit 的两倍速且精度更高；Orin Nano 上 TaCo-T 达 1203.9 FPS、仅 11 MB 显存。

## 七、优点

- **问题切入有说服力**：以真实设备上的算子级 profile 而非理论 MACs 立论，直接指出"低 MACs ≠ 低延迟"，对边缘部署社区有实际指导价值。
- **方法设计克制且自洽**：把交互拆成"条件化"与"匹配"两个正交角色，用最便宜的算子（通道乘加 + 一次矩阵乘）分别实现，且模板派生量全部每视频缓存一次，工程可落地性强。
- **消融有针对性**：不仅做移除实验，还用注意力替换相关做"同功能对照"，并用 VastTrack 与 LaSOT 的损失比例差异支撑"相关的 2D 归纳偏置更利于泛化"的解释。
- **评测严谨**：统一数值验证门槛、失败图灰色标注、区分本地复现与官方服务器结果、公开代码与模型；还报告内存与功耗，覆盖实际部署关切。
- **迁移实验增强说服力**：在 HiT、LightFC、AsymTrack-T 三种范式上替换交互，证明增益不依赖特定主干。
- **可视化有解释力**：用实测响应图展示目标核/上下文核的互补激活、核行质心顺序保持，以及用跨视频均值替换调制操作数后峰值漂移到干扰物，直观支撑"调制提供实例选择性、相关提供有序定位"的论断。

## 八、不足与局限

- **消融配置与最终模型不完全一致**：Tab.3–5

- **消融配置与最终模型不完全一致**：Tab.3–5 采用 200 epoch、2 个随机种子的简化设置，而最终模型训练 300 epoch；因此消融表中的绝对 AUC 不能与主表逐项对齐，只能解读相对趋势。更关键的是，论文未报告种子间标准差或置信区间，像调制 +0.59、核加权 +0.62 这类量级的增益是否显著超出训练噪声，读者无法独立判断。
- **训练数据不对等**：TaCo 使用 LaSOT + GOT-10k + COCO + VastTrack 的混合训练，数据规模与多样性可能优于部分对比方法。作者用 GOT-10k-only 协议（Tab.9）作了部分缓解，但该设定下 TaCo-B 的 66.7 AO 反低于 FERMT 的 69.6，说明"精度优势"在数据受限时并不稳固，主表结论对训练配方存在一定依赖。
- **硬件覆盖偏窄**：主基准集中在 Rockchip RV1126B（单一国产 NPU）、Raspberry Pi 5（Arm CPU）与 Orin Nano（TensorRT）三类平台，缺少高通 Hexagon、联发科 APU、Apple Neural Engine、Intel NPU 等更主流的移动/PC 端推理后端。由于"内存受限算子"的实际代价高度依赖具体编译器与算子融合策略，论文关于注意力开销的定量结论能否迁移到其他工具链（SNPE、TFLite、CoreML、OpenVINO）尚未验证。
- **数值验证门槛的经验性**：相对 L2 ≤ 0.02、最大绝对误差 ≤ max(0.005, 0.05·‖Y_ref‖∞) 等阈值由作者设定，论文未讨论阈值放宽或收紧时"通过/失败"统计的敏感性；灰色标注把"数值不达标"与"根本不可部署"混为一类，可能夸大注意力方法在工程上的不可行程度。
- **超参敏感性分析不足**：相关核的 P=4、Q=4、N_k=32 主要依据与 LightFC 的对照经验确定，缺少对核网格尺寸、核数量、上下文池化方式的扫描；调制位点也仅在 s1/s2/s3 的有限组合上枚举（Tab.4），未给出"位点数—精度—延迟"的连续 scaling 曲线，也未分析调制通道维度与主干宽度之间的耦合。
- **训练成本与能效信息缺失**：论文报告了边缘侧推理延迟、内存与功耗，但未给出参数量、FLOPs 之外的完整模型体积表、训练 GPU 小时数或训练能耗，因而无法评估"精度/能效"的全生命周期权衡；也未系统给出 FPS/W 这类能效比指标与基线的横向对比。
- **失败模式分析偏定性**：定性图中对失败序列作了灰色标注，但未统计失败在遮挡、快速运动、相似干扰物、尺度剧变等属性维度上的分布，也未与 14 维属性雷达图建立对应解释。
- **模板更新与长时鲁棒性未展开**：方法把模板派生量（调制参数、相关核、核权重）在首帧一次算好并全程缓存，这一设计的代价是缺乏对目标外观漂移的自适应机制。论文未讨论是否需要、以及如何以低成本引入模板更新，也未针对长时序列（如 LaSOT 平均两千余帧）单独分析缓存策略的衰减特性。
- **注意力基线选择的可商榷处**：对比的注意力跟踪器多为完整 softmax 注意力实现，未与已针对边缘做过算子级优化的线性注意力、token 剪枝/合并或量化友好注意力变体在同条件下比较，因此"注意力路线代价高"这一结论的普适性仍需更精细的对照。

## 九、启示与适用边界

- **方法论启示**：论文示范了一条"以部署端算子级 profile 反推架构设计"的研究范式——先测量真实瓶颈（softmax、LayerNorm、layout ops），再据此把交互拆解为可用廉价算子实现的子功能。这一思路可迁移到检测、ReID、多模态适配器等同样依赖跨图/跨模态交互的任务。
- **设计模式可复用**："模板派生参数一次算好、逐帧只做通道乘加 + 一次矩阵乘"的缓存式条件化，适合任何模板在推理期内基本固定的场景（单目标跟踪、少样本分类、参考式分割）；但其前提是目标外观在视频内变化有限，外观剧变场景需另配轻量更新机制。
- **结论的适用边界**：论文的定量结论建立在"NPU 编译器对注意力算子支持不佳"这一现实之上。随着 NPU 工具链逐步原生支持 fused attention 与高效 softmax，注意力与相关之间的延迟差距可能收窄；因此论文的核心贡献更应被理解为"在当前边缘工具链条件下，显式相关 + 调制是性价比最高的交互形式"，而非"注意力在原理上劣于相关"。
- **对评测实践的建议**：论文提出的统一数值验证协议（含零 CPU 回退算子要求、峰值单元格一致性与解码框 IoU 检查）值得被边缘跟踪基准采纳，可缓解当前文献中"MACs 可比、实际延迟不可比"的普遍问题。

## 十、总体评价

这是一篇**问题意识清晰、工程落地性强、评测严谨度高于同类**的边缘视觉跟踪工作。其核心贡献不在于提出更复杂的网络结构，而在于：(1) 用真实设备的算子级测量纠正"低 MACs = 低延迟"的行业惯性；(2) 把模板—搜索交互拆成"条件化"与"空间匹配"两个正交角色，并分别用通道调制与显式相关以近乎零额外延迟的方式实现；(3) 通过跨主干迁移、注意力替换对照与三设备部署验证，把设计选择与主干、工具链因素尽量解耦。

主要短板集中在**实验严谨性的细节**（消融与最终模型配置不一致、缺少方差报告、训练数据不对等）与**结论外推的边界**（硬件与工具链覆盖有限、超参敏感性未扫描、模板更新缺位）。这些不足不否定其核心论点，但提示读者在引用其精度增益时应保留余量，在移植其设计时应重新做本地 profile 验证。

综合而言，该论文对"边缘实时跟踪应如何设计交互模块"给出了一个可复现、可迁移且经过多设备验证的强基线方案，其**测量驱动的设计方法论**与**统一数值验证协议**的参考价值，可能超过模型本身的精度数字。
