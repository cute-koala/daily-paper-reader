Abstract
RGB-based video object segmentation (VOS) remains brit-
tle under fast motion and adverse illumination.
Event
cameras preserve signal under blur and challenging expo-
sure, but provide little evidence when motion slows. In-
teraction can restore object state for subsequent propa-
gation, yet promptable event methods merely address sin-
gle windows. We formalize event-based Promptable Video
Segmentation (ePVS), where prompts at arbitrary win-
dows initialize, correct, or introduce objects and predic-
tions. We present Event Memory-As-Prompt Segmentation
(E-MAPS), which transfers a pretrained promptable seg-
menter to event streams and learns propagation and correc-
tion. Event-to-Token (E2T) aligns recurrent event features
with pretrained representations while preserving prompt-
conditioning priors. Memory-Aware Prompting (MAP) con-
verts object-conditioned history into sparse prompts, allow-
ing memory and user inputs to share one decoder path-
way efficiently. We construct Event-View Masklets (EViM)
from 206K aligned RGB–event pairs and ∼620K masks
for two-stage representation transfer and native event-video
learning, and establish three training-disjoint benchmarks.
E-MAPS leads prompt-once and interactive ePVS across
all three benchmarks while being more efficient.
It fur-
ther demonstrates strong performance on zero-shot object
tracking benchmarks. Project page: https://github.
com/adonaydem/emaps-wacv.
1. Introduction
Video Object Segmentation (VOS) aims to segment target
objects across video frames while maintaining their iden-
tities [5, 10–12, 31, 33, 52, 61]. Despite strong progress,
RGB-based methods can struggle with fast motion and dif-
ficult lighting, where blur and poor exposure weaken visual
cues [8, 14, 17, 24, 25, 28, 43, 53, 62, 64]. Event cam-
eras address some of these challenges by recording bright-
ness changes with microsecond latency and high dynamic
range [7, 16]. Yet their continuous, change-driven streams
require efficient processing and may contain limited shape
or identity cues during slow motion or low illumination
[27, 60]. Tracking objects from events therefore requires
maintaining identity through sparse activity, occlusion, and
disappearance. Promptable segmentation offers a flexible
way to specify and correct objects using points, boxes, or
masks [6, 22, 29, 37, 41]. For event streams, we find that
these prompts can also recover object state and guide sub-
sequent propagation when observations are weak. Existing
Event-SAM adaptations mostly focus on individual win-
dows or RGB–event fusion [8, 14, 24, 53], while event-
only VOS has mainly supported initial-mask propagation
without subsequent interaction [64]. We therefore study an
event-only setting that combines prompt-conditioned seg-
mentation with temporal propagation in a single model.

We address this task with Event Memory-As-Prompt

Our contributions are:
• Task. We formalize ePVS, where prompt-once propaga-
tion and arbitrary-window interaction produce identity-
consistent masklets despite intermittent event observa-
tions (Sec. 3).
• Model. We propose E-MAPS, an efficient promptable
event-based VOS framework that uses E2T for trans-
fer into a SAM-style feature space, learns propagation
and interaction from event masklets, and injects tem-
poral memory as sparse prompt tokens through MAP
(Secs. 4.2–4.4).
• Data.
We introduce EViM, with over 206K aligned
RGB–event pairs and 620K masks supporting large-scale
and diverse pretraining across both stages(Secs. 5 and 6).
Experiments on EViM, FE108 [55], and VisEvent [47] show
that E-MAPS achieves leading prompt-once and interactive
ePVS results. It outperforms SAM2.1 B+ while operating at
a much faster frame rate. On the zero-shot VisEvent testbed,
E-MAPS also achieves the strongest prompted result and
the largest relative gain from additional prompts over SAM2
and SAM-I2V.
2. Related Work
2.1. Promptable Segmentation Foundation Models
Promptable segmentation allows users to specify and refine
target objects through points, boxes, or masks [22]. SAM
established a flexible encoder–prompt–decoder architec-
ture [22], which TinySAM later made more efficient [41].
Building on this foundation, SAM2 introduced stream-
ing memory for video segmentation [37], while SAM-I2V
adapted image-based SAM models to promptable video
tasks [29].
Alongside these developments, VOS meth-
ods have relied on dense space–time memories to asso-
ciate objects across frames and propagate their masks [10–
12, 31, 52, 61]. E-MAPS builds on TinySAM’s compact se-
mantic and prompt priors while learning temporal dynamics

2.2. Event Representation Transfer and SAM
Adaptation
Event segmentation spans event-native encoders, RGB-to-
event transfer, and cross-modal fusion [1, 44, 49, 56, 57].
EventSAM enables SAM-like event prompting through
weighted distillation [8], while SAM-Event-Adapter and
EVSAM inject event cues into image models [14, 53].
MemorySAM applies SAM2-style memory to multimodal
semantic segmentation, and other work studies language
guidance and event-domain representation learning [9, 23,
24, 28, 34].
These methods establish promptable event
segmentation and cross-modal adaptation, mainly for per-
window or multimodal prediction, while we seek to learn
temporal dynamics under intermittent event streams.
2.3. Event-based Video Segmentation and Tracking
ECOS is the closest event-only VOS predecessor, propagat-
ing an initial mask through recurrent event representations
and cross-time matching [64].
Event-assisted low-light
VOS [25] and EVOLVE [2] instead combine frames and
events through memory matching or dual-memory refine-
ment. Related work also studies event-guided video seg-
mentation, frame–event instance segmentation, and high-
rate tracking through frame–event fusion or RGB-to-event
transfer [20, 48, 54, 58].
E-MAPS targets event-only
mask propagation from point, box, or mask prompts, with
arbitrary-window correction and object insertion.

5. Data Construction
5.1. Datasets and EViM construction.
We build supervision from three complementary event
sources. EOS [64] provides DAVIS-style sequences with
native event-view instance masks.
DSEC-Detection [18,
19] provides real driving videos with dense boxes, class la-
bels, and persistent track IDs. N-ImageNet [21] contributes
broad semantic diversity through RGB–event pairs. Since
DSEC-Detection and N-ImageNet lack instance masks,
we construct and release Event-View Masklets (EViM)
using a semi-automated cross-modal annotation pipeline.
EViM contains 206,811 RGB–event pairs and approxi-
mately 620K event-view instance masks. Table 1 compares
EViM with prior datasets, which mainly provide semantic
labels, image-level instances, or smaller video collections.


EViM construction. For each RGB–event pair, an RGB
teacher model generates candidate masks with confidence
scores. Accepted masks are then transferred into the event-
camera image plane. For teacher model, we consider large
variants of SAM2.1 [37] and SAM3 [6]. SAM3 produces
higher-quality masks, while cross-teacher agreement shows
limited dependence on the selected teacher.
For DSEC-Detection, we prompt SAM3 on the synchro-
nized RGB image using the ground-truth box and class text.
We project each mask to the left event-camera view using
the provided calibration. Masks are retained based on con-
fidence and box–mask agreement, then grouped by track ID
to form masklets.
For N-ImageNet [21], we prompt SAM3 using Ima-
geNet [40] synset labels and co-occurring concepts to im-
prove multi-object coverage.

EViM benchmarks.
We construct three fixed, training-

5.2. Quality control (QC)
EViM combines automatic filtering with human verifica-
tion.
DSEC proposals are filtered using confidence and
box–mask agreement, while N-ImageNet proposals are fil-
tered using confidence and homography support. Review-
ers then audit RGB–event–mask triplets for object iden-
tity, event-view alignment and geometric validity. In a fi-
nal 2,000-triplet audit, 92.2% of post-QC masks are judged
correct, while the hard failure rate decreases from 25.7%
before QC to 4.8%.
6. Experiments
Training setup.
We initialize the TinySAM image en-
coder, prompt encoder, and mask decoder from the public
TinySAM checkpoint [41], whereas RTEE, E2T, the mem-
ory module, MAP, and the occlusion head are randomly
initialized and trained from scratch. Training follows the
two-stage procedure in Sec. 4.4: Stage I performs token-
space alignment for 20 epochs with batch size 16, and Stage
II trains clip-level propagation with memory prompting for

betas 0.9, 0.999. Newly introduced modules use an initial
learning rate of 3×10−4, while TinySAM-initialized mod-

Table 5 evaluates memory retrieval and decoder injection
while keeping the event-derived scene and object memory

36.55 ms (4.16× faster).
Combining MAP with dense
cross-attention yields no further improvement. Removing
Sparse-Motion Adjustment reduces performance, with the
largest drop on EViM-HM. Tables 6 and 7 assess the train-
ing objectives. In Stage I, the full objective improves J &F
from 53.17 to 57.07 over Dice+L1 alone, translating to
a downstream Stage-II improvement from 76.34 to 81.37.
Removing Dice or L1 reduces the final score to 75.96 and
79.45, respectively, highlighting their complementary con-
tributions. In Stage II, ablating Dice, focal, occlusion, or
IoU supervision lowers performance. Finally, Table 8 ex-
amines memory token capacity and current-window condi-
tioning early in the training stage. Increasing K from 1 to 2
improves performance, while conditioning on current event
evidence benefits both token budgets. Combining the two
yields the best results, emphasizing the value of grounding
compact memory representations in current observations.

7. Conclusion
We introduced ePVS, where arbitrary-window prompts ini-
tialize, correct, or introduce objects and predictions form
identity-consistent masklets.
We presented E-MAPS, an
event-only framework that retains pretrained semantic and
prompting priors while learning propagation and correc-
tion directly from event masklets.
E2T aligns recurrent
event features with the pretrained representation space,
while MAP converts object-conditioned history into sparse
prompts, allowing memory and user inputs to share one effi-
cient decoder pathway. We also introduced EViM for scal-
able representation transfer and event-video learning. We
extensively evaluate E-MAPS across prompt-once and in-
teractive ePVS, and zero-shot tracking on FE108 and Vi-
sEvent. These evaluations show that E-MAPS provides ac-
curate and efficient segmentation from sparse event streams.
