## 摘要
跟踪物体在变换中的变化对于理解真实世界动态至关重要。近期工作将传统目标跟踪扩展至检测状态变化。然而，现有方法需要初始物体提示，并且只检测其分解，遗漏了以多个物体而非单个物体为起点的组装事件。因此，我们为该任务引入一种无提示的表述：仅给定一段视频，目标是恢复所有物体轨迹并检测分解与组装两类事件。我们的关键洞察是，组装是分解的逆过程。基于这一洞察，我们提出 Atlas，一种零样本系统，它构建正向与反向时空划分并对其进行联合推理，以恢复物体轨迹及其变换。我们进一步引入 OmniST，一个对物体及两类变换均提供密集标注的基准。在 OmniST 上，Atlas 恢复的状态变化数量是先前方法的两倍以上，同时在仅评估分解的现有基准上仍保持竞争力。

## Abstract
Tracking objects through transformations is essential for understanding real-world dynamics. Recent work has extended traditional object tracking to detect state changes. However, existing methods require an initial object prompt and detect only its decompositions, missing assembly events, which begin with multiple objects rather than one. We therefore introduce a prompt-free formulation of this task, where the goal is to recover all object tracks and detect both decomposition and assembly events given only a video. Our key insight is that assembly is decomposition in reverse. Building on this insight, we present Atlas, a zero-shot system that constructs and jointly reasons over forward and reverse spatiotemporal partitions to recover object tracks and their transformations. We further introduce OmniST, a benchmark with dense annotations of objects and both transformation types. On OmniST, Atlas recovers more than twice as many state changes as prior methods while remaining competitive on existing benchmarks that only evaluate decomposition.

## 1. 核心问题与研究动机

- **背景**：物体变换（切菜、拆包装、拼装玩具、毛毛虫化蛹等）普遍存在，理解这些状态变化对具身智能体的动作前后条件推理、野生动物监测、从演示中提取子目标等任务都很重要。
- **现有路线一（MLLM 直接描述）**：多模态大模型只能给出粗粒度的事件描述，缺乏像素级/时空定位，无法把“男孩拼玩具”绑定到具体零件及其组合方式上。
- **现有路线二（TubeletGraph / FluxGraph 等“Track Any State”）**：在第一帧给定目标物体掩码作为提示（prompt），跟踪该物体并输出状态图（记录变换时间、参与物体、自然语言描述）。
- **关键缺陷**：
  - 任务被限定为“跟踪单个被提示物体”，因此**只能检测分解（decomposition）**——被跟踪物体碎成可独立跟踪的部件；当发生**组装（assembly，多物体合并）**时，系统要么静默终止轨迹，要么让轨迹穿过合并后的整体，输出不完整且有误导性。
  - 无法检测**先前分解产物再次发生的变换**（例：箱子→取出袋子→从袋子取出饼干→把袋子放回箱子，后两个事件均被漏检）。
- **本文主张**：放松“单一提示物体”假设，提出**无提示（prompt-free）的任务形式**——仅给定视频，输出所有物体轨迹，并检测分解与组装两类事件，形成时空状态图。
- **核心洞察**：**组装是分解的逆过程**；一段“物体合并”的视频在时间反演后与“物体分裂”不可区分。

## 2. 方法论（ATLAS）

### 2.1 任务形式化

- 输入：视频 \(V=\{I_t\}_{t=1}^{T}\)（无初始掩码）。
- 输出：
  1. 轨迹集合 \(\mathcal{T}=\{T^1,\dots,T^N\}\)，每条轨迹是掩码序列 \(\{M^i_t\}\)；
  2. 变换集合 \(\mathcal{S}=\{s\}\)，其中 \(s=(t, T_{pre}, T_{post}, D)\)，\(t\) 为发生帧，\(T_{pre},T_{post}\subseteq\mathcal{T}\) 为变换前后的轨迹集合，\(D\) 为自然语言描述。
- TubeletGraph 的原表述被视为本任务的一个特例（额外输入首帧掩码，且输出限制在与提示物体相关的子集）。

### 2.2 双向时空划分构建

- 正向：用 **CropFormer**（Hornet3X）分割每帧，用 **SAM2.1-L** 从首帧实体向前传播；若某帧实体的面积被已有轨迹覆盖比例低于 \(\tau_{coverage}\)，则新建轨迹。
- 去重：两条已跟踪超过 5 帧的轨迹若 IoU 超过 \(\tau_{dup}=0.9\)，终止置信度较低者，以保持空间上互异的实体集合。
- 反向重复同一流程，得到反向划分。最终得到正向/反向 tubelet 池 \(\mathcal{P}_F\)、\(\mathcal{P}_R\)。

### 2.3 状态变化检测（两个谓词 + 两个方向）

- **匹配谓词**：\(P_A\) 在帧 \(t\) 匹配 \(P_B\) 需同时满足包含度 \(\frac{|e^A_t\cap e^B_t|}{|e^A_t|}>\tau_{contain}=0.7\) 与 IoU \(\frac{|e^A_t\cap e^B_t|}{|e^A_t\cup e^B_t|}>\tau_{IoU}=0.05\)。
- **核心假设**：由变换产生的 tubelet 在空间上源自先前已跟踪物体；新进入视野的物体则不然。
- **分解（正向涌现）**：正向 tubelet \(P_{F,i}\) 在 \(t>1\) 新出现 → 在帧 \(t\) 找匹配的反向 tubelet \(P_{R,j}\) → 在 \(\omega=1\)s 窗口内回看，若在 \(t-\delta\) 处 \(P_{R,j}\) 匹配某个已跟踪的 \(P_{F,k}\)，则判定候选分解，记录 \((t,\{P_{F,k}\},\{P_{F,k},P_{F,i}\})\)，并把 \(P_{F,i}\) 与 \(P_{R,j}\) 标记为重复。
- **组装（反向涌现）**：反向 tubelet \(P_{R,i}\) 在 \(t<T\) 新出现 → 与正向 tubelet \(P_{F,j}\) 匹配 → 向前搜索 \(\omega\)，若在 \(t+\delta\) 处 \(P_{F,j}\) 匹配 \(P_{R,k}\)，则判定候选组装，记录 \((t,\{P_{R,i},P_{R,k}\},\{P_{R,k}\})\)。

### 2.4 VLM 验证与时间重对齐

- 动机：空间巧合会造成假阳性；且 SAM2 在分解时常把分离物体保持为单一掩码若干帧，导致**分解被晚检、组装被早检**。
- 做法：用 **GPT-4.1**（temperature 0）。输入包含（a）全视频均匀采样的完整帧提供上下文；（b）事件附近帧，裁剪到参与物体包围盒的并集并叠加轮廓。
- **非对称采样**：疑似分解采样 \([t-\omega_{long}, t+\omega_{short}]\)，疑似组装采样 \([t-\omega_{short}, t+\omega_{long}]\)，其中 \(\omega_{long}=4\)s、\(\omega_{short}=1\)s。
- VLM 判定是否真的发生变换，并输出“分离首次可见 / 合并首次完成”的帧号作为最终事件时间，同时给出动作名与前后物体名称。

### 2.5 统一时空划分

- 对 \(\mathcal{P}_F\times\mathcal{P}_R\) 计算时间重叠上的视频级平均 IoU，用**匈牙利匹配**保留超过 \(\tau_{merge}=0.75\) 的配对，加上检测阶段确认的匹配，取时间戳与掩码的并集合并为单条 tubelet。
- 依据 VLM 对齐结果裁剪轨迹：分解则新生轨迹从 \(t\) 开始；组装则新生轨迹在 \(t\) 结束；并从源 tubelet 掩码中减去新生物体掩码以避免重叠。
- 未被匹配、也未被关联到变换的 tubelet，若其面积被覆盖比例低于 \(\tau_{area}=0.2\)，则补入最终池，保证完整覆盖。

  - 报告了配对 bootstrap 置信区间与超参敏感性，结论不依赖单一阈值点。
  - 与基线共享同一套骨干模型，控制变量较好。
- **需要打折之处**：
  - **M3-VOS 上主动剔除 20 段视频**（因其标注在组装后仍单独跟踪被插入物体，与本文“大物体掩码吸收小物体”的约定冲突），虽声明所有方法在同一子集上评估，但改变了基准，横向可比性受限。
  - **VOST-TAS 评估只保留涉及提示物体及其产物的预测**，丢弃其余预测，这对无提示方法是一种人为裁剪。
  - 语义准确率 \(S_V,S_O\) 由 **GPT-4.1 担任裁判**，存在 LLM 评判偏置，且未报告人工校验一致性。
  - OMNIST 规模较小（97 段、平均 13.6 秒、无跳切），事件数仅 302，长视频与复杂场景覆盖有限。
  - 未见对失败案例的定量统计（仅定性提及）。

## 6. 主要结论与发现

- **OMNIST 上全面领先**：\(J_{tubelet}=68.7\)（比 TubeletGraph 高 11.4）；总体召回 \(H\) 从 TubeletGraph-Bidir 的 16.2 提升到 36.1（>2×），总体精度 \(H_P\) 从 12.2 提升到 48.2（约 4×）。
- **分类型**：组装事件总体召回从 9.0 → 34.7；分解事件从 22.8 → 37.3。
- **双向独立运行不够**：给 TubeletGraph-Bidir 加上同样的 VLM 验证与重对齐后仅达 \(H=23.2\)、\(H_P=29.3\)，说明剩余差距来自**对正反划分的联合推理**而非单纯后处理。
- **增益来源分析**：
  - 恢复了 8 个“先前分解产物再次分解”的事件（TubeletGraph 因只推理提示物体而漏检）。
  - 有 13 个变换满足 TubeletGraph 的空间邻近先验但不满足其语义先验（FC-CLIP 特征相似度），典型如 SD 卡插入相机、眼镜放入镜盒、从镜盒取出清洁布——说明语义先验对组装尤其不适用。
- **旧基准不退化**：VOST \(J=50.2\)（TubeletGraph 50.9、FluxGraph 52.8），VSCOS、M3-VOS 上与提示式方法相当，同时是唯一能同时恢复两类事件的方法。
- **VOST-TAS 语义大幅提升**：\(S_V\) 81.8 → 89.5，\(S_O\) 72.3 → 97.3，时间精度 \(T_P\) 43.1 → 51.4；但时间召回从 20.4 降至 17.6（验证会过滤掉部分有效变换）。
- **消融结论**：验证主要提升精度（\(T_P\) 77.4→64.6 若去掉，\(H_P\) 48.2→34.7），重对齐主要提升召回与整体（去掉后 \(H\) 36.1→25.2），两者皆去最差（\(H=22.8\)）。
- **VLM 基线的定位**：GPT-4.1 系列时间定位与语义准确率最高，说明 VLM 能可靠判断“发生了什么、何时发生”，但时空召回只有 ATLAS 约三分之一，难以定位参与物体——正好印证“VLM 做语义/时序、几何方法做空间接地”的分工。

## 7. 优点

- **任务层面的推进**：指出“提示式单物体跟踪”这一形式化本身的缺陷（无法表达组装），并给出无提示的完整形式化，问题定义清晰且有实际意义。
- **洞察简洁而有效**：“组装是分解的逆过程”把一个不对称难题转化为对称的双向搜索，且工程上可复用现有分割/跟踪器（CropFormer + SAM2），无需训练。
- **联合推理优于朴素双向**：不仅跑两遍，而是用跨方向的匹配谓词把正反 tubelet 对应起来，并用消融（TubeletGraph-Bidir + VLM）明确证明这一点。
- **误差来源分析到位**：明确诊断出“分解晚检、组装早检”的系统性偏差，并据此设计**非对称采样窗口**，是有物理依据而非拍脑袋的设计。
- **指标设计有思考**：意识到组装后物体身份会合并、传统 \(J\) 不适用，提出按变换边界切分 + 匈牙利匹配的 \(J_{tubelet}\)。
- **数据贡献扎实**：OMNIST 提供逐帧密集掩码（54,369 个，对比 VOST-TAS 的 350 个）与两类事件，并公开数据与代码。
- **效率反而不劣**：由于一次性联合传播所有实体，跟踪速度比逐实体的 TubeletGraph 快约 4 倍（2.97 vs 13.04 s/帧），部分抵消了双向带来的开销。
- **透明度**：明确声明 LLM 仅用于代码实现与写作润色，未用于研究想法、数据创建或结果解读。

## 8. 不足与局限

**方法层面（作者自述 + 分析）**

- **依赖“新 tubelet 涌现”这一信号**：不产生分裂/合并的**渐变式原地状态变化**（融化、形变、颜色变化、液体混合等）完全无法检测。
- **依赖跟踪器的“假阴性”**：必须让 SAM2 在变换产物上可靠地失败、从而涌现新轨迹；若跟踪器过于鲁棒地跨越变换，事件将被漏检——这是把跟踪器的缺陷当作信号，鲁棒性存在隐患。
- **双向划分成本高**：需构建两套时空划分，整体推理开销大（虽然可并行、且已有 FluxGraph 类加速可迁移）。
- **超参较多**：\(\tau_{coverage},\tau_{dup},\tau_{contain},\tau_{IoU},\omega,\omega_{long},\omega_{short},\tau_{merge},\tau_{area}\) 共 9 个阈值，虽声称在独立视频上选定一次，但敏感性分析只覆盖了其中 3 个（\(\tau_{contain},\tau_{IoU},\omega\)）。
- **VLM 判定不可解释/不稳定**：GPT-4.1 作为验证器可能拒绝有效变换（VOST-TAS 上时间召回下降即为例证），且不同 VLM 版本的可复现性未讨论。

**数据与评测层面**

- **OMNIST 规模偏小、场景受限**：97 段、平均 13.6 秒、无跳切、以家务/烹饪/组装为主，长视频、多人交互、遮挡严重场景未覆盖；302 个事件对统计功效仍偏紧。
- **基准修改影响可比性**：M3-VOS 剔除 20 段视频、VOST-TAS 只保留涉及提示物体的预测，两处都使结果不能与原始榜单直接对话。
- **LLM-as-judge 偏置**：语义正确性由 GPT-4.1 判定，缺乏人工一致性校验或与人类评分的相关性分析。
- **“变换”的定义较窄**：附录中援引认知科学的“连贯性（cohesion）”原则来界定变换，因此只覆盖破坏/建立连贯性的事件，对不改变连贯性的状态变化（如颜色、温度、形变）明确排除在外。
- **未报告失败案例的定量分析**：仅定性提及，缺少漏检/误检的类型学统计。

**应用层面**

- 作为零样本流水线，误差会跨阶段累积（分割 → 跟踪 → 匹配 → VLM 验证 → 合并），端到端可靠性未做误差传播分析。
- 逐帧分割 + 双向跟踪的算力需求（约 4.2 s/帧单卡）对实时或长视频应用仍是障碍。
