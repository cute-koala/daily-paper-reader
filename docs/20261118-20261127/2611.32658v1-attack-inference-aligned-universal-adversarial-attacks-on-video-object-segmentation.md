## 摘要
现代视频对象分割（VOS）依赖两阶段推理范式：目标初始化与基于记忆的传播。然而，现有针对VOS的对抗攻击往往忽视这一结构。为弥补这一空白，我们提出AUV，一种与VOS模型的通用两阶段范式对齐的对抗框架。具体而言，AUV通过分别为初始化和传播阶段定制的解耦训练策略来优化通用对抗扰动（UAP）。通过破坏共享记忆空间，它实现了跨不同模态的提示无关攻击，包括掩码、点、框和语言。大量实验表明，AUV达到了最先进的VOS攻击性能，例如在DAVIS17-val上将基于掩码的SAM3降至仅8.4 J&F（相同训练设置下此前SOTA为55.4）。它还表现出优越的时间动态特性：起效最快、持续时间最久，并支持视频中途任意时刻攻击。AUV优化框架适用于不同的VOS模型，揭示了真实流式VOS中的脆弱性。代码见 https://github.com/FudanCVL/AUV。

## Abstract
Modern video object segmentation (VOS) relies on a two-stage inference paradigm: target initialization and memory-based propagation. However, existing adversarial attacks on VOS often overlook this structure. To bridge this gap, we propose AUV, an adversarial framework that Aligns with the Universal two-stage paradigm of VOS models. Specifically, AUV optimizes a universal adversarial perturbation (UAP) through decoupled training strategies tailored for both initialization and propagation stages. By disrupting the shared memory space, it achieves prompt-agnostic attacks across different modalities, including masks, points, boxes, and language. Extensive experiments show that AUV establishes state-of-the-art VOS attack performance, such as degrading mask-based SAM3 to only 8.4 J&F on DAVIS17-val (compared to 55.4 for the previous SOTA under the same training setup). It also exhibits superior temporal dynamics with the fastest onset, the most enduring persistence, and the support of any-time mid-video attacks. The AUV optimization framework is applicable to different VOS models, revealing vulnerabilities in real-world streaming VOS. Code is available at https://github.com/FudanCVL/AUV.
