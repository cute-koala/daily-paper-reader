## 摘要
基于RGB的视频目标分割（VOS）在快速运动和不利光照条件下仍然脆弱。事件相机在模糊和挑战性曝光下能够保留信号，但当运动变慢时提供的证据很少。交互可以恢复对象状态以供后续传播，但可提示的事件方法仅处理单个窗口。我们形式化了基于事件的可提示视频分割（ePVS），其中任意窗口的提示可初始化、校正或引入对象和预测。我们提出事件记忆作为提示分割（E-MAPS），将预训练的可提示分割器迁移到事件流，并学习传播与校正。事件到令牌（E2T）将循环事件特征与预训练表示对齐，同时保留提示条件先验。记忆感知提示（MAP）将对象条件历史转换为稀疏提示，使记忆和用户输入能够高效共享一个解码器通路。我们利用206K对齐的RGB-事件对和620K掩码构建事件视图掩码片段（EViM），用于两阶段表示迁移和原生事件视频学习，并建立三个训练不相交的基准。E-MAPS在所有三个基准上在单次提示和交互式ePVS中均领先，同时更高效。它进一步在零样本目标跟踪基准上展现出强劲性能。项目页面：https://github.com/adonaydem/emaps-wacv

## Abstract
RGB-based video object segmentation (VOS) remains brittle under fast motion and adverse illumination. Event cameras preserve signal under blur and challenging exposure, but provide little evidence when motion slows. Interaction can restore object state for subsequent propagation, yet promptable event methods merely address single windows. We formalize event-based Promptable Video Segmentation (ePVS), where prompts at arbitrary windows initialize, correct, or introduce objects and predictions. We present Event Memory-As-Prompt Segmentation (E-MAPS), which transfers a pretrained promptable segmenter to event streams and learns propagation and correction. Event-to-Token (E2T) aligns recurrent event features with pretrained representations while preserving prompt-conditioning priors. Memory-Aware Prompting (MAP) converts object-conditioned history into sparse prompts, allowing memory and user inputs to share one decoder pathway efficiently. We construct Event-View Masklets (EViM) from 206K aligned RGB-event pairs and 620K masks for two-stage representation transfer and native event-video learning, and establish three training-disjoint benchmarks. E-MAPS leads prompt-once and interactive ePVS across all three benchmarks while being more efficient. It further demonstrates strong performance on zero-shot object tracking benchmarks. ## 1. 核心问题与研究动机

- **RGB-VOS 的脆弱性**：基于 RGB 的视频目标分割在快速运动、运动模糊、低照度或极端曝光下性能显著下降，视觉线索被削弱。
- **事件相机的优势与短板**：事件相机以微秒级延迟和高动态范围记录亮度变化，在模糊与挑战性曝光下仍能保留信号；但其数据是稀疏、变化驱动的流，在慢速运动或低照度时缺乏形状与身份线索，难以单独维持目标身份。
- **现有方法的分裂**：
  - 事件-SAM 适配方法（EventSAM、SAM-Event-Adapter、EVSAM 等）多聚焦**单窗口**分割或 RGB–事件融合，缺少跨窗口的时序传播与交互校正。
  - 事件-only VOS（如 ECOS）主要支持**初始掩码传播**，不支持后续任意窗口的提示交互。
- **任务形式化**：作者提出 **ePVS（event-based Promptable Video Segmentation）**，即在连续事件流上，点、框或掩码提示可在任意时间窗**初始化、校正或引入**目标，并输出身份一致的 masklet。该任务同时覆盖“单次提示传播”（prompt-once）与“交互式分割”（interactive）两种设定。
- **整体含义**：将“可提示分割”的灵活交互能力与“事件流”的极端条件鲁棒性结合，在单一模型中统一初始化、传播、校正与新目标插入。

## 2. 方法论

### 2.1 核心思想

- 以轻量可提示分割器 **TinySAM** 为骨干，保留其语义与提示条件先验；
- 用**循环事件编码器**提取时序特征，通过 **E2T 适配器**映射到 SAM 风格 token 空间；
- 用**时序记忆库**保存场景与目标条件特征，并通过 **MAP（Memory-Aware Prompting）** 将记忆压缩为少量稀疏提示 token，与用户提示共享同一解码器通路；
- 采用**两阶段训练**：先做 token 空间对齐，再学习视频传播与交互校正。

### 2.2 事件表示与循环编码

- 将事件流切分为非重叠时间窗（默认 ΔT=50 ms），转换为**带符号体素网格** \(V_t \in \mathbb{R}^{B\times H\times W}\)（B=5），按归一化时间戳做线性时间插值累积，保留极性。
- **RTEE（Recurrent Temporal Embedding Extraction）**：基于 ConvLSTM（ResLSTM）的循环编码器，包含两个分支：
  - 事件编码器：输入当前窗口体素，输出多尺度金字塔特征 \(F^{(1)}_t, F^{(2)}_t, F^{(3)}_t\)；
  - 参考事件编码器：输入当前窗口体素与上一窗预测掩码，输出**目标条件记忆特征** \(O^{(k)}_t\)。

### 2.3 E2T 适配器与可提示解码

- **E2T** 将浅层事件特征 \(F^{(1)}_t\) 映射为预训练图像编码器的 patch embedding：先做通道压缩，再经两级上采样与卷积细化，匹配 token 网格的空间分辨率与通道宽度。
- 图像编码器、提示编码器、掩码解码器均来自 TinySAM；新增**遮挡 token 与轻量遮挡头**（focal loss，空掩码为缺失标签），以处理目标消失与严重遮挡。

### 2.4 记忆库、记忆注意力与 MAP

- **记忆库**：每个目标保存若干 \((S_j, O^{(k)}_j)\) 对，其中 \(S_j\) 为场景深层特征、\(O^{(k)}_j\) 为目标条件特征；保留**首个提示窗口**与最近 \(s-1\) 个窗口（默认 s=3）。
- **记忆注意力**：以当前场景特征为 query，历史场景特征为 key，历史目标特征为 value，做标准 softmax 注意力，得到记忆读出 \(R^{(k)}_t\)。
- **稀疏运动调整**：用偏移条件可变形卷积，将最近的目标特征与当前窗口对齐，得到 \(R^{(k)}_{t,\text{sparse}}\)；最终记忆输出为三者相加。
- **MAP**：用 K 个可学习 query（默认 K=2）经“场景特征自注意力 → 与融合特征交叉注意力 → FFN”提炼出 K 个**记忆提示 token** \(T^{(k)}_t\)。在提示窗口，记忆 token 与用户提示嵌入拼接；在无提示窗口，记忆 token 单独进入稀疏提示通路。这样避免了对完整空间记忆的重复处理，显著降低延迟。

### 2.5 两阶段训练

- **Stage I（token 空间对齐）**：
  - I-a：冻结 SAM 模块，仅训练 RTEE+E2T；损失包括中间层与最终层的 **L1 特征蒸馏**、**InfoNCE** 对比损失、**CORAL** 二阶统计对齐，以及采样提示解码的 **Dice** 损失，以保留提示行为。
  - I-b：解冻编码器与掩码解码器继续适配。
- **Stage II（视频训练）**：全部参数解冻，使用 10 窗 clip 与 MAP 记忆；损失为 Dice + 掩码 focal + 遮挡 focal BCE + IoU 置信度回归。
- **交互训练**：当 Dice 低于阈值时模拟注入前景/背景点击；采用**计划式教师强制**，记忆写入从真实掩码逐步过渡到预测掩码，防止早期噪声污染记忆。

### 2.6 数据构建（EViM）

- 来源：**DSEC-Detection**（真实驾驶，含密集框、类别与轨迹 ID）与 **N-ImageNet**（RGB–事件对，语义多样）；另使用 EOS 的原生事件视图实例掩码作为监督来源之一。
- 半自动流程：用 SAM2.1/SAM3 作为 RGB 教师生成候选掩码 → DSEC 用标定投影到事件相机视图；N-ImageNet 用 RoMa-MINIMA 匹配 + RANSAC 估计单应性，并按重投影内点率筛选 → 按轨迹 ID 组织成 masklet。
- 规模：**206,811 对 RGB–事件数据、约 620K 事件视图实例掩码**；人工质检后 2,000 组审计中 92.2% 掩码正确，硬失败率从 25.7% 降至 4.8%。
- 基准：从 DSEC-Detection 测试划分构建三个**训练不相交**基准——EViM500、EViM1000、EViM-HM（长时程、全人工校验）。

## 6. 主要结论与发现

- **精度领先**：E-MAPS 在 EViM500/1000/HM 上 prompt-once J&F 分别为 **84.38 / 80.37 / 76.41**，均高于所有对比方法（含微调后的 ECOS、SAM-I2V、SAM2.1 B+）。
- **效率显著**：27.41 FPS、150.43 GFLOPs/frame、36.25M 参数；比 SAM2.1 B+（2.65 FPS、390 GFLOPs）快十倍以上。
- **交互有效**：在线交互约提升 2 个点；离线交互达 **87.08 / 83.74 / 79.89**，说明校正不仅改善当前帧，还能通过记忆改善后续传播。
- **零样本泛化**：FE108 上 70.15 SR，超 EventSAM+ECOS 4.90 点；VisEvent 低照度条件排名第一，快速运动/运动模糊下优于所有 RGB-only 方法；简单 RGB–事件特征平均融合后在低照度、遮挡、背景杂波下超过专用 RGB–事件方法。
- **零样本交互跟踪**：VisEvent 上 SR 从 38.3 提升至 44.1，相对增益 **15.3%**；无运动（NMO）条件下相对增益 **30.8%**，显著高于 SAM2.1 B+ 与 SAM-I2V。
- **MAP 优于稠密记忆交叉注意力**：精度更高且延迟从 152 ms 降至 36.55 ms（约 4.16× 加速）；再叠加稠密交叉注意力无额外收益。
- **训练目标互补**：Stage-I 的 Dice 与 L1 均关键，完整目标使 Stage-II 从 76.34 提升至 81.37；Stage-II 中 Dice、focal、遮挡、IoU 监督均有贡献；K=2 且条件化当前事件证据效果最佳。

## 7. 优点

- **任务定义清晰**：ePVS 将“任意窗口提示初始化/校正/插入”与“时序传播”统一形式化，填补了事件-only 可提示 VOS 的空白。
- **方法高效且结构优雅**：用稀疏记忆提示 token 替代稠密记忆交叉注意力，让记忆与用户提示共享解码器通路，在精度与速度间取得良好平衡。
- **迁移策略合理**：E2T + 两阶段训练（先特征对齐、再视频传播）充分利用预训练分割先验，避免从零训练大型 token 编解码器。
- **数据贡献扎实**：EViM 规模较大（206K 对、620K 掩码），半自动跨模态标注流程含几何一致性检验与人工质检，并构建训练不相交基准，降低数据泄漏风险。
- **实验维度丰富**：同时评估单次提示、在线/离线交互、零样本跟踪、零样本交互跟踪，并报告参数量、FPS、GFLOPs，兼顾精度与部署可行性。
- **交互增益可传播**：校正后的记忆能改善后续窗口，体现了“记忆作为提示”的设计价值。

## 8. 不足与局限

- **标注依赖 RGB 教师**：EViM 掩码由 SAM2.1/SAM3 迁移生成，存在教师误差与跨模态对齐误差；虽经质检（92.2% 正确），仍有约 4.8% 硬失败，可能引入噪声监督。
- **慢速/低照度下的根本限制未完全解决**：事件在运动缓慢时证据稀疏，方法仍依赖交互提示恢复状态；无提示时性能可能下降。
- **场景多样性有限**：EViM 主要来自驾驶

场景（DSEC-Detection 真实驾驶）与 N-ImageNet 的物体中心序列为主，缺少室内、多人交互、非刚性大幅形变、手持剧烈抖动等更复杂的场景类型；对开放世界类别的泛化能力仍需更多验证。

- **事件表示与时间窗超参固定**：默认 ΔT=50 ms、体素通道 B=5 全程固定，未讨论自适应时间窗或多时间尺度聚合；对极高速运动（窗内事件过密）与极慢速运动（窗内事件过稀）的适配性缺少分层分析。
- **交互评估的外部有效性有限**：在线/离线交互均由基于 IoU 阈值的启发式点击策略模拟，而非真实用户研究；未报告人工标注/点击的时间成本、用户主观负担或点击效率曲线，因此“交互友好性”的结论主要是算法层面的。
- **对比公平性需谨慎解读**：部分 RGB 基线运行在 E2VID 重建帧上，与直接使用事件体素的 E-MAPS 输入模态不同；EventSAM 系列参数量为 164–175M，而 E-MAPS 仅 36.25M，效率对比并非同一量级；事件-only 可提示方法的直接对照因该方向本身空白而有限。
- **遮挡与长时消失的建模较粗**：遮挡 token 使用二值“缺失”标签，未区分“被遮挡”“移出视野”“真实终止”等语义差异；记忆库仅保留首窗与最近 s−1 个窗口（s=3），目标长时间消失后重现的再识别主要依赖有限窗口与首窗锚点，超长时程的遗忘风险未被系统量化。
- **训练与复现成本**：两阶段训练、2×A100 80GB、Stage I/II 各 20 epochs，但未报告总 GPU 小时与实际墙钟时间；数据构建链路依赖 SAM2.1/SAM3 教师、RoMa-MINIMA 匹配与 RANSAC 单应估计，流程较长，第三方完整复现门槛较高。
- **误差分析颗粒度**：主要报告 J、F、J&F 与 SR 等聚合指标，对边界精度、小目标、不同事件密度/信噪比条件下的分层失效模式缺少细粒度诊断；对 4.8% 硬失败样本的成因（教师误差 vs 投影误差 vs 匹配失败）未做归类统计。
- **零样本结论的样本面**：低照度、快速运动等条件性结论主要来自 VisEvent/FE108 零样本实验，其类别与场景分布有限，结论向更广域事件数据迁移时仍需验证。

## 9. 启示与可拓展方向

- **“记忆即提示”范式的可迁移性**：将时序记忆压缩为少量提示 token、与用户提示共享同一解码通路的做法，不依赖事件模态本身，可推广到 RGB–事件融合 VOS、多模态长视频分割与交互式编辑等场景，是本文最具方法学价值的抽象。
- **稀疏接口优于稠密注意力的证据**：MAP 在精度不降的前提下将延迟从 152 ms 降至 36.55 ms，提示在记忆增强型 VOS 中，“如何把记忆喂给解码器”比“记忆容量多大”更关键，这一结论对同类记忆库架构具有普遍参考意义。
- **两阶段“先对齐后传播”的训练策略**：Stage-I 的特征蒸馏 + 对比 + 二阶统计对齐，使小骨干（TinySAM）能承接大规模预训练先验，为“轻量骨干 + 新模态适配器”的迁移提供了可复用配方。
- **可继续深入的方向**：
  - 自适应时间窗与多尺度事件聚合，缓解慢速/高速两端的证据稀疏与冗余；
  - 长时记忆的压缩与检索（如分层记忆、语义锚点），提升目标重现后的再识别；
  - 真实用户交互研究与人机协同的主动提示选择（模型主动请求点击）；
  - 降低对 RGB 教师的依赖，引入事件域自监督或跨模态一致性约束以提升标注质量与规模；
  - 与更强事件基础模型结合，或在保持精度的前提下进一步蒸馏压缩以适配边缘部署。

## 10. 总体评价

本文的核心贡献是**任务定义 + 高效方法 + 规模化数据**三位一体的：ePVS 将“任意时间窗提示初始化/校正/新目标插入”与“时序传播”统一到事件流上的单一模型，填补了事件-only 可提示视频分割的空白；E-MAPS 以 E2T 适配 + 循环事件编码 + 稀疏记忆提示（MAP）的组合，在 36.25M 参数、27.41 FPS 的轻量配置下取得 EViM 三个基准上的最优 J&F，并显著优于参数量数倍于己的事件-SAM 适配方案；EViM 以约 206K RGB–事件对、620K 掩码及含几何一致性校验与人工质检的半自动流程，为该新任务提供了可用的训练与评测基础。其局限主要在于监督信号源自 RGB 教师、场景以驾驶为主、交互评估为模拟点击，以及事件表示超参固定带来的适用边界。总体而言，这是一篇问题切口清晰、工程与实验都较扎实的工作，其“记忆压缩为提示 token”的设计对更广泛的记忆增强型视频分割研究具有借鉴价值；若能在真实用户交互验证、长时记忆与标注自监督化方面继续推进，影响力可进一步提升。
