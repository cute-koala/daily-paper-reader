## 摘要
本文提出并评估了基于深度学习（DL）的线性分配问题（LAP）求解器，用以替代多目标跟踪（MOT）系统中的经典匈牙利算法。研究了三种代表性神经网络模型，即卷积网络（CNN）、图神经网络（GNN）和基于图的线性分配网络（GLAN）。引入了一种代价矩阵嵌入，使单一模型能够处理任意大小的代价矩阵，这符合MOT中目标数量随时间变化的需求，而无需为每种输入形状训练单独模型。大量仿真表明，该嵌入提高了神经求解器（即CNN和GNN）的精度，而GLAN在其中取得了最佳精度。随后，这些求解器被集成到广义标签多伯努利（GLMB）跟踪器中，并在WILDTRACK数据集上评估，其中GLAN的跟踪精度接近匈牙利算法参考结果，并与近期基于DL的跟踪器相当。

## Abstract
This paper proposes and evaluates deep learning (DL)-based linear assignment problem (LAP) solvers as a replacement for the classical Hungarian algorithm in multi-object tracking (MOT) systems. Three representative neural models are studied, namely a convolutional network (CNN), a graph neural network (GNN), and the graph-based linear assignment network (GLAN). A cost-matrix embedding is introduced so that a single model operates on cost matrices of any size, as required in MOT where the number of objects varies over time, without training a separate model for each input shape. Extensive simulations show that the embedding improves the accuracy of the neural solvers (i.e., CNN and GNN), while GLAN attains the best accuracy among them. These solvers are then integrated into a generalized labeled multi-Bernoulli (GLMB) tracker and evaluated on the WILDTRACK dataset, where GLAN yields tracking accuracy close to the Hungarian reference and comparable to recent DL-based trackers.
